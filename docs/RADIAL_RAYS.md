# 放射光線

演出の適用順・前段/後段の作用範囲は [演出チェーン](EFFECT_CHAIN.md) に従う。

作成日・実装日: 2026-11-19。

## 目的と確定要件

アニメのエネルギー放出のように、中心から光線が激しく広がる演出を追加する。ユーザー指定は、中心からの放射、加算ブレンド、解像度に合わせた楕円形への拡張。参考画像では中心の強い白い光と、外へ広がる水色の太い光線が見える。静止画像から動作の周期・速度は確定できない。

ユーザーが承認した設計を実装。既存の集中線２・集中線３は維持する。集中線２の角度ノイズとは別に、個々の光線の本数・太さ・長さを制御できる独立演出「放射光線」とする。

## 見た目と配置

中心付近で細く、外側へ扇状に太くなる長い光線を360度へ描く。輪郭の明確な芯と柔らかい光のにじみを重ね、中心には白いコアと指定色の光輪を置く。芯・にじみ・コアをすべて加算する。透明背景で、素材の明るさから光線を抽出する処理は行わない。

「画像・演出 → 追加演出 → 放射光線」で1クリップに1つ追加。画像・動画・Spine・空クリップの有効区間で表示する。単独の光として重ねるときは、空クリップの単色背景を無効にする。

光線の出現角度・長さ・太さ・光量を短いコマ間隔で不規則に切り替えることで激しさを作る。形状のばらつきに応じ、光線全体の向きもコマごとに不規則に回転する。中心から外への連続移流も行わず、中心に接続した長い光線の再描画を基本にする。

## 設定

座標と寸法は1920×1080の論理座標、左上原点。中心からの長さは基準楕円の長半径、潰れ具合は正円から短い軸を縮める割合。

「配置を変更」ボタンはseedを再抽選する。数値自動化にはしない。

## 楕円形と解像度

長さL、潰れ具合S（%）から軸倍率を `A = (1-max(0,-S)/100, 1-max(0,S)/100)`、半径を `R = L×A` とする。単位円上の点qは `p = C + R×q` へ変換する。0%は半径Lの正円、+50%は横半径L・縦半径L/2、−50%は横半径L/2・縦半径L。±99%でも短軸の1%を残して退化を防ぐ。

光線の角度・開き角・長さばらつきは単位円内で作り、この変換で放射形状全体を楕円へ広げる。長さを変えても潰れ具合は維持される。中心光と周囲の光輪は直径Dの正円として描き、潰れ具合や光線の長さで形・大きさを変えない。にじみは変換後の画面距離で評価する。

実出力へは論理座標をXに出力幅/1920、Yに出力高さ/1080で変換する。現在の出力は1080p固定。縮小プレビューは同じ画角・同じ形状を縮小し、ビューサイズから光線の配置を再計算しない。将来別アスペクト比を実装する際は同じ正規化配置で追従する設計であり、今回出力解像度の設定機能は追加しない。

## 形状と時刻の評価

`k = floor((clipRelativeTime + phaseOffset) × 更新頻度)` とし、0回/秒ならk=0。seed・線番号・k・属性別の固定saltから乱数を得る。壁時計・フレームの呼出回数・逐次乱数に依存しない。コマ内は静止し、境界で切り替える。回転は楕円変換の前に適用し、楕円の横長/縦長の軸と正円の中心光は維持する。シーク、プレビュー、30fps出力で同一時刻の形を再現する。

線番号iの角度候補は本数に依存しない低偏差列を使い、本数の増減で既存番号の候補を再配置しない。形状ばらつきV、長さばらつきL、独立乱数u/v/z（0〜1）から、全光線に共通の回転角最大±V×180°（専用乱数）と、線ごとの角度最大±V×8°、開き角へ `1-0.75Vv`、先端半径へ `1-0.85Lu` を適用する。長さ0%では全線が基準楕円まで届き、100%では半径15〜100%へ散る。根元は全線が中心へ収束し、先端は短い距離で消える。中心の重なりはコアと光量で調整する。

線ごとの光量倍率は `1 - 明滅比 × z`。色を黒へ補間せず、加算するエネルギーへ掛ける。明滅100%でも候補の削除はせず、暗い線が混ざる。本数は見える本数の保証ではなく、重なりや画面外部分により少なく見える。

形状ばらつき0・長さばらつき0・明滅0なら更新しても同一形状。更新頻度0ではどのばらつき設定でも静止する。強弱の時間変化は光量または不透明度の既存自動化を使う。左トリムはphaseOffsetへ開始差を加え、キー時刻を同じ差だけ減らす。右トリムは位相を変更しない。

## 描画と合成

専用RadialRaysモデルが線属性を決定し、Metalは線ごとの三角形・外周のにじみを含む境界矩形へインスタンス描画する。中心光は別の矩形で評価する。輪郭は出力画素単位の微分でアンチエイリアスし、縮小時の細線消失・ちらつきを検証する。画面全体を本数分走査する実装は避ける。にじみは解析的な減衰を使い、画面全体への追加ブラーを不要にする。

色を線形sRGBへ変換し、芯・にじみ・コアのRGB光量へ演出不透明度×クリップ不透明度を掛ける。既存の加算pipelineと同じくRGBのsource/destinationはone/one、alphaはzero/oneとして合成先alphaを維持する。中間の浮動小数点面では1超の光量を保持し、既存のSDR出力変換で収める。白背景では光線が見えにくくなることや、高光量で白飛びすることは加算の性質として扱う。黒い板は描かない。

所有段の素材・既存追加描画の後、上段素材・スペクトラム・歌詞より前に置く。基本素材変形と独立した画面座標で生成し、後段のシェイク・色補正・ブラー・自クリップマスクに従う。上段からの下向きマスクは段全体に適用し、放射光線も対象とする。人物の背後へ置くには別段に透過人物を配置する。

## 保存・編集との接続

`ImageEffects.radialRays: RadialRays?` に設定、isEnabled、seed、phaseOffsetを保存する。未追加はnil。現在のProjectFile version17内で新規optional演出として扱い、既存の集中線と保存名を共有しない。不正な非有限値・範囲外値を検証する。保存項目はlength/squash、キー識別子はraysLength/raysSquash。幅/高さ形式の互換読込は設けない。

ImageParameter / EffectAutomationへ14数値の範囲・既定値・読書きを登録し、ParameterEvaluatorの手動値→項目別音楽同期→範囲制限→本数丸めを共有する。色と更新頻度以外を描画専用経路で評価し直さない。

追加・削除・有効切替・色変更・再抽選は既存の保存/履歴通知へ接続。削除時は関連カーブ・音楽同期・表示範囲も除去。コピーではseedと位相を保持し、クリップ/キーIDを再発行する。貼付・複製・段移動も既存経路を使う。

## 実装順と受入条件

1. RadialRays.swiftの決定的形状生成を実装。円/横長/縦長、画面端の中心、最小寸法、最大本数、更新頻度0、seed再抽選、ランダム順のシークで有限値と再現性を確認する。
2. 芯・にじみ・中心光のMetal描画を接続。暗背景で水色、中心が白へ寄ること、楕円の軸比、加算で背景が暗くならないこと、alpha不変、各光量0・不透明度0を圧縮前画素で検証する。
3. 14項目の入力/キー/音楽同期、色、保存往復、Undo/Redo、コピー、左トリムの同一絶対時刻での位相維持、演出削除を確認する。
4. 1080pと縮小プレビューで同時刻を比較。MP4の時刻・フレーム数、上下段の遮蔽・下向きマスク、歌詞の前後関係を検証する。参考の印象は中心から伸びる太い光線と切替の激しさで評価し、元画像のキャラクターやゲームUIは再現しない。
5. 最大128本×3段、最大にじみ、60秒再生/出力でGPU時間・メモリ・欠落を測定。全体33.3ms以内を目標とし、環境に依存するため保証はしない。責務・重複・命名を整理し、必要なテストとbuild-app.sh成功後に実装完了とする。

将来案は発生源の複数化、連続した外向き移流、滑らかな連続回転。初期実装には含めない。実装の検証結果と制約は末尾に記録する。
