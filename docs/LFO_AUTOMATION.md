# オートメーションレーンのLFOモード

2026-11-22実装。ユーザー要件はレーンのLFOモード、周波数指定とビート同期、Waveform Tilt、Waveform Curve、Amount、Bipolar。以下を実装仕様とする。

## モードと対象

項目単位に「キー / LFO」を選ぶ。LFOはキー間の補間ではなく、親クリップの有効区間全体を評価する信号源とする。既存のパルス/ウェーブ補間はキー方式に残す。画像・動画・Spineの変形とチェーン演出の数値項目へ共通適用し、Spineのアニメーション名や素材、色そのものには適用しない。

LFOは基準値Bへ振動を加える。キー方式との同時加算は初期版では行わず、切替時には非選択側の設定を保持する。キーからLFOへ切り替えてもキーを破棄しない。初回LFO設定のAmountは0とし、切替で突然大きく振れないようにする。キー曲線から固定基準値へ切り替わる差は波形で確認でき、切替全体をUndoできる。音楽同期は独立して併用できる。

## 操作と表示

レーン左欄は項目名とモードバッジを表示し、詳細設定はインスペクターで選択クリップ・項目に対して編集する。同じ段の別クリップへ設定を適用しない。

```text
対象       [拡大縮小 ▾]    モード [キー | LFO]
基準値     [100 %]
時間単位   [Hz | ビート同期]
周波数     [1.00 Hz]        ← Hz時
周期       [1/4音符 ▾]      ← 同期時
位相基準   [曲に同期 | クリップ開始]
位相       [0 °]
Waveform Tilt   [0 %]      下降 ← 対称 → 上昇
Waveform Curve  [0 %]      矩形寄り ← 三角 → サイン
Amount          [0 %ポイント]
Bipolar         [✓]
[1周期の波形見本：ゼロ線・最小/最大・開始位相]
```

LFOレーンはキーと中央○を表示せず、空白クリックでキーを作らない。クリックはクリップ/項目選択だけでシークしない。キーへ戻ると既存キーと補間が復元する。右クリックにはモード切替と「LFO設定を初期化」を用意する。既存のオートメーション削除はキー・LFO・非選択側設定を削除し基準値を残す。レーン削除はさらに音楽同期と表示範囲を削除する。

数値はDragValueFieldを使い、ダブルクリック入力、中ボタンで初期値、左右/上下ドラッグ、Shift微調整、mouseUpで1回確定、Esc取消に対応する。波形とプレビューは仮値で更新し、確定時に保存・Undoへ反映する。Bipolarやモードの切替も1操作。

## 設定値

| 項目 | 範囲・初期値 | 意味 |
| --- | --- | --- |
| 時間単位 | 初期はビート同期 | Hzとビート周期を別々に保持し、切替時に換算して上書きしない |
| 周波数 | 0.01〜20Hz、初期1Hz | 1秒あたりの周期数。入力感度は対数的に扱う |
| ビート周期 | 16/8/4拍、全/2分/4分/8分/16分/32分/64分音符、初期4分音符 | 4分音符を1拍とする。通常/付点/3連を選べる |
| 位相基準 | 初期は曲に同期 | 曲の拍開始またはクリップ開始を原点とする。Hz時にも選択可能 |
| 位相 | 0〜360°未満、初期0° | 波形の開始位置。360°入力は0°へ正規化 |
| Tilt | −100〜100%、初期0% | −100で下降ランプ、0で左右対称、+100で上昇ランプ |
| Curve | −100〜100%、初期0% | −100で矩形、0で三角、+100でサイン状の丸み |
| Amount | 0以上、初期0 | 出力項目と同じ単位の片振幅。表示範囲に依存しない |
| Bipolar | 初期ON | ONは−1〜+1、OFFは0〜1の信号 |

周期は4分音符単位の有理数beatsPerCycleとして保存する。全音符は4拍、付点は通常の3/2倍、3連は2/3倍。既存の拍同期の整数分母1〜16、タイムラインのスナップ5択とは独立し、秒換算だけBeatTimingへ共有する。「小節」は拍子設定がない現状では使用しない。

AmountのUI単位は位置px、角度°、拡大縮小や不透明度は%ポイント、個数は個。例えば拡大縮小100%・Amount20%ポイント・Bipolar ONは80〜120%、OFFは100〜120%。Bipolarの切替で基準値やAmountを自動補正しない。基準値変更は振動全体を平行移動し、Amountを変えない。非選択側のキーは既存の基準値変更規則で移動する。

Amountの上限は項目定義に集約する。物理的な上下限がある項目は上限−下限、位置・回転など上限なしの項目はdefaultRangeの幅をUI上限とする。全数値の有限性と加算・乗算のオーバーフローも検証する。表示上下限の変更で上限や値は変えない。

## 波形の定義

Bitwigの操作概念を参考にするが、内部式の互換性は要求しない。Tiltは波の上下反転ではなく、上昇と下降に割く時間を変える。Curveは振幅や周期を変えずに形状を変える。次の式をCPU共通の純粋関数LFOEvaluatorへ集約する。

位相をp∈[0,1)、TiltをT∈[−1,1]、山の位置をa=(T+1)/2とする。

- 0<a<1: p<aならu=p/a、それ以外はu=(1−p)/(1−a)。
- a=0: u=1−p（下降ランプ）。
- a=1: u=p（上昇ランプ）。

CurveをC∈[−1,1]とし、u∈[0,1]からF(u)を求める。

- C=0: F(u)=u。
- 0<C≤1: F(u)=(1−C)u+C(1−cos(πu))/2。
- −1<C<0: k=1/(1+C)、F(u)=u^k/(u^k+(1−u)^k)。実装はlogistic/log領域で安定化し、u=0/1は明示処理する。
- C=−1: u<0.5で0、u>0.5で1。u=0.5では上昇中は1、下降中は0（右連続の矩形）。

Tilt=0・Curve=+100%でサイン状、Tilt端点・Curve=0でのこぎり、Curve=−100%で矩形となる。Tilt端点と矩形には不連続があり、境界では新周期/右側の値を採用する。描画は左右極限を区別する。任意カーブ描画、ランダム、スムージング、Delay/Fade-in、LFO設定自体の自動化は後続候補とする。

## 時刻と値の評価

曲時刻t、拍開始O、Hz周波数f、1周期の拍数qに対して、曲同期の周期数はHzで(t−O)f、ビート同期で(t−O)BPM/(60q)。原点前もfloorによる正の剰余で周期を延長する。待機や再生停止中もtだけから同じ値を返す。

クリップ開始基準ではτ=t−clip.start+clockOffsetSecondsを同じ式のt−Oへ置き換える。初期offsetは0。左トリム差Δに対してoffset+=Δとし、残る映像の位相を維持する。右トリム/再延長で位相を変えない。クリップ移動と貼付は、曲同期なら移動先の曲時刻、クリップ基準ならコピーした内部時計を使う。素材動画の再生速度はLFO時計へ掛けない。

周期数へphaseDegrees/360を加え、p=x−floor(x)で位相を得る。フレーム差分を積算せず、プレビュー・出力・途中シークを一致させる。BPM変更は同じ曲時刻で再評価し、Hz周期は変えない（曲原点Oの変更は曲同期の位相を変える）。

出力はs=Bipolar ? 2F(u)−1 : F(u)、V=B+Amount×s。ParameterEvaluatorは次の順に統一する。

1. キー方式は既存の手動値、LFO方式はVを求める。
2. 既存AudioModulationの加算/相対同期を適用する。
3. 項目の物理範囲へ制限し、個数を丸める。拡大率の正値制約も維持する。

音楽同期を相対方式で併用するとLFOの値も相対変化の対象となる。中間のLFO値を先に物理範囲へ丸めない。波形見本は理論信号、レーンの実線は最終評価値とし、基準値・制限前の線を薄く補助表示できる。例えば不透明度100%のBipolar振動は上半分が100%へ制限されることが分かるようにする。表示上下限は評価値の制限として使わない。

20Hzまでの設定は30fps映像で形状を完全に再現する保証ではない。UIへ実効周期/Hzと15Hz以上でのフレームサンプリングの補足を表示し、出力はn/30秒の値をそのまま使う。ピークを別フレームへ移す処理はしない。

## モデル・保存・構造

新しいParameterAutomationを1項目につき1つ所有する。mode（keys/lfo）、keyCurve（任意のKeyCurve。keysのみを所有）、lfo（任意のLFOSettings）を持ち、非選択側も保存する。modeに対応するpayloadは必須。キー方式の空キーは固定値として正規化し、LFO設定が残る場合だけ休止データとして保持する。辞書キーは既存ImageParameterとEffectParameterAddressを使い、同じ情報を旧curves配列にも二重保存しない。

LFOSettingsはtimebase、frequencyHz、beatsPerCycle（分子/分母）、tilt、curve、amount、bipolar、phaseDegrees、phaseOrigin、clockOffsetSecondsを保存する。基準値は既存fixedValues/演出値、表示上下限はautomationRangesに一意に保持する。キー曲線の最小/最大との二重管理は移行時に解消する。共有NumericCurveはキーの補間に専念し、SpineブレンドへLFOが暗黙適用されない構造にする。

保存はv19、読込はv16〜19。旧curvesをkeysモードへ変換し、音楽同期・ノードID・キーIDと表示範囲を保持する。旧版payloadへのautomations混入・未来版・非有限値・無効周期・重複項目は拒否し、読込失敗時に上書きしない。

選択/レーン開閉は既存UI状態、設定はEditHistoryの値スナップショットへ含める。演出削除、発生源番号変更、コピー/複製の新ID発行、素材変更、レイヤーロック、全パラメーター列挙を新モデルへ揃える。LFOは素材を必要としない。休止キーも複製時のID再発行とトリム処理の対象。

## 描画・受入確認

可視範囲だけ評価し、ピクセル幅と周期に応じた適応分割を使う。矩形/ランプの境界は左右極限を同時刻で描く。縮小して周期がピクセル未満になる場合は波を間違った低周波として結ばず、値域の帯表示へ切り替える。通常波形は1周期32分割以上を目安にし、極端なTilt/Curveでは誤差に応じて追加する。上限点数を設け、30fpsの点列だけでグラフを描かない。

- Tilt/Curveの中心と両端、矩形切替、周期境界直前/直後、非整数BPM、原点前、長時間、Hz/付点/3連の周期を確認する。
- Amount0、Bipolar ON/OFF、%ポイント、基準値移動、物理範囲、個数丸め、音楽同期併用を確認する。
- モード往復でキー保持、LFOのみのレーン、空白クリック、削除範囲、ロック、仮編集/取消/1回確定を確認する。
- 移動・左右トリム・再延長・貼付/複製・演出削除で時計と休止設定を確認する。
- 保存往復、対応3世代移行、無効payload拒否、Undo/Redo、グラフ/プレビュー/MP4の同時刻比較を確認する。
- 300秒表示・多数レーン・20Hzでも描画点数と時間が制御され、設定変更時にキャッシュが無効化されることを確認する。
