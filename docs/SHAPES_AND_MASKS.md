# 図形演出とマスクの設計

作成・実装: 2026-11-14。確定要件は長方形・三角形・楕円・星型などの図形、サイズと色の指定、マスクの画像または下レイヤーへの適用。以下は設計に沿って実装した仕様。

## 1. 基本方針

「追加演出」に「図形」と「マスク」を追加する。両者は形状定義と描画処理を共有し、設定は独立させる。色付きの星を表示しながら画像を楕円で切り抜く、といった併用ができる。各1つ/クリップ。複数の図形を使う場合は既存3段の別クリップへ配置する。

図形は画像・動画・Spine・素材未設定クリップに追加可能。マスクの「画像」は動画/Spineの描画結果も含めた素材映像を意味する。素材ファイルのアルファをマスクにする機能や、任意のパス編集は初期範囲外。

空クリップの既定の黒い単色背景は既存仕様として維持する。空クリップに図形またはマスクを追加するときは、インスペクターに「単色背景が有効」を表示し、直接無効化できるようにする。追加操作で既存の背景を黙って削除しない。

## 2. 図形の設定

| 項目 | 仕様 |
| --- | --- |
| 種類 | 長方形、三角形、楕円、星 |
| 幅・高さ | 1080p基準px、各0〜7680、初期400×400。0は空形状 |
| 中心X/Y | 映像左上原点の1080p基準px、各−7680〜7680、初期960/540 |
| 回転 | −180〜180°、初期0°、画面上で時計回りが正 |
| 色 | RGBカラーピッカー、初期白 |
| 不透明度 | 0〜100%、初期100% |
| 星の頂点数 | 3〜12、初期5 |
| 星の内径比 | 外径の5〜95%、初期45% |

長方形の角丸・線のみの表示・グラデーションは将来拡張。三角形は枠の上中央と左右下端を頂点とする二等辺三角形。星は上向きの外頂点から外径/内径の頂点を交互に置く。三角形と星は正規化した枠を幅/高さへ伸縮し、中心を軸に回転する。正方形/円は幅と高さを同値にすれば作れる。

図形は画面座標で配置し、素材の位置・拡大縮小・回転・シェイクから独立する。図形自身のサイズ・位置・回転で操作する。素材と一緒に動かすローカル座標モードは初期範囲外。単色背景→変形済み素材→色付き図形の順に重ね、その結果へ既存の色調補正・ブラー・ブルームを適用し、粒子を重ねる。既存の粒子も図形の手前に表示する。

## 3. マスクの設定

図形と同じ種類・幅・高さ・中心・回転・星の設定を持つ。色は持たず、形状の内側を可視、外側を透明にする。マスク専用の不透明度は設けず「強さ」を使う。

| 項目 | 仕様 |
| --- | --- |
| 適用先 | このクリップの画像 / 直下のレイヤーのクリップ |
| 反転 | 初期OFF。ONで内側を透明・外側を可視にする |
| 境界ぼかし | 0〜200px、初期0px。0でも輪郭のアンチエイリアスは行う |
| 強さ | 0〜100%、初期100%。0でマスク前の見え方へ戻る |

「図形をマスクへコピー」で形状パラメーターを1回コピーできる。以降は独立して編集し、見えない連動状態を作らない。マスク輪郭の編集ガイドは選択中だけ表示し、動画には出さない。

### このクリップの画像

単色背景・素材・色付き図形へフィルターを適用した後、マスクで切り抜く。ブルームのにじみも輪郭で切る。粒子は切り抜かず、従来どおり画面全体へ描く。UIに「粒子は対象外」と表示する。素材なしでも図形と単色背景の切り抜きに使える。

### 直下のレイヤーのクリップ

「下」は画面内の上下位置ではなく描画順の直下の固定段。現在の小さいslotから合成する順序に合わせ、所有クリップがslot Nなら対象はslot N−1。例: 最前面の3段目の星マスクは、2段目のクリップを星形に切り抜く。1段目やシーン背景へ影響しない。

- 対象は同時刻に有効な直下段のクリップ全体。素材・単色背景・図形・ブルーム・粒子を含む。
- 対象範囲は両クリップの時間的な重なりだけ。区間は既存どおり開始を含み終了を含まない。
- 直下が空なら何も加工しない。さらに下の段へ探索しない。再生位置に応じ「対象なし」を表示する。
- 最背面の1段目では選択肢を無効化する。下向きマスクを持つクリップを1段目へ移動しても設定を保持し、描画は無作用・UIで対象なしとする。
- 対象IDを保存しない。段移動や対象クリップの入替え後は、その時刻の直下段へ作用する。
- マスク所有クリップ自身の素材や図形は通常表示する。純粋なマスクだけにしたい場合は空クリップを使い、単色背景を無効にする。マスク形状そのものは色付きでは描かない。
- 歌詞・スペクトラム・シーンの背景色は対象外。

2段目と3段目に下向きマスクがあれば、2段目のマスクは1段目、3段目のマスクは2段目へそれぞれ作用する。マスク生成は他のマスクから独立し、循環参照や合成済み下層全体への連鎖は作らない。

## 4. 合成と不透明度

形状のカバレッジをM（0〜1）とする。反転・境界ぼかしを形状に適用してから、実効マスク係数を `1 − s + s × M` とする。

- 自分の画像への適用ではsはマスク強さ。
- 下レイヤーへの適用ではsはマスク強さ×所有クリップの共通不透明度。所有クリップが0%なら下層へ影響せず、フェードで自然にマスクが解除される。
- 切り抜かれる側はpremultiplied RGBとアルファの両方に係数を掛ける。加算のブルーム/粒子にも同じ係数を掛け、透明部分から光だけ漏れることを防ぐ。
- 対象の共通不透明度は対象自身に1回だけ適用する。図形の色・不透明度はマスクに影響しない。

幅/高さ0のマスクは通常なら全透明、反転なら全可視。強さ0ではどちらも無作用。境界ぼかしは形状自体に適用し、対象画像の色をぼかさない。画面外も含め形状を評価してから表示範囲へ切り取り、画面端でぼかしが不自然に欠けないようにする。

## 5. モデルと描画の責務

- 共通値型 `ShapeGeometry` に形状種別・中心・幅/高さ・回転・星設定を保持する。
- `ImageEffects.shape` に有効状態・geometry・RGB色・図形不透明度、`ImageEffects.mask` に有効状態・geometry・適用先enum・反転・境界ぼかし・強さを保持する。両者は別のShapeGeometry値を持つ。
- `EffectAutomation` / `ImageParameter` / `ParameterEvaluator` を拡張し、形状の連続値とマスク強さ・ぼかしを既存のキー/拍/トランジェント同期へ接続する。色・種類・適用先・反転・星の頂点数は初期段階では固定。星の内径比は連続値。非表示の種類固有設定は保持する。
- `VisualTrack` の段情報から、素材取得前に有効クリップとマスク対象を解決する。`VisualRenderLayer` にslotまたは解決済み対象関係を渡す。現在の有効素材配列の隣接要素から推定しない。欠損素材で段が詰まっても対象を誤らないようにする。
- `ShapeRenderer` は正規化形状から色付き図形とマスクカバレッジを生成する共通処理を持つ。長方形/楕円の解析的評価、三角形/凹形の星の境界評価をMetalで実装し、輪郭とぼかしをプレビュー/出力で共有する。長方形は矩形の符号付き距離、楕円は境界付近の距離近似、多角形は辺への距離と内外判定を使用し、距離に応じたsmoothstepでぼかす。
- `MetalSceneRenderer` は「時刻評価と対象解決」「各クリップの描画」「マスク適用」「段順合成」「前景と色変換」を分ける。現行のsceneへ素材・粒子を直接描くループだけでは対象を限定できないため、下向きマスクの対象クリップは透明な中間面へ全体を描き、切り抜いてから合成する。
- 中間面は必要なクリップだけに確保する。粒子の加算光を含む面は線形浮動小数点で保持し、切り抜き前後で現行の加算合成と一致するか確認する。単純なsource-overへの置換で見え方を変えない。
- キャッシュキーに評価済み形状・色・解像度・マスク設定と対象関係を含める。動くマスクによる下層の更新を素材処理キャッシュの再利用で抑制しない。フレーム内の中間面とマスク面はGPU完了まで保持し、終了後にプールへ返す。

## 6. 編集・保存

数値欄は `DragValueField`。ダブルクリック入力、中ボタン初期化、左右/上下ドラッグ、Shift微調整、Esc取消を共有する。ドラッグ中は仮描画、mouseUpで1回確定する。色欄は既存どおり連続通知を使い、カラーパネルからモデルへ反映する。

既存のVisualEditor確定経路で自動保存・Undo/Redoへ接続する。左トリムは既存の演出カーブと同じ時刻移動を行う。複製/コピーは値を保持してキーIDを再発行する。削除時は該当演出のカーブ・音楽同期・表示範囲も削除し、無効化時は保持する。

保存形式はProjectFile version 10。v9を含む旧形式は既存のバックアップして新規作成するUIへ送り、互換読込を追加しない。サイズ・座標・色・強さ・種別・有限値をモデル検証し、不正ファイルを上書きしない。図形/マスクだけの空クリップは外部素材を要求しない。既存素材付きクリップの欠損検証は維持する。

## 7. 実装範囲と受入条件

1. ShapeGeometryと描画を実装。4形状・非等方サイズ・回転・画面外・0サイズ・凹形の星の画素を確認。
2. 図形UI・空クリップ・保存/履歴/コピー・オートメーションを接続。色パネルの実通知、単色背景との重なりを確認。
3. 自画像マスクを実装。反転/ぼかし/強さ、ブルームの切断、粒子が対象外であることを確認。
4. 下段マスクの対象解決とクリップ単位の中間合成を実装。段間の空白、対象切替、最背面への移動、区間端、同時2マスク、粒子/加算光の切り抜き、不透明度0/50/100%を確認。
5. 画像/動画/Spine/空クリップのプレビューと1080p MP4を同時刻で比較し、輪郭の縮尺・色・反転・ランダムシークの決定性を検証する。3段・動くマスク・粒子併用でメモリとCPU/GPU時間を測定する。
6. 重複した形状評価・演出UI・描画準備を整理し、関連テストと全体検証後に `./scripts/build-app.sh` でappを生成する。

直下固定段、自画像/下段の粒子対象範囲、所有クリップの不透明度による解除は、設計への実装依頼を受けて採用した。
