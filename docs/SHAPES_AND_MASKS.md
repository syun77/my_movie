# 図形とマスク

図形とマスクは画像・動画・Spine・空クリップで使用できる。演出の順序と保存は [演出チェーン](EFFECT_CHAIN.md) に従う。

## 図形

四角形・三角形・楕円・星を1080p左上原点の画面座標で配置する。基本の素材変形と独立し、図形自身の幅・高さ・中心X/Y・回転で操作する。色はRGB、不透明度は0〜100%。星は頂点数3〜12と内径比5〜95%を持つ。

| 数値 | 範囲 | 初期値 |
| --- | --- | --- |
| 幅・高さ | 0〜7680px | 各400px |
| 中心X/Y | −7680〜7680px | 960/540px |
| 回転 | −180〜180° | 0° |
| 星の頂点数 | 3〜12 | 5 |
| 星の内径比 | 5〜95% | 45% |
| 不透明度 | 0〜100% | 100% |

図形はチェーンの指定位置で通常合成する。前段の粒子・素材より手前に描き、後段の色補正・ぼかし・シェイク・マスクなどに従う。単色背景は、その位置までの結果の背面に敷く。

## このクリップのマスク

演出としてチェーンへ追加し、指定位置までの結果全体を切り抜く。図形・背景・粒子・加算光も前にあれば対象になる。後から追加した演出は切り抜かない。

形状・位置・サイズ・回転・星の設定は図形と共通。境界ぼかし0〜200px（初期0）、強さ0〜100%（初期100）、反転（初期OFF）を持つ。強さ0/無効は通過。幅または高さ0は被覆なし、反転すると全被覆になる。「図形をマスクへコピー」は形状設定だけをコピーし、図形との参照関係を作らない。

`マスク→ブルーム` は輪郭から外へ光がにじみ、`ブルーム→マスク` は光も切り抜く。

## 直下段のマスク

チェーン外の「クリップ出力」から設定し、自クリップのマスクと同時に使える。形状と編集項目は自クリップのマスクと共通。所有クリップがslot Nなら対象はslot N−1の完成結果で、さらに下の段は探索しない。対象クリップの素材・背景・図形・全演出を切り抜く。

- 直下が空なら作用しない。対象IDを保存せず、段移動や配置の切替に追従する。
- 自分自身、さらに下の段、歌詞、スペクトラム、シーン背景は対象外。
- 所有クリップの不透明度をマスク強さへ掛ける。不透明度0では解除される。
- チェーンのバイパスでは解除されない。直下段マスク自身の有効チェックを使う。
- 2つの段間マスクがあっても、それぞれ直下固定段だけへ作用する。

## 描画

ShapeRendererの共通形状・距離評価で4種類を描く。自クリップのマスクは余白付きのチェーン面を切り抜き、段間マスクは直下クリップの完成面を切り抜く。加算光のRGBも同じマスク係数を掛け、alpha0を理由に捨てない。プレビューガイドは動画へ出力しない。

図形・マスクの座標は余白と描画縮尺を補正し、プレビューと1080p出力で一致させる。クリップ共通不透明度はチェーン完成後に1回だけ適用する。

## 自動化・保存・編集

図形と自クリップマスクはチェーンノード、直下段マスクは出力用ノードが設定・キー・音楽同期・範囲を所有する。自クリップはmask系、直下段はbelowMask系パラメーターを使う。数値は共通DragValueField、XYはプレビューハンドルにも対応する。色・形状種別・反転・頂点数は固定設定。

並べ替えは設定とノードIDを保持する。削除ではそのノードの自動化も削除し、Undoで復元する。保存はv13、読込はv13〜16。旧マスクのtargetは移行境界で対応するノードへ分離し、実行時モデルには残さない。

## 検証

ShapeTestsとEffectChainTestsで、4形状、位置・回転、色、コピー、数値自動化、トリム、両マスク、順序差、粒子と加算光、直下固定段、空段、不透明度、バイパス、保存・移行を確認する。MP4の混在素材テストでは回転する図形と段間マスクのフレームを比較する。
