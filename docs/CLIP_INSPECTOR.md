# クリップタブと編集対象の設計

作成日: 2026-11-22 JST。実装済み。「画像・演出」を「クリップ」に改名して分かりやすくするユーザー要件に基づく。第1〜9節を現行の編集仕様とする。第10節は別の追加提案で、未実装。

## 1. 目的と対象

画像・動画・Spine・空の演出用クリップを、一つの配置物として扱う。素材、基本変形、演出、その項目の自動化を同じ文脈で編集し、「どのクリップの、どの項目に作用するか」を明示する。

トップレベルのタブは「歌詞 / クリップ / スペクトラム」とする。歌詞区間は既存の専用タブで編集する。「クリップ」のツールチップと未選択案内に「画像・動画・Spine・演出用クリップ」を記し、対象の範囲を補足する。

初回実装では内部に「基本 / 演出」の切替を追加せず、既存のカテゴリを同じ画面で表示する。タブ内切替を増やさずに、選択対象と共有編集欄の整理で改善する。各演出の設定は既存どおり選択した一つを表示する。

## 2. 全体配置

```text
[歌詞] [クリップ] [スペクトラム]

レイヤー2 / 人物.png                    ← 共通ヘッダー
画像クリップ                            ← 共通ヘッダー
────────────────────────────────────
以下を縦スクロール
┌ 素材と配置 ─────────────────────┐
│ 素材の追加・変更・管理、開始／終了、段 │
│ 動画／Spineの専用設定                 │
└────────────────────────────────┘
┌ 基本変形 ───────────────────────┐
│ 位置X / Y、拡大率、回転、不透明度      │
└────────────────────────────────┘
┌ 追加演出 ───────────────────────┐
│ ＋演出を追加                         │
│ ブラー → ブルーム → …（実際は縦一覧） │
│ 選択中：ブルーム                     │
│ 強さ / 半径 …                        │
└────────────────────────────────┘
┌ 選択項目の自動化 ────────────────┐
│ 対象：ブルーム › 強さ          [変更▾]│
│ 基準値：…   キー：あり／なし          │
│ モード：[キー / LFO]                  │
│ LFOの詳細（LFO時のみ）                │
│ 音楽同期：[追加] または有効状態・詳細  │
│ グラフ表示設定（レーンがある場合）    │
└────────────────────────────────┘
```

共通ヘッダーはタブ列の直下に固定し、カテゴリだけをスクロールする。高さは2行を基本とし、素材名は中間省略、全文をツールチップで確認できる。クリップ区間の数値は「素材と配置」に一か所だけ置く。

共通ヘッダーはクリップタブ内だけに表示する。歌詞・スペクトラムへ移った際に、その編集対象と取り違える表示を残さない。クリップタブへ戻ると有効な選択を復元する。

各カテゴリには実装済みInspectorSectionを使用し、450pt幅、内側12pt、行間8pt、主要ラベル72pt・数値86ptの整列を維持する。画面内に収まらない長い対象名は2行へ折り返し、数値欄を縮めない。

## 3. カテゴリの役割

| 領域 | 内容とルール |
|---|---|
| 共通ヘッダー | レイヤー名、素材名または「演出用クリップ」、種類。素材の欠損・ロック状態も表示する |
| 素材と配置 | 配置・削除・素材管理・素材変更、区間、レイヤー。動画の素材開始と速度、Spineの再生設定は対象素材でだけ表示する |
| 基本変形 | 位置・拡大率・回転・不透明度。ノブと数値の操作は既存DragValueFieldを使う |
| 追加演出 | 適用順の一覧、有効／無効、選択演出の詳細。カテゴリ別に並べ直さず、合成順を維持する |
| 選択項目の自動化 | 一つの対象に対するキー／LFO、音楽同期、グラフ範囲。対象を選ぶ場所を一か所に統一する |

基本の不透明度はクリップ出力全体へ作用する現仕様を維持し、その旨をツールチップで示す。画面上のカテゴリ順を描画処理順の説明として使わない。演出チェーン内の入力・出力・直下段マスクの既存表示は保持する。

Spineのアニメーション名・混合率の専用レーンは、通常のImageParameterのキー／LFO編集へ統合しない。「Spine再生」の専用設定と専用レーンとして表示し、変形項目の自動化との区別を保つ。

## 4. 共有する編集対象

選択クリップ、選択演出、選択数値項目をVisualEditorがまとめて管理する。表示用文字列を識別子に使わない。

- 選択クリップ: clip ID。
- 選択スコープ: 基本変形、または演出node ID。
- 選択数値項目: スコープに属するImageParameter、または未選択。
- 演出ごとの最後の選択項目: 開いているクリップについてだけ保持する一時UI状態。

自動化の対象表示は、基本項目なら「基本変形 › 位置X」、演出なら「ブルーム › 強さ」、発生源なら「光の粒子 › 発生源2 › X」とする。LFO、音楽同期、グラフ範囲がすべて同じ対象を参照する。

グラフ・LFO・音楽同期の対象は「対象」の一つの選択UIへ集約する。対象メニューは「基本変形」と、追加済み演出ごとのグループに分ける。演出の数値項目は追加済みノードだけ列挙し、存在しない発生源は含めない。

対象メニューは新規作成の入口も兼ねるため、まだ自動化されていない項目も選べる。単なる項目選択でキー・LFO・音楽同期を作成しない。

## 5. 選択と画面の連動

| 操作 | 編集対象と画面の遷移 |
|---|---|
| 新しいクリップを選択 | 共通ヘッダーとカテゴリを更新。基本変形の「拡大縮小」を初期対象とする。他クリップの演出や項目を引き継がない |
| 同じクリップを再選択 | 有効な演出・項目の選択を維持する |
| 基本変形のラベル／ノブ／数値を操作 | その基本項目へ対象を合わせる。値の変更は既存の操作規則に従う |
| 演出一覧の行を選択 | その演出の詳細を表示。記憶した有効な数値項目を復元し、初めてなら「この演出の項目を選択」と案内する |
| 演出の数値を操作 | その演出と数値項目へ対象を合わせる |
| 「対象」メニューから項目を選択 | 基本／演出の選択も同期。演出項目なら該当演出の詳細を開く |
| タイムラインのレーン・キーを選択 | クリップ、演出、対象項目を同期。自動化欄は必要な場合だけ見える位置へスクロールする |
| 対象にレーンが存在しない | インスペクターでは対象を保持し、タイムラインの旧レーン選択を解除する。選択だけでレーンを作らない |
| 演出を削除 | 削除ノードの記憶も破棄。編集中の対象なら基本変形の「拡大縮小」へ戻す |
| 発生源を削除 | 既存のパラメーター番号変更に追従。対象が消滅した場合は項目未選択とする |
| Undo/Redo | 現在の選択が有効なら維持。消滅していれば上の規則で戻す。Undoのために別クリップへ勝手に選択を移さない |

ノブをドラッグ中に自動スクロールやビュー再構築を行わない。数値編集中に対象を更新しても、field editorやIMEを作り直さない。ラベルクリックによる既存のXYハンドル表示を保ち、クリックを二重消費しない。

対象変更とレーン選択の通知は、一つの同期経路で処理する。自分から更新したUIの通知で同じ更新を再実行しない。選択によって再生時刻を変更しない。

## 6. 自動化欄の表示条件

- 対象未選択: 案内だけを表示。前の演出の設定値を残して表示しない。
- 通常のキー側: 対象・基準値・キーの有無・モード選択を表示。LFO詳細は隠す。
- LFO側: 波形、周波数／ビート周期、位相などを表示。休止中のキーは保持する。
- 音楽同期なし: 「音楽同期を追加」だけを表示。
- 音楽同期あり: 有効スイッチ、入力方式、その方式に必要な詳細を表示。OFFでも設定を確認・編集できるよう詳細は残し、OFFと明記する。
- グラフ範囲: 対象に表示レーンがある場合だけ表示する。「表示範囲」と書き、出力値の制限と取り違えないようにする。
- キースナップ: キー編集に使う設定として表示。LFOだけを編集している間は隠し、値は保持する。

基本値・LFO・音楽同期の合成規則は変更しない。対象だけを変えた場合は自動保存やUndo履歴へ追加しない。モード切替・値変更は既存の確定経路を使う。

## 7. 未選択・ロック・欠損

クリップ未選択時は「画像・動画・Spine・演出用クリップを選択してください」と素材追加・素材管理を表示し、基本変形・演出詳細・自動化の空パネルは省略する。

ロック時は名前と設定値を確認できる状態を維持し、変更操作を無効にする。素材欠損時もクリップを保持し、素材変更による復旧を可能にする。クリップ区間外の注意や演出のOFF状態は、対象名の近くにも表示し、値を変えても映像が変わらない理由が分かるようにする。

## 8. 実装範囲と整理

| 対象 | 変更内容 |
|---|---|
| PlacementEditor | タブの表示名・アクセシビリティ名・ツールチップを更新。共通ヘッダーをスクロール外へ置く受け皿を用意する。クリップと歌詞のタイムライン切替、スペクトラムでの維持は既存仕様を保つ |
| VisualEditor | 共通ヘッダー、選択状態と対象パスの一元管理、カテゴリと自動化欄の同期。内部のvisualという名称は映像素材を表す既存モデルと整合させ、表示名の変更だけを理由に一括置換しない |
| LFOEditor / AudioModulationEditor | 対象ピッカーを取り除き、親から対象を受け取る。各設定の描画・入力処理に責務を限定する |
| ImageEffectsEditor | 選択ノードの通知、各数値の選択通知、外部からの選択反映を用意。演出チェーンの並べ替え・開閉・有効状態を保持する |
| DragValueField / PreviewHandleLabel | 必要なら値変更と独立した選択通知を追加し、既存のドラッグ／直接入力／初期化／ハンドル表示を維持する |
| TimelineView | インスペクターの対象とレーン選択を連動。キー未作成の項目選択をグラフ選択と混同しない |
| InspectorSection | 既存の見出し・枠・整列を再利用する |
| ドキュメント・試験 | 現行UIを説明するREADME、ARCHITECTURE、IMAGE_TIMELINE等と関連試験を実装時に新しい表示へ更新する |

保存モデル・描画・プロジェクトversionは変更しない。選択・自動化欄の対象・スクロール位置は一時UI状態で、プロジェクトやUndoスナップショットへ保存しない。

実装は (1) 改名と共通ヘッダー、(2) 選択状態の一元化、(3) 重複ピッカーの除去と対象パス表示、(4) 未選択等の表示、(5) 重複通知・責務の整理、(6) 検証とbuild-app.shの順で行う。演出のON/OFFやレーン作成を選択の副作用にしないことを整理フェーズで確認する。

## 9. 受入条件

1. タブが「歌詞 / クリップ / スペクトラム」と表示され、各タブでタイムラインと編集欄が正しい対象を示す。
2. 450pt幅と最小ウィンドウでカテゴリ・数値欄が枠内へ収まり、スクロール中もクリップ名が確認できる。
3. 基本の位置Xと演出の数値を交互に選んでも、対象名・LFO・音楽同期・グラフが同じ項目を示す。
4. ノブ、対象メニュー、タイムライン、演出一覧のどこから選んでも、別クリップや別ノードを編集しない。
5. 対象選択だけで値・再生時刻・保存内容・履歴・キー数が変化しない。
6. LFO／キーの切替、音楽同期のON/OFF、タブ切替で設定値が保持され、条件付き表示が復元する。
7. 演出・発生源の削除、Undo/Redo、素材変更、プロジェクト切替で消滅した対象への参照を残さない。
8. ドラッグ確定は1操作、Escで取消、数値入力中のカーソル・IME・プレビュー操作を維持する。
9. 画像・動画・Spine・演出用クリップ、未選択・欠損・ロック・区間外を確認する。Spine専用レーンも使用できる。
10. 描画と保存モデルに差分を作らず、関連試験と整理後に最新のdist/MV Studio.appを生成する。

## 10. 変更項目だけの表示（追加提案・未実装）

2026-11-22の追加要件に対する設計。固定ヘッダー直下に「表示: [すべて | 変更のみ]」を置く。初期表示はすべて。変更のみではパラメータ単位で絞り、空のカテゴリ枠を省略する。カテゴリ順・項目順は維持する。まずクリップタブへ適用し、歌詞・スペクトラムの書式設定にも同じ規則を展開可能とする。

「変更」は保存前との差分や操作履歴ではなく、項目の標準初期値との差分。初期値へ戻せば対象外になる。キー・LFO・音楽同期の設定があれば、基準値が初期値でも対象とする。休止中のキーや無効の同期も保持設定として含め、状態を明示する。再生時刻の評価値では判定せず、再生で一覧を増減させない。範囲だけの表示調整・選択・開閉は変更扱いにしない。浮動小数値は項目の精度に対応した許容差で比較し、表示文字列では判定しない。

追加済み演出の一覧と追加ボタンは常時表示する。追加自体が設定なので初期値だけの演出も一覧から消さず、OFFも明示する。選択演出の詳細は変更項目だけを示し、該当なしなら「この演出のパラメータは初期値です」とする。有効/削除などの管理操作は残す。色・選択肢・画像参照も初期値との差で対象に含める。

クリップ名・種類・開始/終了・素材参照・レイヤーと、素材追加/変更/管理は文脈と操作の入口として残す。動画速度・素材開始、Spineの再生設定は対応する標準値との差で判定する。歌詞へ展開する場合、本文・区間は残し、全歌詞共通の書式を絞る。

変更のみでも「項目を選んで編集…」から全ての適用可能項目を選べる。既存の共有対象メニューを再利用し、未変更項目を選んだ場合は「編集中」としてその項目と必要な設定入口を一時表示する。選択だけではモデルを書き換えない。新規演出の追加直後は詳細全体を一時表示し、最初の調整を可能にする。

ドラッグ・直接入力・IME変換・色編集セッション中は表示集合を固定する。初期値復帰で条件を外れた項目も、現在の編集対象である間は一時表示を維持し、別項目選択または明示的な表示切替で再判定する。入力ビューを再構築せず、スクロール位置を保つ。Undo/Redo、クリップ切替では確定モデルから再判定し、有効な編集対象だけを保持する。

表示モードはアプリ共通のUI設定としてUserDefaultsへ保存し、プロジェクト・Undo・出力に含めない。変更項目がなくてもヘッダーと管理操作を残し、「変更したパラメータはありません」「項目を選んで編集…」「すべて表示」を示す。

実装時は項目の初期値・比較・自動化所有関係をモデルから問い合わせる共通判定へ集約し、各エディターは表示制御を担当する。既存の用途別表示条件とANDで適用するが、編集に必要なモード入口と状態要約は残す。X/Yなど同一行の片側だけが該当する場合もパラメータ単位で省略し、数値欄幅を維持する。

受入確認は固定値変更/初期値復帰、初期値のキー/LFO/同期、無効・休止設定、初期値演出の追加、未変更項目の呼出、入力中の非消失、Undo/Redo、再生中の一覧安定、最小幅、欠損/ロック、プロジェクト内容不変を対象とする。
