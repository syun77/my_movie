# 演出チェーンのドラッグ表示

2026-11-19実装。対象は「追加演出」のチェーン一覧。ドラッグ中の項目を半透明で表示し、操作対象と移動先を見分けやすくする。

## 表示

元の場所と移動中の項目を両方見せる。

| 表示 | 動作 |
| --- | --- |
| 元の行 | 行全体を不透明度30%で残す。元位置と高さを保持する |
| ポインターに追従する行 | 不透明度85%。演出名・有効状態・ハンドルを表示し、通常のパネル色の背景と細い枠・控えめな影を付ける |
| 挿入位置 | 既存の黄色・2ptの線を維持し、追従行より手前へ描く |
| ほかの行 | 通常表示を維持する |

半透明の追従行を動かすことで、何をどこへ移しているかを示す。元の行だけを薄くして移動対象が見失われる状態を避ける。追従行の背景は文字が重なった際も名前を読めるものにする。無効な演出は無効の表記を保ち、有効化したように描かない。

行の一部分だけでなく、文字・チェック表示・選択背景・メニュー表示をまとめて同じ不透明度にする。表示上の不透明度はUI内だけに作用し、映像の演出値・クリップ不透明度は変更しない。

## 開始と追従

- ハンドル押下時はドラッグ待機。押下位置から5pt以上移動した時点でドラッグ表示へ切り替える。クリックだけでは半透明化・挿入線・仮変更を発生させない。
- 閾値は押下位置からの移動距離で判定する。横へ動かしても開始できるが、並べ替え方向は上下だけとする。
- 追従行の横位置と幅は元の行に揃え、縦位置は押下時の行内オフセットを保ってポインターへ追従する。行中央へ突然飛ばさない。
- 元行を含め、一覧の各行の位置は固定する。追従行と挿入線を動かし、既存の仮順序による映像プレビューを継続する。
- 他の演出を選択中でも、半透明化するのは掴んだノードIDの行とする。詳細パネルの選択は並べ替えで変えない。
- ドラッグ中は閉じた手のカーソルを使う。追従行は描画専用で、チェック・選択・メニュー等の操作を受け取らない。

## 領域外・確定・取消

追従行は一覧の表示領域でクリップし、インスペクターの別の設定へ重ねない。ポインターが有効なドロップ領域から出たら挿入線を消し、カーソルを操作不可にする。元行の薄い表示は維持し、戻ってきたら候補と仮プレビューを再計算する。領域外にいる間は最後の有効な仮順序の映像を保持する。

有効領域内で離したときは、最後のmouseUp位置から移動先を計算して1回確定する。元の位置なら変更なしとして扱う。領域外ドロップ、Esc、タブ/クリップ切替、編集不可への移行、終了準備では取消し、元の映像プレビューへ戻す。

確定・取消のどちらでも、追従行と挿入線を消し、元行を通常の濃さへ戻し、カーソルも通常状態へ戻す。取消後のmouseUpで変更を確定しない。既存のUndo1回・自動保存1回・再生位置維持を共有する。ドラッグ表示自体は保存・Undoの対象外。

## 実装方針

EffectChainListのドラッグ状態を、待機と実ドラッグに分ける。ノードID、開始点、行内オフセット、現在点、挿入先、有効領域内かどうかを一時状態として保持する。行描画を共通化し、通常行・薄い元行・追従行で同じ文字と状態を使う。開始時に選択や色を捏造した別の行を作らない。

描画順は「通常行と薄い元行 → 追従行 → 挿入線」。毎回ビュー全体を画像化せず、行描画と合成透明度を使う。モデルの順序・有効状態・ノードIDは表示処理から変更しない。ドラッグの取消処理を共通化し、一覧の再読込や編集終了でも表示が残らないようにする。

表示と入力はEffectChainList内で完結し、保存形式・レンダラーは変更しない。初期範囲はチェーン内の並べ替えだけで、タイムラインのクリップ・キーや数値欄のドラッグには適用しない。自動スクロールは別途検討する。

## 受入条件

1. 押下だけ/5pt未満では表示とモデルが変わらず、開始後は元行30%・追従行85%になる。
2. 未選択の行、選択中の行、無効な演出のいずれでも、掴んだ項目と有効状態を読める。
3. 先頭・末尾・隣接移動・元位置への復帰で、追従行と挿入線が正しい位置を示す。
4. 領域外への移動と復帰、最終mouseUp座標、Esc、タブ/クリップ切替、終了準備で表示と確定結果が一致する。
5. 長い名前、ライト/ダークモード、一覧の一部がスクロールで隠れた状態でも、文字と挿入線を識別できる。
6. 並べ替えはUndo/保存1回、取消/移動なし/待機クリックは0回。再生位置・演出の数値・選択は維持される。
