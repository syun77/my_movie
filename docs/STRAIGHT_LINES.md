# 直線効果線

作成日: 2026-11-18。実装日: 2026-11-19。ユーザーが承認した仕様に沿って独立した追加演出として実装。

## 外観と配置

画面内に平行な直線を散らし、それぞれの長さ・太さ・不透明度を変える。参考画像で確認できるのは、細い白〜青白い線、長短の混在、両端の柔らかな減衰。青い背景や斜めの模様はこの演出に含めず、透明背景の線として重ねる。

「画像・演出」→「追加演出」→「直線効果線」。画像・動画・Spine・空クリップへ1つ追加でき、クリップ区間内で表示する。素材の変形とは独立した画面座標を使う。空クリップで透過の線だけにする場合は既存の単色背景を無効にする。

## 設定

寸法と速度は1920×1080基準。基本欄に角度・本数・長さ・太さ・速度、詳細欄にばらつき・端・発光などを配置する。

| 項目 | 初期値 | 範囲・意味 |
| --- | --- | --- |
| 角度 | 0° | −180〜180°。0°は右、90°は下、−90°は上、±180°は左へ流れる |
| 表示本数 | 40本 | 0〜300本。生成候補の本数。画面端で切れたり重なったりするため、見える本数は前後する |
| 長さ | 80（10px） | 表示1〜384、実寸10〜3840px。ばらつき前の基準長 |
| 太さ | 2px | 0.5〜30px。ばらつき前の基準幅 |
| 移動速度 | 160（10px/秒） | 表示0〜800、実速度0〜8000px/秒。0で位置を停止し、逆方向は角度で指定 |
| 長さのばらつき | 65% | 0〜100%。各線の長さを基準の100%〜(100−設定値)%へ分散 |
| 太さのばらつき | 50% | 0〜100%。同様に分散するが最小0.5px |
| 不透明度のばらつき | 60% | 0〜100%。線の不透明度を100%〜(100−設定値)%へ分散 |
| 端のフェード | 15% | 0〜50%。各端で減衰する区間の線長に対する割合。0で平らな端 |
| 発光 | 25% | 0〜200%。線の周囲へ同色の淡いにじみを加える。0で芯のみ |
| 不透明度 | 80% | 0〜100% |
| 色 | 青白色（#DDEEFF） | RGB単色 |
| 配置を変更 | ボタン | 保存seedを更新して配置を再抽選。Undo対象 |

角度は線の向きと進行方向を兼ね、全線で共有する。角度のばらつきは初期仕様では設けず、平行を保つ。「出現本数」は毎秒の発生量ではなく、画面内の密度を決める本数とする。速度を変えても密度が変わらないため調整しやすい。

## 動きと決定性

参考画像から動きは判定できない。線は長軸方向へ一定速度で流れ、画面外から循環する。点滅による再抽選やフレームごとの位置変更は行わない。

画面を進行軸と垂直軸へ投影する。進行軸の範囲に最大線長と発光分の余白を加えた周期領域を取り、固定seed・線番号から位置・長さ・太さ・不透明度倍率を生成する。垂直軸は画面の投影範囲へ分布させる。進行軸の位置は初期位置に速度×時計を足し周期で折り返す。境界付近は周期コピーを描き、画面内にある線の端が折り返しで消えないようにする。

開始時から全候補を分布させ、線が徐々に溜まる待ち時間を設けない。固定の最大候補列から先頭N本を使い、本数変更で既存番号の乱数属性を変えない。再入場でも属性は維持する。

時計はクリップ相対時刻＋保存するphaseOffset。同一時刻はシーク順序に依存せず再現する。左トリムは位相へ開始差分を加え、手動キー時刻を減算する。右トリムは位相を変えない。

速度は既存演出と同じく、その時刻の評価値を時計へ乗算し、積分しない。速度や角度の自動化では線位置が移る場合がある。滑らかな加減速の積分と密度一定の粒子出生管理は初期仕様に含めない。

## 描画と編集

芯は一定幅で、長軸の両端に滑らかなアルファ減衰を付ける。輪郭は出力解像度に合わせてアンチエイリアスを使う。線単位の矩形をMetalインスタンス描画し、全画面を本数分ループしない。発光半径は1080pで太さ×3（最低2px）、発光設定は光量を変える。

芯は線形sRGBのpremultiplied source-over、にじみは線形RGBの加算。にじみの加算では中間面のアルファを増やさない。線ごとの不透明度倍率と演出・クリップ双方の不透明度を芯・にじみへ乗算する。RGB色は維持する。黒い線では発光しない。

所有段の素材と既存の集中線系の後、上段の素材と歌詞・スペクトラムの前へ描画する。素材の色調補正・ブラー・シェイク・自画像マスクの対象外。上段からの下向きマスクには対象段の一部として含む。人物の背後へ置く場合は、下段に線、上段に透過人物を置く。

全11数値は共通DragValueFieldを使い、直接入力・中ボタン初期化・方向固定ドラッグ・Shift微調整・仮プレビュー・mouseUp一括確定・Esc取消へ対応する。太さは0.5px刻み、他は整数で確定する。共通のキーと項目別音楽同期に対応し、本数は評価後に整数化する。色・seed・有効状態は固定設定。角度は通常の数値補間で、170°から−170°へは0°を経由する。短い回転はキーを分けて指定する。

## 保存・実装と受入条件

ImageEffects.straightLinesへ設定・seed・phaseOffsetを保存する。未追加はnil、有効切替は設定保持、削除はキー・音楽同期・表示範囲も削除する。既存の自動保存・Undo/Redo・コピーを共有し、コピーはseedを保持してキーIDを再発行する。ProjectFile version10へ保存し、設定未追加のファイルはnilとして読み込む。

StraightLines.swiftに決定的な属性・座標評価、EffectAutomationに数値定義、既存エディターにUI、Metal共通レンダラーに描画を持つ。放射状集中線とは設定モデルを分け、共通化は時計や線描画で実際に重複する部分に限る。

受入確認:

- 0/±45/±90/180°で平行と進行方向が正しく、縦横で太さ・速度の単位が一致する。
- 0/1/40/300本、速度0、最小幅、最大長、フェード0/50%、発光0、不透明度0を確認する。
- 同じ時刻の再シーク・保存再読込・コピー・左トリムで結果が再現する。
- 画面端の折り返し、斜め時の四隅、キー/音楽同期、本数変更を確認する。
- 通常合成・発光・上下段の遮蔽・マスク、プレビューとMP4を比較する。
- 最大本数を複数段で描画し、GPU時間・メモリ・細線のちらつきを測る。性能は未測定で、実装後に上限を再評価する。

検証はStraightLinesTestsで形状/時計/保存/トリム、キー/音楽同期、色パネル通知/再抽選/削除、Metal描画/縮小/マスク/発光、MP4の時刻と画素を確認する。描画例と性能値、最終アプリ生成はPROGRESS.mdへ記録する。

移動速度のインスペクターは10px/秒単位で表示・直接入力・ドラッグ・初期化を行う。表示1の増減は実速度10px/秒。保存値・オートメーションと音楽同期の数値はpx/秒で保持する。

長さのインスペクターも10px単位で表示・直接入力・ドラッグ・初期化を行う。表示1の増減は実寸10px。保存値・キー・音楽同期・描画はpxを保持する。
