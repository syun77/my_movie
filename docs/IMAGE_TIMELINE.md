# 画像レイヤーと配置モードの設計

自動アニメと位置・拡大縮小・回転の手動キーの仕様は [画像クリップのアニメーション設計](IMAGE_ANIMATION.md) を参照。

作成: 2026-11-09。実装済み（2026-11-09）。現在の単一画像と歌詞タイムラインを、最大3画像レイヤーと2つの配置モードへ拡張するための仕様。

## 1. 要件と今回の提案範囲

ユーザー指定の要件:

- タイムラインで画像レイヤーの配置を操作する。
- タブで「歌詞」「画像・演出」の配置モードを切り替える。
- 画像編集時、配置済み歌詞をタイムライン背面へ薄いゴーストとして表示する。
- 画像は最大3レイヤーとし、使用画像・開始時間・終了時間を指定する。
- ボタンに加え、「画像・演出」のタイムラインへの画像ファイルのドラッグ＆ドロップで読み込める。
- 読込済み画像を管理画面で削除・置き換えでき、元ファイルが存在しない画像も置き換えて復旧できる。

以下はこれを具体化した実装仕様。特に「3レイヤー」は、画像素材の総数ではなく、同時に重ねられる画像数の上限と解釈する。各レイヤーには時間順に複数の画像クリップを置ける。トランジェントに同期した拡大は画像クリップごとに設定する。

本設計は画像編集の実装仕様として、ARCHITECTURE.mdの広範な将来構想とTIMELINE.mdの未実装の汎用トラック構想より優先する。既存歌詞の保存・連結・描画仕様は維持し、tick時間モデル、NSDocumentへの移行は本機能の前提にしない。

## 2. 画面構成とタブ

最上段に音声選択と書き出し、左上に映像プレビューとBPM・拍開始の共通設定を配置する。右上の「歌詞」「画像・演出」タブは、右上の編集欄と下段のタイムラインの編集対象を切り替える。「スペクトラム」タブでは表示有無・形式・色・分解度・幅・高さ・XY座標・バー間の余白を編集し、下段は直前のタイムラインを表示する。

```text
音声を選択… / ファイル名                    MP4を書き出す
┌──────────────────────────┬──────────────────────────┐
│ 映像プレビュー             │ [歌詞] [画像・演出] [スペクトラム] │
│                          │ 画像の配置・削除・管理       │
│                          │ 時刻・レイヤー・拡大設定    │
│ BPM / 拍開始               │                          │
├──────────────────────────┴──────────────────────────┤
│ 再生 / 全曲シークバー / 現在時刻                           │
│ 表示範囲 / 曲全体                                      │
│ 時間目盛り                                             │
│ 画像3（最前面）                         [光.png────]   │
│ 画像2                  [人物.png──────────────]       │
│ 画像1（最背面） [背景A.jpg──────][背景B.jpg────────]      │
└─────────────────────────────────────────────────────┘
```

画像モードでは歌詞ゴーストを各画像行の背面に表示する。画像・歌詞の編集時刻はBPMに応じてスナップする。

| モード | 編集可能な対象 | 右上の編集欄 |
| --- | --- | --- |
| 歌詞 | 歌詞1トラック | 追加・削除、一覧、本文、開始/終了、連結、共通縁取り |
| 画像・演出 | 画像3/画像2/画像1の3段 | 画像配置・管理、選択画像、開始/終了、移動先レイヤー、変形・アニメーション |

レイヤー行は常に3段表示し、空行も残す。上段ほど映像の前面とする。レイヤー追加・削除・自由な並べ替えは設けず、クリップの所属レイヤーを変えて前後関係を調整する。選択行が分かるハイライトを付け、初期選択は画像1とする。

タブは編集対象の切替であり、映像の表示ON/OFFではない。各タブで完成映像全体をプレビューする。時刻、表示範囲、再生状態は共通とし、単純なタブ切替ではシーク/再生停止をしない。選択クリップはモードごとに保持する。

タブ切替前に入力を通常の終了処理へ渡す。日本語変換や不正な時刻が残り、正常に入力終了できない場合は切替を保留して理由を表示する。ドラッグ中の切替は仮編集を取り消してから行う。取消・入力終了を経たモデルから切り替え、仮モデルを別モードへ持ち越さない。

表示範囲は既存の2〜300秒・UserDefaults保存を両モードで共有する。最後に選んだ歌詞／画像・演出のタイムラインはアプリ共通UI設定として保存し、クリップ選択は保存しない。Space、Command+Space、入力中Esc、ドラッグ中Escの操作も両モード共通とする。

## 3. 歌詞ゴースト

「画像・演出」モードで、歌詞の開始/終了と短い本文を背面に描画する。表示区間は画像クリップと同じ時間座標を使用する。タイムライン内だけの補助表示であり、映像プレビューや書き出しにゴーストを追加しない。

- 歌詞区間を3画像行にまたがる薄い縦帯として描き、区間の左右を淡い点線で示す。
- 本文は目盛りと画像行の間の短い注記領域に1行表示し、長文は省略する。改行は空白として表示する。
- 初期の濃さは背景帯の不透明度10%、本文/境界25%を提案。画像ブロックは十分な不透明度で上描きし、選択枠と再生ヘッドを最も見やすくする。
- ゴーストはヒットテスト対象外。クリック/ドラッグしても歌詞を選択・変更しない。前面の画像を操作し、画像がなければ通常の空白シークになる。
- 歌詞がない場合は描画しない。選択や画像ドラッグによって歌詞を動かさない。
- 初期版では常時表示とし、濃さ調整やクリックによるタブ移動は追加しない。

描画順は「背景→時間/拍グリッド→歌詞ゴースト→画像クリップ→選択枠/ドラッグ表示→再生ヘッド」。画像のスナップは既存の16分音符グリッドのみとし、歌詞境界への別スナップは今回追加しない。ゴーストは視覚的な参照とする。

## 4. 画像クリップの配置・編集

| 項目 | 提案仕様 |
| --- | --- |
| 表示区間 | 音声の時間軸上の秒数Doubleで`[start, end)`。開始を含み終了を含まない |
| レイヤー数 | 固定3段。各段に任意数のクリップ。各時刻に1段あたり最大1枚 |
| 重なり | 同一段では禁止、異なる段では許可。隙間・終了と次の開始の一致は許可 |
| 最小長 | 既存歌詞と同じ1/30秒。スナップにより実際には配置可能な次のグリッド点以上 |
| 時間制限 | `0 <= start < end <= 音声長`。有限値のみ。音声読込前は配置操作を無効化 |
| スナップ | BPMの16分音符（15/BPM秒）、拍開始を原点。新規/時刻入力/ドラッグに共通適用。フレームへの再丸めなし |
| 本体移動 | 開始をスナップ、長さ維持。前後のクリップ/曲境界で制限。他クリップの飛越しなし |
| 左端/右端 | 対象端のみ調整。最小長、同じ段の隣接区間、曲境界で制限 |
| 他のクリップ | 移動・トリムで自動追従しない。画像には歌詞のpredecessorID/連結機能を持たせない |
| レイヤー間移動 | 本体を別行へ上下ドラッグ、または編集欄の移動先から変更。開始/終了・演出を保ち、移動先で重なる場合は全体を拒否。別行へのドラッグでは横方向のずれを時刻に反映しない |
| 画像の変更 | 選択クリップの素材参照だけ変更。時刻・レイヤー・演出を維持 |
| 配置を削除 | 選択クリップだけ削除。画像管理への登録、元素材ファイル、同じ画像を参照する別クリップは削除しない |

### 新規配置の手順

1. 配置したい行を選び、全曲シークバーまたは目盛りで時刻を合わせる。
2. 「＋画像を配置…」で読込済み画像を選ぶか、「ファイルから読み込む…」でPNG/JPEG/TIFFを選ぶ。読込とデコードが成功してから配置を確定する。選択取消/読込失敗はモデルを変えない。
3. 再生位置に最も近い、曲内のグリッド点を開始候補にする。候補が選択行の既存区間内に入る場合は追加を拒否し、空白への移動または別行選択を案内する。自動連結や別行への自動配置はしない。
4. 初期長は2秒。次クリップ開始/曲末までを上限とし、最小長を確保できるグリッド点から終了を選ぶ。点がなければ追加しない。
5. 選択/再生ヘッドを新規開始へ合わせ、一時停止してプレビューする。画像・時刻・演出を自動保存する。

### タイムラインへのドラッグ＆ドロップ

Finder等から画像ファイルを「画像・演出」の画像行へドロップして、読込と配置を一度に行える。ボタンと同じデコード・素材登録・区間検証・自動保存の処理を使う。

- ドロップ先の行をレイヤー、横座標を開始時刻として使う。現在の再生ヘッド位置や選択行には依存しない。
- ドラッグ進入時の表示範囲を固定し、受入可能な行と、16分音符へスナップした仮の開始/終了を表示する。確定前はプロジェクトを変更しない。
- 初期長2秒、隣接クリップ/曲末/最小長の制限はボタン配置と共通。衝突、配置可能なグリッド点なし、対応外ファイルでは禁止表示にし、ドロップしても既存配置を変更しない。
- 既存クリップの上へ落としても画像置換にはしない。配置候補がそのクリップと重なるなら拒否する。置換は編集欄または画像管理の明示操作から行う。
- 受け付けるのはローカル画像ファイルのURL。フォルダー、Web URL、画像データだけのペーストボード、動画は対象外。拡張子だけでなく実際に読める画像かを検証する。
- 初期版は1回1画像。複数ファイルは一括拒否し、「1枚ずつドロップしてください」と案内する。先頭だけを黙って読み込まない。
- 歌詞タブ、目盛り、行見出し、タイムライン外では配置を受け付けず、自動タブ切替もしない。歌詞ゴーストにはヒットせず、その位置の画像行へ配置する。
- ドラッグ中断や失敗では再生位置/配置を変えない。ドロップ受理時に一時停止し、非同期デコードと最新モデルの再検証が成功したら、素材登録とクリップ追加を一括確定・保存し、新規開始へシークする。
- 読込中のプロジェクト切替や編集で対象が変わった場合は、当初の座標/レイヤーと最新モデルで検証し直す。プロジェクトが別なら結果を破棄し、衝突なら全体を取り消す。素材だけを意図せず登録しない。

音声未読込、解析/書出し中、画像クリップのドラッグ編集中は外部ドロップを無効化する。複数画像の一括配置と複製は後続候補とする。既存クリップは本体の上下ドラッグで別段へ移動できる。

### 編集の確定

ドラッグ開始時に一時停止し、元モデル・座標・許容範囲を固定する。ドラッグ中は仮プレビューのみ、mouseUpで一括検証・自動保存。Escで取消。許容範囲にグリッド点がなければ元に戻し、理由を表示する。

本体を同じ行で動かす場合は従来の時刻移動、別行へ動かす場合は時間を維持したレイヤー移動とする。ドラッグ中は移動先行と仮配置を表示し、衝突時は赤い枠と禁止カーソルを表示して仮配置を元に戻す。範囲外や衝突先でmouseUpした場合は確定せず、Esc/タブ切替でも取り消す。端トリムで行をまたいでも所属段は変更しない。

数値の開始/終了は有効になるたびに反映する。画像では開始のみの変更は終了固定のトリムとする。長さ維持移動は本体ドラッグを使う。歌詞の「開始数値変更は長さ維持移動」とは独立したルールであり、歌詞用処理を流用しない。不正値は最後の有効モデルを保持し、入力欄のエラーを示す。

## 5. 映像への合成と演出

ブラー・ブルーム・光の粒子・舞い上がる火の粉の仕様は [画像クリップの追加演出](IMAGE_EFFECTS.md) を参照。

描画はMetal／Core Imageの共通レンダラーを使い、1920×1080/30fps出力とプレビューで同じ時刻評価を使う。

1. 現行の暗い背景色。
2. 画像1→画像2→画像3の順で、有効区間のクリップを通常のsource-overで合成。
3. 背景なしのスペクトラム。
4. 既存歌詞（常に画像より前面）。

画像はアスペクト比を保持して画面へ収めたサイズを基準とする。クリップごとの位置・拡大縮小・回転と、トランジェント・拍による自動拡大の仕様は [画像クリップのアニメーション設計](IMAGE_ANIMATION.md) を参照。PNG等のアルファを維持し、画像外の余白は塗りつぶさない。上段の不透明な画像は下段を隠す。画像のない区間は下段または共通背景が見える。全曲表示には画像1へ`0〜曲末`のクリップを配置する。


## 6. 保存モデルと素材管理

保存形式はProjectFile version 5。画像素材と配置は別に保存する。

| 型/フィールド | 内容 |
| --- | --- |
| ProjectFile | version、audio、settings、lyrics、imageAssets、imageLayers |
| SceneSettings | 共通BPM、beatOffset、スペクトラム設定 |
| ImageAsset | UUID、AssetReference。同じファイルを複数クリップから参照できる |
| ImageLayer | UUID、固定slot（1〜3）、開始順のclips。保存時は3段すべてを持つ |
| ImageClip | UUID、assetID、start、end、automaticAnimation、pulseAmount、fixedValues、curves、effects |
| PlacementEditorState | モードごとの選択ID/選択行、再生位置、仮ドラッグ。プロジェクトには保存しない |

ImageClip/LayersはCodable・Sendable・Equatableの値型とする。画像のCGImage、サムネイル、ドラッグ仮値、歌詞ゴーストは保存しない。画像クリップは1つのレイヤーだけが所有する。

素材参照は既存AssetReferenceの相対/絶対パス規則を使い、コピーしない。同じ正規化URLは1つの素材として再利用する。未配置の素材も画像管理に残し、保存/再読込で維持する。最後のクリップを消しても素材レコードを自動削除せず、画像管理の明示的な削除でだけ除去する。ファイル自体は変更しない。相対参照は従来どおり音声と同じフォルダだけに使う。

読込・保存・編集確定時に、3段/slotの一意性、全IDの一意性、素材参照の存在、同じ段の区間順と重なり、音声長、演出値の有限性と範囲を検証する。JSON読込時点で分かる構造検証と、音声解析後の区間検証を分ける。不正なプロジェクトは自動保存で上書きしない。

欠損画像は参照と区間を残し、タイムラインで警告、プレビューでその画像を省略する。画像管理の「置き換え…」で、その素材を使う全クリップをまとめて復旧できる。選択クリップの「画像を変更…」では、そのクリップのassetIDだけを差し替え、同じ素材を使う別クリップは変えない。有効区間に欠損/読込不能画像が残る場合は、書出し前に該当箇所を示して停止する。画像がゼロでも、音声があれば共通背景＋歌詞/スペクトラムを出力できる仕様とし、現在の「単一画像必須」ガードを除去する。

version 4は追加演出なしとして読み込み、保存時にversion 5へ更新する。それ以前の形式には「バックアップして新規作成」を使う。歌詞を含む旧データが引き継がれない点を案内し、旧プロジェクトを無断で上書きしない。

### 画像管理画面

「画像・演出」タブの「画像管理…」から、プロジェクト内の素材一覧をシートで開く。表示中は再生を一時停止し、タイムライン編集を止める。初期版は1素材ずつ選択・操作する。

```text
画像管理（このプロジェクト）
サムネイル   ファイル名       状態       使用数
[背景]       background.jpg  読込済み   2配置
[ ! ]        portrait.png    見つからない 3配置
[光]         light.png       未配置     0配置

選択画像: portrait.png
参照先: /…/portrait.png
使用箇所: 画像2 00:08–00:14 / 画像3 00:20–00:22 / …
[画像を読み込む…] [置き換え…] [画像を削除…]    [閉じる]
```

一覧はサムネイル、ファイル名、読込状態、使用数を持ち、選択時に参照先と使用レイヤー/区間を表示する。「未配置」は使用数ゼロの状態であり、ファイル欠損/読込不能とは別に表示できる。欠損画像も一覧から消さない。ファイル名は参照先から表示し、欠損時も記録済みパスを示す。

| 操作 | 対象と結果 |
| --- | --- |
| 画像を読み込む… | 対応画像を素材一覧へ登録。自動配置はせず、未配置のまま保存できる。同じファイルは既存素材を選択する |
| 置き換え… | 選択素材のファイル参照を置換。その素材を使う全クリップの見た目をまとめて更新し、配置時刻・所属段・演出は保持 |
| 画像を削除…（未使用） | 素材登録だけ除去。元ファイルは消さない |
| 画像を削除…（使用中） | 使用数/使用箇所を示して「配置も削除して画像を削除」を確認。確定時に該当クリップと素材を一括削除。取消では変更しない |
| 閉じる | 管理画面だけ閉じる。確定済みの操作はすでに自動保存済みで、閉じるまで保留しない |

「画像を削除」はプロジェクト内の登録を消す操作で、ディスク上の元ファイルを削除・移動しない。タイムラインの「配置を削除」と区別する。削除によって生じた空白は詰めず、残る画像や歌詞を移動しない。欠損素材も同じ削除手順で除去できる。

置き換え時は新ファイルを先に検証・デコードし、成功した場合だけ参照とキャッシュを更新して自動保存する。欠損状態でも同じ「置き換え…」を使い、新しいパスへ再接続する。ファイル名一致や同じフォルダーであることは求めず、異なる画像への変更も許可する。取消/読込失敗では古い参照・全配置を保持する。

通常の置換は素材UUIDを維持する。置換先がすでに登録済みの素材なら、対象素材を使うクリップのassetIDをその既存UUIDへ一括変更して素材を統合し、重複レコードを残さない。未配置素材同士でも同様。いずれも1つのモデル変更として検証・確定する。

素材単位の置換では、その素材のサムネイル/画像キャッシュを無効化して全使用箇所を更新する。古い非同期デコード結果を適用しないよう素材IDに加えて参照の世代も照合する。未使用の欠損素材は一覧で警告するが書出しを妨げず、配置済みの欠損画像がある場合だけ書出しを止める。書出し前エラーからも画像管理画面を開いて対象を選択できる。

## 7. 実装の分担と接続

| 対象 | 変更内容 |

汎用トラックプラグインや未使用のエフェクトenumは作らない。共有するのは時間座標・スナップ・ドラッグの仮状態/確定契約とし、歌詞の連結、画像の段移動と重なり検証はそれぞれのモデル操作が持つ。

画像ファイルはフレーム描画中に開かない。素材単位で共有デコードし、プレビュー用サムネイルと出力用画像を分ける。全素材を無制限にフル解像度展開せず、出力サイズ/拡大率を考慮したデコードとサイズ上限付きキャッシュを使う。読込世代/プロジェクトIDを確認し、別プロジェクトへ切り替えた後に古い非同期結果を適用しない。

書出し開始時に画像配置・設定・歌詞を固定し、使用素材の読込を検証する。処理中の編集は現行どおり無効化する。サムネイルの完成待ちでモデル保存を止めず、読込失敗は参照を保持したエラー状態として扱う。

## 8. 実装順と受け入れ確認

1. 画像モデル・区間操作・プロジェクトの保存/復元を作成し、同一段/別段の重なりと素材参照を検証。
2. 共通レンダラーと出力を3段へ対応させ、固定配置データで1080pの実動画を検証。
3. 配置エディターへ共通時間軸と2タブを導入し、既存歌詞編集の回帰確認。
4. ボタン/外部ドロップによる画像追加、選択/数値編集/配置削除、3行のドラッグと所属段変更を接続。
5. 画像管理の未配置登録/削除/全配置置換/欠損復旧、歌詞ゴースト、表示モード保存、非同期素材読込を仕上げる。
6. 責務・重複・命名・旧単一画像経路を整理して再検証し、build-app.shでappを生成する。

| 検証対象 | 受け入れ条件 |
| --- | --- |
| 合成順 | 透過画像/不透明画像を3段に重ね、画像3が最前面、歌詞がさらに前面。境界時刻の二重表示なし |
| 複数画像 | 同一段でA→Bへ切替可能。別段の同時表示は可能、同一段の重なりは拒否。4段目は作れない |
| 編集 | 追加・両端トリム・長さ維持移動・段移動・曲頭/曲末・最小長を検証。他の画像や歌詞は動かない |
| スナップ | 非整数BPM/非ゼロ拍開始、異なるズームで同じ結果。移動の長さ保持、許容点なしの取消 |
| 読込/ドロップ | ボタンとドロップで同じ検証結果。ドロップ行/横座標/16分音符が一致。衝突/複数ファイル/形式不正/取消/曲切替では部分登録なし |
| 画像管理 | 未配置素材を保存/復元。最後の配置削除で素材が残る。使用中削除は確認後のみ全配置を除去し、元ファイルと他素材/歌詞を維持 |
| 置換/復旧 | 素材置換は全使用箇所、クリップ差替は選択箇所だけ更新。欠損から復旧、登録済み置換先への統合、失敗時保持、古い非同期結果の破棄を検証 |
| ゴースト | 歌詞と画像の時間座標が一致。クリックを奪わず、映像/出力へ混入しない |
| モード切替 | 時刻/表示範囲/再生状態を維持。選択はモード別。IME、不正入力、ドラッグ中の切替でデータ消失なし |
| 保存 | 曲を開き直して素材/区間/演出/段が一致。UIモードと表示範囲はアプリ設定から復元 |
| 障害 | 欠損素材の区間を維持し差替可能。欠損がある出力を停止。読込/保存失敗やプロジェクト切替で別データを上書きしない |
| 出力 | 1920×1080/30fps、音声/長さ、画像の開始前/開始/終了、透過/重なり、歌詞/スペクトラムを実MP4再読込で検証 |

上記を実装済み。フェード、独立演出トラック、歌詞境界スナップは後続の機能として扱う。

画像の確定編集は共通EditHistoryへ登録する。素材登録と配置、素材削除と関連配置削除、素材置換は一括でUndo/Redoする。復元時は管理画面/欠損状態/プレビューを再取得し、自動保存する。非同期読込中のUndo/Redoは禁止する。

表示範囲は固定2〜300秒または「曲全体」を選択可能。「曲全体」は5分を超える曲にも対応し、曲切替時も曲長に追従する。固定範囲と切替状態をUserDefaultsへ保存し、表示幅に合わせて目盛り間隔を調整する。
