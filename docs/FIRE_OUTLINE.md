# 炎アウトライン

2026-11-20実装。指定作品を参考にした、矩形四辺の内向き炎を生成する追加演出。10数値・透明加算・可変矩形・共通自動化に対応する。

## 参照と再現範囲

[Dogrtt / Inner outline test](https://www.shadertoy.com/view/3lfGR7)（2019-04-21）。ブラウザーでImageパスの実行コードを確認した。作者はremonvvの作品を基にしたことも明記している。

元作品は素材のアルファ輪郭を抽出せず、四辺に沿うノイズ状の光を画面内側へ描く。入力テクスチャは実行部分では参照しない。紫〜青紫の炎を基準とし、人物や文字のシルエットへ炎を付ける機能は別設計になる。

四辺に沿う紫系の炎という見た目を参考に、ノイズ生成・色生成・合成を独自実装した。原作コードの転用条件は取得できておらず、原文コード・デモ素材は転用も同梱もしない。初期設定は画面全体を囲い、背景は透明。原作のノイズ定数やパレット式の直接移植ではなく、ピクセル一致を保証しない。

## チェーンへの配置

「ぼかし・発光」に「炎アウトライン」を追加する。`EffectKind.fireOutline`、`EffectPayload.fireOutline(ImageEffects.FireOutline)`で保持する。同種1つという既存の追加制約を使い、既存の保存済み整数rawValueを変えないようEffectKindの末尾に追加する。

任意位置へ挿入する生成ノード。画像・動画・Spine・空クリップで同じ結果を生成し、直前の面へ光を加える。他レイヤー、歌詞、スペクトラムを入力に使わない。素材なしでも枠が表示される。

- `炎アウトライン → ブラー` は炎もぼける。
- `炎アウトライン → 色調補正` は炎の色も変化する。
- `炎アウトライン → このクリップのマスク` は炎を切り抜く。逆順なら炎は切り抜かれない。
- 後段のシェイク・拡大ループは炎を含めて動かす。基本素材の位置・回転・拡縮には追従しない。
- クリップ出力の不透明度と段間マスクは完成結果へ適用する。レイヤーのUUIDや段数を生成処理へ渡さず、可変レイヤー方式を共有する。

## 設定パネル

| 項目 | 範囲 | 初期値 | 意味 |
| --- | --- | --- | --- |
| 中心X | −1920〜3840px | 960px | 1080p左上原点 |
| 中心Y | −1080〜2160px | 540px | 下方向が正 |
| 幅 | 1〜7680px | 1920px | 炎の矩形枠の横寸法 |
| 高さ | 1〜4320px | 1080px | 炎の矩形枠の縦寸法 |
| 炎の広がり | 0〜400% | 100% | 辺から内側へ届く距離の倍率 |
| 模様の細かさ | 25〜400% | 100% | 辺に沿ったノイズ密度 |
| 速度 | 0〜400% | 100% | 炎の時間倍率 |
| 明るさ | 0〜200% | 100% | 線形RGBのゲイン |
| 不透明度 | 0〜100% | 100% | この演出の光量倍率 |
| 色相 | −180〜180° | 0° | 元の紫系パレットからの色相回転 |

全10数値をDragValueField・手動キー・項目別音楽同期へ接続する。位置/寸法/色相は1単位、他は1%単位を基本とする。ダブルクリック直接入力、主方向固定ドラッグ、Shift微調整、中クリック初期化、仮更新、mouseUpで1回確定、Esc取消を共通化する。追加時はキーと音楽同期なし。

中心XYはPreviewPositionPairへ登録し、既存のプレビューハンドルから動かせるようにする。基準値変更は全キーと表示範囲を同じ差分だけ移動する既存経路を使う。サイズ専用ハンドル、角丸、辺ごとのON/OFF、外向き炎、素材輪郭モードは初期版に含めない。

ノードOFF、チェーンバイパス、不透明度0、明るさ0、広がり0は追加光なし。入力をそのまま通す。加算演出の「不透明度」は遮蔽率ではなく光量として扱う。幅/高さは0を許可せず、評価・入力・保存検証で共通範囲を使用する。

## 座標と炎の評価

矩形は映像の左上原点、1080p基準で定義する。矩形内の点を左右・上下の各辺からの内向き距離と辺に沿う座標へ変換し、4辺を評価する。矩形外は透明、境界は最終描画解像度で約1pxの被覆AAを付ける。炎の裾は滑らかに減衰させ、矩形の外側へ光を生成しない。後段のブルーム等による外側へのにじみは許可する。

初期矩形での見た目を参照に合わせるため、炎の広がり100%では横辺は矩形高さ、縦辺は矩形幅を基準にした元作品の正規化距離を使う。矩形を変形すると炎も伸縮する仕様。辺を少し枠外へ置く元作品の見え方も基準へ取り込む。細かさはノイズ座標に適用し、広がりの距離倍率から分離する。四隅は両辺の寄与を評価し、辺を選ぶ方式による不連続を作らない。

固定整数ハッシュと滑らかな値ノイズを使い、3段のfBmでノイズ座標を歪ませる。辺からの距離とノイズによる4乗減衰で炎の奥行きを作り、裾は滑らかに0へ落とす。紫系のHSVパレットを光量に応じて変化させる。上・右・下・左の順で色を光量重み付き補間し、演出内の最終色とする。四隅を無条件の4色加算へ変えず、初期状態の角だけが白く飛ぶことを避ける。辺の評価順は固定し、シークやレイヤー順から独立させる。

除算の分母へ下限を設け、色の負成分は光量化前に0へ制限する。パレット生成・内部混合に使う重みは有限の0〜1へ収め、powの入力は非負とする。無効値を黒へ隠すだけにせず、モデル検証とGPUの両方で非有限値の発生を防ぐ。広がりの除算下限は0.000001。色と重みは0〜1で評価してから線形光へ変換する。

元の見た目を基準とする色計算結果は表示用sRGBとして扱い、色相回転後に線形RGBへ変換する。明るさ・不透明度は線形光量へ乗算する。sRGBをそのまま線形中間面へ加えない。最終出力色変換とディザは既存共通工程を使う。

## 合成とMetal実装

`Scene.metal`へ専用fragment、Swift側へ対応uniformとパイプラインを追加する。フルスクリーンquadの1パスで生成し、入力テクスチャや前フレーム、フィードバックバッファは不要。初期版で輪郭抽出用のSobel・距離場・CPU画像生成は導入しない。

既存`MetalSceneRenderer.drawGenerated`から生成面へ描画し、`process`の生成演出経路でcurrentへマージする。生成面は透明でクリアし、出力は`RGB=炎の線形光量 × 明るさ × 不透明度`、`alpha=0`。加算パイプラインでRGBを蓄積し、入力coverageを増やさない。黒い矩形面や透明素材の縁が現れないことを確認する。クリップ共通不透明度はここで二重に掛けず、チェーン完成後に一度だけ適用する。

生成面は画面座標の向き、中間面はCore Imageの向きという既存契約に従い、マージ時の反転を共有する。上下非対称の固定時刻の画像で確認する。後段の色補正・2値化・発光抽出は既存のalpha0 RGB対応を利用する。

矩形の画面外部分は自然にクリップする。後段加工のpaddingを含む中間面の原点と、映像枠の原点を混同しない。新たな常駐フルサイズ面をノードごとに持たず、既存generatorScratchを再利用する。明るさ/不透明度/広がり0および画面と矩形が交差しない場合は生成を省略する。

## 時計・編集・保存

`localTime = 曲時刻 − clip.start`、`t = (localTime + phaseOffset) × speed / 100`を使用する。GPUへ渡す時刻は既存の生成演出と同じく100000秒の剰余で有限範囲へ収める（その境界で模様が切り替わる）。速度0はt=0で静止。壁時計、iFrame、再生順、可変乱数へ依存しない。ノイズの定数は固定し、初期版にseed再抽選は設けない。

左トリムでは開始位置の差をphaseOffsetへ加え、キー時刻は同じ差を減らす。固定曲時刻における模様を保持する。通常移動・コピー・順序変更・OFF/ONではphaseOffsetをリセットしない。速度は共通演出と同じ時刻乗算で、積分しない。速度キーや同期を急変させると位相が跳ぶ仕様。

FireOutlineは有効状態、10数値、phaseOffsetを保持する。実体はEffectNode.payloadのみ。キー・同期・表示範囲は同じノードIDに属し、種類別プロパティは既存どおり投影にする。モデル範囲・既定値・キーパスはFireOutline.fieldsに集約し、EffectAutomationと保存検証で共有する。

保存は現行v16、読込v13〜16。既存の任意演出payload形式を使用し、versionは変更しない。v13〜15からの変換で炎を自動追加しない。旧版を名乗るデータにfireOutlineが混入している場合はv14→15変換境界で拒否する。新payloadを知らない旧アプリはenumのデコードで拒否する。

追加・削除・有効切替・色相などの確定編集は既存の自動保存とUndo/Redoを共有する。複製はノード/キーIDを再発行する。削除時はノードの自動化・同期・範囲も除去する。キャッシュには評価済み全設定・時計・ノード順・解像度を反映する。

## 実装構成

1. ImageEffects/EffectChainへ型・検証・payload・種類別投影・トリム位相を追加する。EffectKindの全switchとProjectMigratorの未知項目判定を更新する。
2. ImageAnimation/EffectAutomationへ10項目と範囲・既定値・評価を追加し、ノードID単位のキー・同期を接続する。
3. Scene.metal/MetalSceneRendererに生成・線形加算・スキップ判定を追加し、初期値を参照の見え方へ調整する。
4. EffectCategory/ImageEffectsEditorへメニューと設定を追加する。PreviewPositionPairへ中心XYを登録する。ClipClipboard、履歴、保存の共通経路が新payloadを網羅することを確認する。
5. FireOutlineTestsを追加し、関連ドキュメントの種類数・一覧・追加方法を更新する。責務/重複/uniformの配置を整理して検証し、最終コードでbuild-app.shを実行する。

## 受入条件

- 初期値で四辺から内側へ紫系の炎が動き、中央と枠外は黒塗りされない。任意のPNGの外周へ勝手に追従しない。
- 空クリップ、半透明PNG、動画、Spine、黒/白/市松背景で同じ枠になり、coverageを増やさない。後段の色調補正とブラーに光が残る。
- XY、幅/高さ、広がり、細かさ、速度0、明るさ0、不透明度0、色相±180°、画面外、極小/極大矩形を検証する。四隅の継ぎ目、反転、縦横比、NaN/Infがない。
- 全10項目のキー/音楽同期、数値操作、XYハンドルの取消と1回確定、コピー、Undo/Redo、保存往復、無効化とバイパスを確認する。
- 左トリム前後の固定曲時刻の画像が一致し、前後シークでも同時刻が一致する。速度変更時の位相ジャンプは仕様どおりとする。
- 既存のv13〜16 fixtureにノードを混入させず読め、新payloadを含む不正値・重複ID・未知形式は拒否し原本を上書きしない。
- プレビューとMP4で固定時刻の枠・色・マスク結果を比較する。比較は出力色空間を揃え、H.264の圧縮誤差を許容する。
- 1080pで1/3レイヤーと、実装済み可変レイヤー上限でメモリ/GPU時間を測る。受入目標は対象Macで通常3レイヤーの総フレーム時間33.3ms以内。上限付近は別途計測し、未測定の実時間性能を保証しない。

最終コードで`./scripts/build-app.sh`を実行して`dist/MV Studio.app`へ反映する。検証結果はPROGRESS.mdに記録する。50レイヤーは実測で約300msのGPU時間となり、最大段数での実時間再生は保証しない。
