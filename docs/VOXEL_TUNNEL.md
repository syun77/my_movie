# Voxelトンネルの組み込み設計

作成日: 2026-11-19。設計提案であり、未実装。ユーザーの確定要件は [Shadertoy MscBRs](https://www.shadertoy.com/view/MscBRs) を組み込むための設計。以下の操作項目・値・実装順は提案とする。

## 参照作品と確認範囲

参照作品は lsdlive の「Outline #1: Voxel tunnel」（2018-05-14）。2026-11-19に公式ページのImageパスと説明・コードをブラウザーで確認した。Web取得APIでは取得できた本文がなく、ブラウザーで補完した。Imageパスで参照する入力は時刻と解像度で、外部画像・音声・前フレームバッファは必要としない。

見た目は、立方体単位の壁を持つ曲がった通路を進み、面の明暗、色の帯、霧、ボクセル状の光を重ねるもの。前方の八面体も含む。通常の連続距離によるレイマーチと区別し、セル境界を追うDDAを核に移植する。光による半透明に見える表現と、クリップの実際のアルファは別のものとして扱う。

原文コメントにCC-BY-NC-SAの記載がある。版番号、依存する先行作品の利用条件、商用アプリへの同梱可否は未確認。原文はfb39ca4の [4dX3zl](https://www.shadertoy.com/view/4dX3zl)、Shaneの [MdVSDh](https://www.shadertoy.com/view/MdVSDh) を参照している。実装着手時に原作・依存元の条件を確認し、必要な許諾と同梱するクレジットを確定する。確認前にコードを配布物へ取り込まない。別実装を選ぶ場合も、その方針と再現範囲を改めて決める。

## 組み込み位置と操作

「追加演出 → 動き・抽象映像 → Voxelトンネル」を追加する。`EffectKind.voxelTunnel` と専用payloadを持つ生成ノードにし、種類は1クリップ1つまで。既存のワープ航行とは独立した項目にする。

基本の用途は、空クリップに追加して背景の段へ置き、その上に画像・動画・Spineを配置すること。素材付きクリップにも追加できる。その場合はチェーンのその位置で手前へ通常合成し、不透明度100%では前段を覆う。前段を背景として透かすのはノードの不透明度で指定する。前段画像を壁に貼る、前段をトンネル状に変形する処理は初期対象外。

経路は「素材・基本変形 → ノード順の生成/加工 → クリップ不透明度 → 段間マスクと合成 → スペクトラム・歌詞」。位置・拡縮・回転の基本変形は生成するトンネルを動かさない。後段のシェイク、色調補正、ブルーム、マスクはトンネルにも作用する。前段の加工は後から生成する映像に作用しない。有効OFF・全体バイパスは完全通過で、設定・時計・キーを保持する。

## 初期の編集項目

| 項目 | 初期値 | 範囲 | 意味 |
| --- | --- | --- | --- |
| 速度 | 100% | 0〜400% | 原作の共通時計への倍率。前進・色帯・八面体をまとめて変える |
| 拡大率 | 100% | 25〜400% | 中央を基準とする視線平面の倍率。セルの大きさは変えない |
| 発光 | 100% | 0〜200% | セル走査で蓄積する光の倍率 |
| 明るさ | 100% | 0〜200% | 生成したRGB全体の倍率 |
| 不透明度 | 100% | 0〜100% | 生成面の通常合成率 |

全数値を既存DragValueFieldで編集し、ダブルクリック入力・中ボタン初期化・左右/上下ドラッグ・Shift低感度・Esc取消を共有する。ドラッグ中は仮描画、mouseUpで1回保存/Undo。各項目はノードID＋ImageParameterの共通キー・音楽同期・表示範囲に対応する。

速度は既存生成演出と同じ「時刻×現在の倍率」とする。速度を自動化すると進行位置が跳ぶ場合があるため、ラベルのヘルプで示す。速度の積分は初期版に追加しない。拍・トランジェントで滑らかな反応を付けたい用途には発光・明るさ・拡大率を使う。色・道幅・セルサイズ・任意カメラ・八面体ON/OFF・シード再抽選は初期対象外。最初は原作の構図を安定して再現する。

## モデル・時計・保存

`ImageEffects.VoxelTunnel` に有効状態、5数値、`phaseOffset`を保存し、`EffectPayload.voxelTunnel`をノードの唯一の実体とする。種類別プロパティは既存の投影APIに合わせる。全値の有限性・範囲を保存/読込時に検証する。未知の種類や不正値を黙って削除して保存しない。

時計は `localTime = sceneTime - clip.start`、`effectTime = (localTime + phaseOffset) * speed / 100`。壁・カメラ・八面体・色帯の全式へ同じeffectTimeを渡す。前フレームの積算・壁時計・フレーム数・実行順・乱数には依存させない。左トリムの差ΔはphaseOffsetへ加算し、キー時刻からΔを引く。これで同じ曲時刻の固定速度で外観を維持する。コピー/複製は時計と設定を保持し、ノード/キーIDだけ再発行する。並べ替え・無効化でphaseOffsetをリセットしない。

調査時点の作業ツリーは保存v14、読込v11〜14（可変レイヤー実装中）。新payloadを旧アプリが読めないため、単独で次版となるならv15保存・v12〜15読込へ更新する。v14→15は既存ノードを保持し、トンネルを自動追加しない。実装時に他機能の版更新と再調整し、currentVersion・移行器の未知キー検査・固定fixture・境界テスト・説明文書を同時更新する。読込成功/曲長検証後のバックアップとatomic保存は既存ProjectStorageに任せる。

## Metal描画

専用 `Shaders/VoxelTunnel.metal` と `VoxelTunnelRenderer.swift` を提案する。共通ライブラリへの読込は現在のシェーダー結合方法を確認して追加し、SwiftPMリソースとbuild-app.shのbundleコピー対象を確認する。任意GLSLの実行環境やWebViewは導入しない。

1. 出力の論理画面座標からアスペクト比補正した視線を作り、曲線の経路と前方注視点からカメラを評価する。GLSLの行列積の向き・列優先とMSLの対応を明示して移植する。
2. セル中心から距離場を評価し、DDAで次の境界へ進む。原作と同程度の100回を固定上限とし、整数ループで回数を確定する。
3. 面方向から基本色を求め、走査中の光、色帯、距離による霧を組み合わせる。ループを抜けた時のヒット有無・面方向を明示する。
4. 見た目を比較して確定した色変換後、premultipliedの線形RGBとして共通生成scratchへ描き、既存の上下反転mergeでチェーンへ接続する。

原作は発光用変数を距離関数から更新する。MSLではピクセルごとのローカル累積値として明示的に返すかthread参照を使い、共有globalにしない。初回セルでのヒットに備えて面方向を初期化する。ゼロ方向成分、同距離の境界、カメラが境界上にある場合もNaN/InfがRGBへ伝播しないDDAにする。ゼロ軸は有限の大きな境界距離で表し、0×Infを作らない。八面体中心のゼロベクトル正規化も有限な評価に置き換える。変更が外観に及ぼす差を比較する。

ヒットしない場合も霧/蓄積光から背景色を返し、未初期化値を使わない。原作の出力に負のRGBが生じる領域は生成色の段階で0以上へ整理する。1超の光量は後段発光へ保持する。原作には明示的な色空間宣言がないため、原作基準画像と比較し表示RGBから線形への変換位置を決め、専用関数へ固定する。最終sRGB/Rec.709変換を二重に行わない。

不透明度aで生成色Cを `(C*a, a)` として通常合成し、後からクリップ共通不透明度を1回適用する。黒い領域も背景の一部として被覆する。光をalpha0の独立加算成分へ分離する仕様は初期版に持ち込まない。

## 解像度・キャッシュ・性能

視線の座標系は余白を除いた映像枠。ブラー等のpaddingでトンネルの中心や画角を変えない。標準はプレビューの実描画サイズ、動画は1920×1080/30fps。プレビューと出力でアルゴリズムや走査上限を変えず、同じ解像度・時刻なら同じ結果を返す。

前フレーム依存バッファやCPUへの読み戻しは不要。共通generatorScratchを順次再利用し、各ノードへフルサイズ面を常駐させない。有効ノードを`needsClock`へ登録し、PreviewFrameReuseと処理済み面のキーに時刻・5評価値・phaseOffset・解像度・チェーン順を反映する。速度0でも他項目に自動化があれば再評価を省かない。無効/不透明度0では走査を省略する。

1080p・100ステップは1面あたり最大約2.07億セル評価/フレームになる。1段/3段と可変段の上限、後段ブルーム併用でGPU時間p50/p95/最大・ピークメモリ・5分出力を計測する。プレビュー全体の33.3ms以内は目標であり未保証。低負荷表示を追加するなら明示的なプレビュー解像度設定とし、セルサイズ/ステップ数や出力画質を自動で変えない。出力は全フレームのGPU完了を待ち、既存キャンセル処理を共有する。

## 受入条件

- 初期設定で原作の構図・ボクセル壁・発光・色帯・霧・前方物体が確認できる。0/1/5/30秒の同解像度画像を比較し、数値安定化による差も記録する。
- 空クリップ/画像/動画/Spineで追加でき、ノード前後のブラー/色補正/マスクで正しい順序差が出る。下段・上段・歌詞・スペクトラムとの合成も確認する。
- ノード不透明度0/50/100%、明るさ0、発光0、速度0、拡大率両端でアルファと表示が定義どおり。無効と全体バイパスは完全通過。
- ランダム順シーク/再生/保存復元/MP4の同時刻が一致する。左トリム、移動、並べ替え、コピー、Undo/Redoで時計と参照を保持する。
- 全数値のキー/拍/トランジェント、入力/ドラッグ/中ボタン/Esc、自動保存1回を既存操作経路で検証する。
- 境界・軸方向・初回ヒット・未ヒット・長時間・全範囲でNaN/Inf、上下反転、色変換の二重適用がない。
- 対応4世代の読込/移行、未知ノード拒否、破損/外部変更/保存失敗時の原本保持、コピーID再発行を検証する。
- 1080p MP4を再デコードして向き・色・時刻を許容圧縮差内で比較し、複数段負荷と出力キャンセルを実測する。
