# グラデーション背景

2026-11-21実装。2色、変化の偏りカーブ、位置、A→B→A、角度、直線と円形への対応がユーザー要件。以下は実装仕様とする。

## 使い方と構成

「追加演出 → 背景・図形・マスク → グラデーション背景」で選択クリップへ追加する。空クリップでも生成でき、画像・動画・Spineの素材は不要。同種は1ノードまでとし、単色背景とは別のノードとして共存できる。新しい空クリップの既定演出を自動変更しない。

形状と色の並びは独立して選ぶ。

| 形状 | A→B | A→B→A（中央に色B） |
| --- | --- | --- |
| 直線 | 指定方向へ色Aから色Bへ変化 | 指定位置を中心に色Bの帯、両側は色A |
| 円形 | 中心から外側へ色Aから色Bへ変化 | 指定半径のリングが色B、内外は色A |

円形の中心だけを色Bにする場合はA→Bのまま色A/Bを交換する。円形のA→B→Aを中心スポットと解釈せず、半径方向で往復するリングとする。色交換ボタンは色だけを交換し、幾何・カーブ・キーを変更しない。

## 編集項目

座標と距離は1920×1080基準。解像度が変わっても出力倍率で一様に拡大し、円が楕円にならないようにする。

| 項目 | 初期値 | 範囲・意味 |
| --- | --- | --- |
| 色A / 色B | 黒 / 白 | 不透明sRGB色、色選択と交換ボタン |
| 形状 | 直線 | 直線 / 円形 |
| 色の並び | A→B | A→B / A→B→A |
| 中心X / Y | 960 / 540px | −7680〜7680px、左上原点・下向きY |
| 位置 | 0px | −7680〜7680px、直線は中心から進行方向への変位、円形は中心からの半径方向の変位 |
| 変化幅 | 1920px | 1〜15360px、色変化の区間全幅 |
| 角度 | 0° | −3600〜3600°、0°右、90°下、正方向は時計回り |
| 偏り | 0% | −100〜100%、0は等速、正はBへの変化が遅く、負は早い |
| 不透明度 | 100% | 0〜100%、背景面だけへ適用 |

角度は直線のみ表示・操作する。円形へ切替えても角度の値と自動化は保持するが描画には使わない。中心X/Yは既存XYプレビューハンドルに対応させる。位置は中心そのものとは分け、直線では帯の移動、円形ではリングの拡張・収縮に使う。

形状・並び切替で数値を自動変換しない。位置0・円形・A→Bでは、中心は区間中央の混合色となる。中心を純色Aにして外へ変化させたい場合は位置を変化幅/2にする。UIに「中心から外へ」ボタンを設け、位置の基準値を現在の幅/2へ移動する1回の編集として扱う。既存キーがある場合は共通の基準値移動規則を使い、全時刻の中心純色を保証するボタンとはしない。

## 空間カーブと評価

偏りカーブは「空間上の距離から色Bの割合への対応」であり、時間方向のオートメーション補間とは別物。横軸に変化区間0〜100%、縦軸に色Bの割合0〜100%を表示する小さなグラフと、対応するグラデーション見本をインスペクターへ置く。初期版は偏り1項目で連続した単調カーブを調整する。任意個数の制御点、色停止点の追加、繰り返しタイルは初期版の対象外。

画素位置p、中心c、位置o、幅w、角度θに対して、距離dを次で求める。座標はすべて1080p基準へ変換済みとする。

- 直線: `d = dot(p-c, (cosθ, sinθ))`
- 円形: `d = length(p-c)`
- 共通: `u = clamp((d-o)/w + 0.5, 0, 1)`

偏りbを−1〜1へ正規化し、`k = 2^(4b)`、`F(x) = x^k` とする。b=0ではF(x)=x、正ではBが遅く現れ、負では早く現れる。端点は必ずF(0)=0、F(1)=1とする。

- A→B: 色Bの混合率 `t = F(u)`。
- A→B→A: `t = F(1-abs(2u-1))`。

A→Bでは区間より手前はA、後ろはB。A→B→Aでは両外側はA、中央は必ずB。往復の両側は対称で、偏りを変えても色Bの中心位置は移動しない。正の偏りで色Bの帯/リングが細く、負で広くなる。位置と幅はカーブとは独立している。A→B→Aの変化幅は往復全体であり、片道の幅ではない。

円形ではd≥0のため、設定した変化区間の一部が中心より内側へ入ることがある。位置を負にするアニメーションも許可し、画面外中心・画面外リングを含め、見える部分だけを描く。中心や位置を描画時に勝手に画面内へ丸めない。

## UIと自動化

```text
グラデーション背景                 [有効 ✓]
色A [■]       [A/B交換]      色B [■]
形状          [直線 ▾]
色の並び      [A→B→A ▾]
中心X [960 px]      中心Y [540 px]
位置  [0 px]        変化幅 [192（10px）]
角度  [0°]          不透明度 [100%]
偏り  [0%]          [カーブと色見本]
```

全数値は共通DragValueFieldを利用する。ダブルクリック入力、方向ドラッグ、Shift微調整、中ボタン初期化、ドラッグ中の仮反映、mouseUpで1回確定、Esc取消に対応する。非有限値や直接入力の範囲外は確定しない。色選択の連続変更はカラーパネルを開いてから閉じるまでのセッションIDで履歴へまとめる。他の編集が間に入った場合は別操作として分ける。

中心X/Y、位置、変化幅、角度、偏り、不透明度の7項目はノード単位の手動キー・音楽同期に対応する。共通ParameterEvaluatorで手動値→音楽同期→物理範囲の順に評価する。角度のキーは数値を連続補間し、0〜360°へ保存時に丸めない。色・形状・並びは初期版では固定設定とする。

時間変化はキー/音楽同期だけで与え、独立した速度や内部時計は追加しない。クリップ移動・トリム・コピー・複製は既存ノードの規則を共有し、同じ曲時刻のプレビュー・シーク・出力を一致させる。

## 合成と実装責務

単色背景と同じく、チェーンのその位置にある前段面の背後へ、画面座標のグラデーション面を敷く。素材の移動・拡縮・回転には追従しない。後段の色調補正・ブラー・ブルーム・マスクは合成済みの面へ作用する。歌詞・スペクトラムは既存の前景描画を維持する。

合成は `前段 over グラデーション`。透明素材の周囲に背景が見え、不透明素材の裏は見えない。単色背景が先に有効だとその不透明面がグラデーションを隠すため、追加時に既存背景を自動で削除せず、両方が有効なら「前段の不透明な背景に隠れる場合があります」と表示する。追加位置・並び替えも既存チェーンの経路を使う。

色A/BはsRGBとして保存し、線形sRGBへ変換後に混合する。背景不透明度でpremultiplied RGBAを作り、前段のalpha0加算光も保持して合成する。クリップ全体の不透明度は既存の最終合成時に1回適用する。背景不透明度0は完全な無作用。透明領域を黒で置き換えない。

`GradientBackground`の値型へ設定・数値定義・検証を集約し、EffectPayloadへ専用payloadを追加する。曲線や音楽同期はEffectNodeの既存ストレージを使い、別の時間評価器を作らない。専用Metalフラグメントで画素ごとに距離とカーブを評価し、前段面と合成する。全画面の中間面方向、padding、色空間は既存チェーンに揃える。生成範囲は映像矩形とし、後段フィルター用の余白は透明にする。

変更対象はEffectChain、EffectCategory、ImageEffects、ImageEffectsEditor、EffectAutomation/ImageParameter、PreviewPositionPair、MetalSceneRenderer/Scene.metal、ProjectFile/ProjectMigrator、関連試験と仕様書。共通の背景合成に重複が生じた場合は単色背景と整理し、既存の描画結果を保持する。

## 保存と実装構成

保存はv21、読込はv18〜21。v16→17は既存ノードを保持し、グラデーションを自動追加しない。v16以前への新payload・新パラメーター混入を拒否する。v13→14変換器を削除し、v17固定fixtureと世代境界試験を追加した。既存のProjectStorageでバックアップ・atomic保存・原本保護を行う。

1. 距離・偏り・混合率のCPU参照とモデル検証を定義する。
2. Metalの背景合成をプレビュー/出力共通のチェーンへ接続する。
3. インスペクター、7数値の自動化、XYハンドル、追加メニューを接続する。
4. 保存世代・履歴・複製・削除・素材なしクリップを検証する。
5. 重複・命名・責務を整理し、最終検証後にbuild-app.shでアプリを生成する。

## 受け入れ確認

- 直線0/90/180/270°、斜め、円形で色の方向・中心・1080pの正円を確認する。
- 2形状×2つの並びで端点/中央/外側をCPU参照と比較する。円形のリングと中心スポットを区別する。
- 偏り−100/0/+100%、最小/最大幅、画面外中心、負の位置、同色A/B、不透明度0/50/100%を検証する。
- A→B→Aの対称性、中心が動かないこと、境界のアンチエイリアスと急峻カーブのバンディングを確認する。数値精度はfloatで評価し、最終8bit出力の階調は別に目視評価する。
- 透明/不透明素材、前段の加算光、単色背景との両順序、後段マスク/ぼかし/色補正、段間合成、クリップ不透明度を比較する。
- 各数値の仮更新/取消/1回確定/初期化、色編集、形状切替後の角度保持、キー・音楽同期、移動/両端トリム、履歴・保存往復・世代移行を確認する。
- 再生・途中シーク・MP4の同時刻画素を比較し、1080p複数段のGPU時間とメモリを測る。検証結果はPROGRESS.mdへ記録する。

## 実装上の整理

数値定義はGradientBackground.fieldsへ集約し、モデル検証・インスペクター・共通自動化で共有する。GradientProfileViewは同じ空間評価と線形色補間を見本へ使う。GradientBackgroundRendererは追加の中間面を持たず、destination alphaを使った背面合成で既存のcoverageと加算光を保持する。急峻な変化は画素内4点の平均で描く。SessionColorWellは色変更中だけ履歴グループを渡す。

変化幅のインスペクターは10px単位（初期192、範囲0.1〜1536）で表示・入力する。表示値1の操作は幅10pxに対応する。保存・キー・音楽同期・描画はpx値を保持し、共通numericの読書き境界で変換する。
