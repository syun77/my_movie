# クロスグレア演出

2026-11-18。設計案に沿って実装済み。以下は現在の仕様。

## 見え方と対象

選択クリップの明るい部分から、直交する2軸・4方向へ先細りの光条を伸ばす。角度45°でX形、0°で＋形。素材の色を引き継ぎ、白い点は白い光になる。点光源に星状の輝き、面光源に筋状の光が発生する。

画像・動画・Spine、および同じ加工面に含まれる図形・単色背景が対象。粒子・全画面の生成演出・歌詞・スペクトラムや他段の合成結果からは発光させない。素材がない透明な空クリップでは光を発生させない。1クリップ1つとし、既存の追加演出メニューへ追加する。

初期実装は4方向固定。光源座標・ランダム点配置・時間による自動明滅は持たず、素材の輝度変化と既存のキー/音楽同期で動かす。

## 編集項目

| 項目 | 初期値 | 範囲 | 意味 |
| --- | --- | --- | --- |
| 輝度しきい値 | 75% | 0〜100% | 光源として抽出する明るさ。100%は発光なし |
| 強さ | 60% | 0〜200% | 生成した光の倍率。0%は完全に元描画 |
| 長さ | 160px | 0〜600px | 中心から各方向への到達距離。1080p基準 |
| 太さ | 2px | 1〜20px | 光条の横断方向のぼかし幅の目安。1080p基準 |
| 角度 | 45° | −180〜180° | 左上原点で右向きから時計回り。もう1軸は＋90° |

全項目は整数表示のDragValueFieldとし、直接入力・中ボタン初期化・ドラッグ・Shift微調整・Esc取消を共有する。ドラッグ中は仮描画、確定は1回。全5項目を共通オートメーションと項目別音楽同期へ接続する。角度は既存数値カーブと同じ補間とし、周期の最短経路へ自動変換しない。

## 描画順と合成

[演出チェーン](EFFECT_CHAIN.md) の指定位置で直前までの結果から光条を抽出し、RGBへ加算する。前段の粒子・ブルームも入力に含む。後段のブラー・色補正・マスク・拡大ループは光条にも作用する。長さ・角度は1080p画面座標で扱う。

加算光はcoverageを増やさず、alpha0のRGBも次の処理へ渡す。クリップの不透明度は全チェーン完成後に1回適用する。光条の余白を確保し、SDRへの変換は最終出力に任せる。

## GPU処理

単純な600px全探索は行わず、Metal computeによる方向別の多段畳み込みを専用CrossGlareRendererへ分離する。CPUは正規化カーネル/実行計画とuniformを準備し、GPU readbackはしない。

1. クロスグレア用の高輝度面を生成する。既存bloomHighlightsの抽出規約を共通化し、しきい値100%を事前に分岐する。
2. 原点の抽出面を各軸へ独立に入力し、両方向の減衰付き疎な畳み込みをping-pongで反復する。サンプル間隔は1, 2, 4…pxと広げ、各段は中心1/2、両側各1/4の正規化3タップ。最終段の間隔を残りの支持範囲へ縮めて指定長を連続的に扱う。片方の軸の結果を次軸へ入力すると面状に広がるため、軸同士は直列接続しない。
3. 軸に直交する方向を短い正規化カーネルでぼかし、太さを作る。方向別の結果を平均して合成し、軸の交点だけが二重に強くなることを避ける。
4. 強さを掛けて素材/ブルームと共通のサンプリング経路で合成する。素材外は透明読みとし、画面端で折り返さない。

各段の重み総和を1にして、長さを変えても光量が不意に増えない設計とする。長さはカーネルの有限支持範囲として定義し、段ごとの支持範囲の和が指定長になるよう実行計画を組む。点光源で方向と有限支持を検証し、整数半径7pxではCPU参照畳み込みとの全画素一致を確認する。初回実装ではフル解像度を基準とし、低解像度化は細い光条の消失を計測してから判断する。

処理範囲は既存のブラー/ブルーム余白に光条の支持範囲と横断ぼかし分を加える。描画面外の光源から画面内へ入る光も保持し、最終合成で画面へ切る。余白を含むメモリ/処理時間は最大値で検証し、性能目標を超える場合は画面に寄与しない領域の切り詰めから改善する。

## モデル・接続箇所

- ImageEffects.CrossGlare: isEnabled、threshold、intensity、length、width、angle。crossGlareはoptional、未追加はnil。有限値と範囲をisValidで検証する。
- ImageAnimation/ImageParameter、EffectAutomation: 5項目の名前・単位・範囲・既定値・読書きと時刻評価を登録する。基準値移動、範囲制限、カーブ/同期削除を既存経路へ接続する。
- ImageEffectsEditor: 追加/選択/有効/削除と5数値欄。無効化で値を保持し、削除時はキー・同期・範囲も除く。
- MetalSceneRenderer: チェーン内の該当ノードで抽出と加算を完結する。評価済みノード列と入力フレームを最終クリップ面のキャッシュキーへ含める。
- CrossGlareRenderer.swiftとShaders/Scene.metal: 光条生成と実行計画を分離する。sampleImageLayerを拡張し、通常素材と拡大ループの両方で同じ光を読む。
- ProcessedImage.costと一時テクスチャ: 実際の各テクスチャ寸法からバイト数を集計し、既存128MiB保持予算へ光条を含める。一時面はレンダラー内で再利用し、コマンド完了まで参照を保つ。プレビューと出力は別所有を維持する。

保存は現version17のImageEffectsへ追加する。フィールド未指定は未追加として読み、既存の保存・コピー・Undo/Redoを使う。時刻履歴を持たず、左トリム専用の位相補正は不要。動画は入力フレーム変更、静止素材は変形/フィルター/抽出条件変更でキャッシュを更新する。

## 実装と受入検証

1. モデル・5項目・保存・UI・自動化を接続する。
2. 点光源用のCPU参照畳み込みとGPU処理を比較し、方向・減衰・支持範囲・正規化を確かめる。参照はテスト用途とする。
3. 共通合成・マスク・拡大ループ・キャッシュ/メモリ予算を接続する。
4. 責務・重複・数値定義・不要コードを整理し、検証後にbuild-app.shでappを生成する。

受入項目は、黒/透明入力で無発光、赤青光源の色保持、透明画素のRGB漏れ防止、＋/Xの向き、1080p換算、しきい値100/強さ0/長さ0/無効の元描画一致、長さの段境界での連続性、端の折り返しなし、画面外光源、半透明/不透明度/上下段/マスク/ブルーム/拡大ループの併用、全数値の保存往復と不正値拒否、キーと音楽同期、削除/Undo/コピー、同時刻シーク再現性、画像/動画/SpineとMP4の一致。

最大3段・1080p・最大長と太さでGPU時間・一時/保持メモリを測る。プレビュー30fpsの1フレーム予算33.3msを全体目標とし、達成可否は実測で判断する。出力は速度より全フレームの一致を優先する。実測では最大長600px/太さ20px・3段・1080pで初回約235〜259ms、再描画約148〜170ms（GPU、開発環境の単回計測。別実行では初回約14.5秒の遅延も観測し、原因は未特定）。保持予算を超える面は再生成するため静止素材でも最大3段は30fpsを満たさない。フル解像度による細い光条の保持を優先し、自動低解像度化は行わない。4枚の作業面を再利用し、演出がなくなった場合とdiscardCacheで解放する。最大設定の作業面は約221MiB、素材面/光条面の同時保持は別途必要となる。
