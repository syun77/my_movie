# 渦巻き収束粒子

2026-11-22。ユーザー要件は「中央に向かって粒子が回転しながら収束する演出」。添付図の矢印は運動方向の参考と解釈する。矢印そのもの、中央の輪郭、青色を描く要件とはしない。同日に実装を承認。以下は実装仕様。

## 見た目

「渦巻き粒子」を粒子カテゴリの独立した生成ノードとして追加する。画面外周付近から現れる粒子が、同じ方向へ旋回しながら中心へ集まる。中心で縮小・フェードアウトし、外側から次の粒子が現れる連続演出とする。中心に粒子を溜めず、中心の光球も初期仕様には含めない。

初期値では約1.5周して3秒で中心へ到着する。粒ごとの開始角度・半径・大きさ・寿命を少し変え、同心円や数本の腕へ整列しすぎない分布にする。中心近くは半径の減少速度を抑え、角速度は有限のまま旋回を続ける。長い尾は付けず、小さな光点の移動で渦を見せる。尾は後続候補とする。

素材の位置・回転・拡縮と独立した1080p画面座標を使う。中心は初期値960/540px、プレビューハンドルで移動可能。空クリップでも利用できる。

| 粒子数 | 1〜1000 | 200 | 同時評価する粒子枠数 |

| 回転数 | 0〜8周 | 1.5周 | 1寿命あたりの旋回量。0で直進収束 |
| 速度 | 0〜400% | 100% | 演出全体の再生倍率 |
| 粒の大きさ | 1〜200px | 8px | 粒別倍率適用前の直径 |
| ぼかしの幅 | 0〜200px | 8px | 標準粒子の周囲光の広がり。粒別倍率と寿命縮小を適用 |

数値はDragValueFieldを使い、ダブルクリック入力・中ボタン初期化・ドラッグ仮更新・mouseUp一度確定・Esc取消に対応する。数値は項目別のキー/LFO/音楽同期を共通経路で評価する。方向・色・画像は離散設定。seedは保存し、「配置を変更」で再生成する。

粒子画像はPARTICLE_IMAGES.mdの画像外観・素材検証・キャッシュ・欠損時の契約を共有する。画像自体の向きは同仕様を使い、軌道の旋回と画像の自転は別とする。

## 運動と時計

フレームごとの物理積分や乱数更新を行わず、seed・粒番号・指定時刻から位置を直接評価する。同時刻ならシーク順、プレビューfps、動画出力によらず同じ配置になる。

```
localTime = songTime - clip.start
clock = (localTime + phaseOffset) * speed / 100
life_i = convergenceTime * random_i(0.85, 1.15)
u_i = positiveFract(clock / life_i + phase_i)
r_i = radius * random_i(0.8, 1.0) * (1 - u_i)^1.5
angle_i = initialAngle_i + direction * 2π * turns * u_i
position_i = center + r_i * (cos(angle_i), sin(angle_i))
```

Y下向きの画面座標でdirection=+1を時計回りとする。乱数は粒番号と用途別saltから固定生成し、周期ごとには変えない。phase_iは粒番号の低偏差分布と小さい固定揺らぎで寿命全体に分散する。粒子数変更で既存番号の軌道・位相を再配置しない。

出現0〜8%でフェードイン、寿命最後の15%で縮小・フェードアウトする。最後の瞬間はサイズ・不透明度とも0とし、次周期の外周への移動を見せない。開始から位相分散済みの渦を表示し、ウォームアップは不要。粒子数は同時評価枠数なので、フェード中や画面外の粒を含む。

左トリムはphaseOffsetへ開始差分を足し、同じ曲時刻の位相を保持する。通常移動はクリップ相対の動きを保持。速度0ではclock=0の配置で静止する。速度・収束時間・回転数の自動化は現在値による直接評価とし、変更による軌道ジャンプを許容する。連続加速を保証する積分方式は初期仕様に含めない。

中心XYや半径の自動化はその時刻の全粒子へ同時適用する。中心が動く場合は渦全体が追従し、過去の中心へ各粒が追跡する方式にはしない。半径0でも正規化除算を使わず、全粒を中心に配置できるようにする。

## 描画と既存機能への接続

- EffectNodeが設定・seed・位相・数値の自動化を所有。既存チェーンの同種1ノード制約を共有し、複数の中心や方向は別クリップ・別レイヤーで重ねる。
- 標準粒子は柔らかい光点をMetalのインスタンス描画で線形加算し、背景を塗らず既存alphaを保持する。画像粒子の合成は既存粒子画像設定に従う。
- チェーン内の挿入位置で前段へ重ねる。後段の色調補正・ブラー・マスク等は粒子込みの結果へ作用。最終クリップ不透明度と段間マスクは共通経路で適用する。歌詞・スペクトラムは対象外。
- 画面外発生を許容し、後段ブラー用の描画余白にも粒子を描く。不要な全画面中間面を追加せず、既存の粒子クワッドと素材テクスチャを再利用する。粒子データはMTLBufferへ渡し、setVertexBytesの4KiB制限を回避する。
- 保存・自動保存・Undo/Redo・複製・貼り付け・素材管理・ノード削除は共通経路へ接続。削除時は関連自動化と画像参照も処理する。
- 保存v21・読込v18〜21。v18→19は既存ノードを維持し、渦巻き粒子を自動追加しない。旧形式への新payload/パラメーター混入は拒否する。v16→17変換器を削除し、v20固定fixtureを追加する。

## 実装順と受入条件

1. 数値定義・検証・固定乱数・時刻評価をUIから独立したモデルへ集約する。
2. 既存粒子描画と画像外観の経路へ接続する。
3. ノード編集・XYハンドル・自動化・保存移行・履歴を接続する。
4. 整理フェーズで時計・乱数・素材参照・数値定義の重複を見直し、検証後にbuild-app.shでアプリを生成する。

受入確認は、両回転方向、回転数0の直進、中心への単調収束、寿命境界の不可視化、初期表示の分布、中心/半径0/画面外/速度0、粒数変更の安定性、ランダムシークと左トリムの一致、キー/LFO/同期、ドラッグ取消/一度確定、保存移行/複製/履歴、画像未指定/指定/欠損、チェーン順/透明度/マスク、プレビューとMP4の一致を含む。1080pで200/1000粒・1/3/10ノードのGPU時間とメモリを測り、実時間性能は測定結果から判断する。

一斉収束、中心への到着時刻指定、螺旋の尾、中心発光、軌道と別の画像自転は後続候補。連続循環の初期仕様へ混在させない。

## 既存構造に合わせた実装判断

初期案の同種ノード複数追加は、既存の項目参照・レーン・インスペクターが同種1ノードを前提としているため、別クリップ・別レイヤーでの重ね合わせに変更した。演出速度・収束時間の変更による位相ジャンプ、画像自転と軌道旋回の分離、中心光と尾を追加しない方針は設計通り。

## 検証結果

初期実装時の全体297件は外部Spineサンプル未指定の1件をスキップし失敗0（/tmp/my-movie-spiral-full.log）。整理後の関連59件も成功（/tmp/my-movie-spiral-final-tests.log）、渦巻き専用9件を含む。決定性・単調収束・回転方向・境界フェード・速度0・粒数の安定性・キー/LFO/同期・トリム・UI取消/確定/初期化・v19保存境界・固定fixture・画像上下/回転/欠損・マスク・後段ぼかし・MP4各フレームの共通描画比較を確認した。素材参照と履歴は既存の粒子画像共通試験へ渦巻き粒子を追加して確認。

整理後1080p・3フレームのGPU最大は、200粒の1/3/10段で6.83/14.40/36.55ms、1000粒で7.42/12.57/26.48ms。測定時の負荷・キャッシュに依存し、粒数に対する単調な比較や最小対象Macでの実時間性能を保証する値ではない。関連試験プロセス全体の累積ピークRSSは約362MiBで、演出単体のGPUメモリ量とは区別する。標準と赤色の描画画像を目視確認。実素材を使った手動GUI操作は未実施。

./scripts/build-app.shで最新dist/MV Studio.appを生成済み（/tmp/my-movie-spiral-build-app.log）。署名検証と同梱シェーダーの最終ソース一致、git diff --checkを確認。

## 標準粒子の周囲ぼかし

標準表示に「ぼかしの幅」（0〜200px、初期8px）と「ぼかしの強さ」（0〜200%、初期100%）を追加。芯は元のGaussian状の光点、周囲は独立した広いGaussian状の加算光として評価し、幅または強さ0で周囲光を消す。幅は1080p基準で、粒別のサイズ倍率と寿命末尾の縮小も適用する。芯の基準サイズ・位置・軌道を変えずクワッドの描画範囲だけを広げる。alphaは増やさず、追加の中間面・ぼかしパスを使用しない。

2項目は共通DragValueField、キー/LFO/音楽同期、保存・履歴・複製・MP4出力へ接続する。粒子画像では数値を保持して入力を無効化し、画像をぼかさない。現行保存v21、読込v18〜21。v19以前の粒子へは読込境界で0px/100%を補完し、旧描画を保つ。新規の初期値は8px/100%。

周囲ぼかし追加後は関連51件、整理後33件が成功（/tmp/my-movie-spiral-glow-tests.log、/tmp/my-movie-spiral-glow-final-tests.log）。専用11件に幅/強さの画素比較、0で芯のみ、画像方式の入力無効、v19補完と新フィールド混入拒否を含む。比較画像/tmp/my-movie-spiral-glow.pngを目視確認。

周囲ぼかしを反映した最新アプリをbuild-app.shで生成済み（/tmp/my-movie-spiral-glow-build.log）。署名と同梱シェーダーの一致を検証。
