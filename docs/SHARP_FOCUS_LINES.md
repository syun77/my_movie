# 集中線３（シャープな集中線）

演出の適用順・前段/後段の作用範囲は [演出チェーン](EFFECT_CHAIN.md) に従う。

作成日・実装日: 2026-11-18。ユーザーの参考画像を基に、独立した追加演出「集中線３」として実装。初回設計の既存集中線への形状追加案は、ユーザー指定により独立演出へ変更した。既存の「集中線」（先細り三角形）と「集中線２」（発光ノイズ）はそれぞれ維持する。

## 見た目と配置

中心へ向かう直線を、一定幅の長い本体と短く尖る先端で描く。指定色の不透明度、長さ・太さ・角度・内端のばらつきにより、参考画像のような明瞭な集中線を作る。ぼかし、発光、丸い端は使わず、輪郭だけに約1出力画素のアンチエイリアスを適用する。参考画像の画素の階段を再現するピクセル化は行わない。

「画像・演出」→「追加演出」→「集中線３」で追加する。1クリップに1つ。画像・動画・Spine・空クリップで既存の有効期間を共有する。背景は透明。空クリップで線だけを重ねる場合は既存の単色背景を無効にする。

線を人物の背後へ置くには、下段に背景と集中線３、上段に透過人物を配置する。人物と背景が一体の素材から人物を自動検出・切り抜きする機能は持たない。

## 設定

座標・寸法は1920×1080基準、左上原点。

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| 中心X/Y | 960 / 540px | 0〜1920 / 0〜1080px |
| 内端の分布幅/高さ | 480 / 270px | 0〜3840 / 0〜2160px |
| 本数 | 120 | 8〜300 |
| 太さ | 4px | 1〜40px |
| 長さ | 100% | 0〜100% |
| ばらつき | 75% | 0〜100% |
| 不透明度 | 100% | 0〜100% |
| 先端の長さ | 12px | 0〜80px |
| 不透明度のばらつき | 65% | 0〜100% |
| 更新頻度 | 12回/秒 | 0〜30回/秒、0で静止 |
| 色 | 白 | RGB単色 |

更新頻度以外の11数値は共通キー・音楽同期へ対応する。更新頻度と色、有効チェックは固定設定。全数値欄は共通DragValueFieldで、ダブルクリック入力、中ボタン初期化、方向固定ドラッグ、Shift微調整、仮描画、mouseUp一括確定、Esc取消を使う。

太さは本体の一定幅。先端の長さ0は平らな内端。長さ0・不透明度0では描かない。分布幅・高さは内端が散る範囲を指定し、中央に一律の透明な楕円は設けない。長さ100%では中心近くに多くの内端が集まり、一部は少し離れて止まる。

## 形状と色の評価

1080pの画面座標で生成し描画時に拡大縮小する。線番号の低偏差列に小さな乱数変動を与え、本数変更で既存番号の候補を維持する。

中心から画面端までの距離E、分布幅・高さの楕円上の距離I、長さ比L、ばらつき比V、独立固定乱数u/z/r（0〜1）から次を求める。

- 中心寄りの到達点: `n = I × (0.15 + 0.85Vu²)`
- 内端: `a = E × (1-L) + n × L`
- 本体幅: `w = 太さ × (1-0.7Vz)`
- 外端: `b = E + 2w`
- 尖端長: 指定値と線長の半分の小さい方
- 線ごとの不透明度倍率: `1-0.8 × 不透明度ばらつき比 × r`
- sRGB線色: 指定色を維持

Eが0以下、IがE以上、bがa以下なら省略する。短い尖端区間で幅0からwへ広がり、その後は一定幅。外端は平ら。外端はばらつきや長さにかかわらず必ず画面端より外へ伸ばし、画面内では途切れさせない。内端の乱数を2乗して中心寄りに偏らせる。長さを下げた場合は意図的に内端を外へ戻す。線ごとの倍率はアルファへ適用し、色の明度は変えない。白・黒・任意色で下の背景が透ける。

線ごとの矩形へインスタンス描画し、内部で本体・尖端の被覆率を評価する。巨大な画面全体を線数分処理しない。画面端の中心、分布範囲0、分布範囲が画面を覆う場合も有限値で評価する。

## 時計・合成・保存

固定seed・線番号・`floor((相対時刻 + phaseOffset) × 更新頻度)`から属性を生成し、同じ時刻を再現する。コマ内は静止、切替時にフェードしない。更新頻度0は常にコマ0。ばらつき0でも不透明度ばらつきがあれば透明度だけ変わるため、完全静止には更新頻度0を使う。静止参考から動きは確定できないため、このコマ切替は設計上の選択。

色を線形sRGBへ変換し通常のpremultiplied source-overで合成。アルファは輪郭被覆率×線ごとの不透明度倍率×演出不透明度×クリップ不透明度。線形RGBも同じアルファでpremultiplyする。重なりは線番号順で、加算による発光は行わない。

所有段の素材・他の追加描画の後、上段素材・スペクトラム・歌詞の前へ描く。基本素材変形と独立した画面座標で生成し、後段のシェイク・ブラー・色調補正・自クリップマスクに従う。上段の下向きマスクでは対象段の集中線３も含めて切り抜く。

保存キーtoneVariation/sharpToneVariationは不透明度ばらつきの値とキーを保持する。

`ImageEffects.sharpFocus`へ設定・seed・phaseOffsetをversion19で保存。未追加はnil。既存集中線の保存形式は変更しない。追加・削除・有効切替・編集は既存保存/Undo/Redo経路を使う。コピーはseedを保持しキーIDを更新、左トリムは位相加算とキー時刻減算、右トリムは位相を維持する。削除で関連カーブ・同期・表示範囲も既存経路から取り除く。

## 実装と検証

SharpFocus.swiftが属性生成、FocusLineGeometry.swiftが既存集中線と共通の時計・交点計算を所有する。EffectAutomation/ImageAnimationで数値定義と評価、ImageEffectsEditorでUI、MetalSceneRenderer/Scene.metalでプレビュー・MP4共通描画を行う。

SharpFocusTestsで決定性、保存、分布範囲/無効値、一定幅・尖端0・不透明度ばらつき、キー・音楽同期・左トリム、UI追加/色通知/削除、透明合成・縮小・マスク・不透明度、MP4の画素とフレーム時刻を確認する。既存FocusLinesTestsも維持する。静止描画の目視、全体テストとアプリ生成結果はPROGRESS.mdへ記録する。

細線の圧縮劣化や再生時の主観的ちらつき、実素材での見え方は残る確認事項。性能値は実行環境と同時演出に依存する。
