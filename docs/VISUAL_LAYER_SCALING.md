# 多数の画像を重ねるためのレイヤー構成（提案）

2026-11-19。可変タイムラインレイヤー方式はユーザー指定。具体設計は [可変タイムラインレイヤー](VARIABLE_VISUAL_LAYERS.md) を参照。以下は方式比較の記録であり、可変レイヤー方式は実装済み。詳細仕様はリンク先を優先する。

## 結論

固定3段を可変の映像レイヤーへ変更することを先行する。クリップ内部のサブレイヤーは、複数素材を一体として再利用・変形する要件が強くなった時点で、独立した複合クリップとして検討する。画像だけの別構造は導入せず、画像・動画・Spine・空クリップの共通配置基盤を使う。

レイヤーは映像の前後関係と配置行、オートメーションレーンは値の編集行を指す。今回増やす対象は前者。

## 比較

| 観点 | 可変タイムラインレイヤー | クリップ内サブレイヤー |
| --- | --- | --- |
| 各画像の表示時刻 | 全曲上で直接比較・編集できる | 展開または内部編集が必要 |
| 個別の変形・音楽同期・演出 | 既存クリップの操作を共有 | 子の選択・編集経路が必要 |
| 多数素材の一覧性 | 縦に長くなる。行の折り畳み等で対処 | 外側は短いが内部の配置が隠れる |
| まとめて移動・拡縮・演出 | 複数選択やグループ機能が別途必要 | 親に対して自然に指定できる |
| 時刻・トリム | 既存の全曲時刻と相対キーを使用 | 親と子の時計、範囲外、親トリムの規則が必要 |
| 合成とマスク | 現在の段順合成を拡張 | 子合成→親加工、階層境界とマスク範囲の新規設計が必要 |
| 実装への影響 | 固定3段前提の解消が中心 | 保存・編集・取得・合成を再帰構造へ拡張 |

多数の画像を独立に出し入れするMVでは可変レイヤーが目的に合う。一方、人物と複数の装飾を常に一体で動かし、同じ組合せを何度も使うなら複合クリップの価値が高い。どちらも同時に描く素材数と演出の負荷は残る。階層化だけで描画が軽くなるわけではない。

## 推奨する初期仕様

- 新規プロジェクトは従来と同じ3段から開始し、任意位置への追加・削除・名前変更・上下並べ替えを提供する。固定の多数空行は作らない。
- 上ほど前面。同じ段の時間重なり禁止、異なる段の重なり許可を維持する。
- レイヤーの表示切替はプレビュー・出力へ共通適用し、ロックは編集だけを防ぐ。非表示とオートメーション折り畳みは明確に区別する。
- 内容がある段の削除は所属クリップも削除することを明示する。素材ファイル・登録済み素材は削除しない。削除・並べ替え・表示切替をUndo/Redoと自動保存へ接続する。
- 行高調整・縦スクロールを維持し、オートメーションは必要な段だけ展開する。後段でフォルダーによる表示整理を検討する。表示用フォルダーには共通変形・共通演出を持たせない。
- 段数の製品上限は負荷試験で決める。モデルは可変長とし、無制限や全段30fpsを約束しない。静止画多数と重い演出多数を別々に計測する。

## モデル・描画への影響

VisualLayerは既にUUIDを持つ。所属・選択・高さ・開閉・ロック等は安定IDで扱い、前後順序は配列順へ集約する。slot番号を永続的な識別子として使わない。VisualTrackの3段検証、TimelineViewの固定ループ、配置先UI、フレーム取得、履歴、コピー、TimelineHeights、関連試験を一緒に変更する。

直下段マスクは「配列上で隣接する直下レイヤー」を対象とし、空段・非表示段を飛び越さない案を推奨する。並べ替え・途中追加・削除で対象が変わることをUIで示す。マスク所有段が非表示ならマスクも無効。対象を固定したい要件があれば、別途ID参照方式を検討する。

描画では段ごとの中間面・加工キャッシュ・素材デコードが増える。非表示段の取得省略、不要キャッシュの解放、作業面の再利用を検討し、マスクが必要な段の寿命とGPU完了までの参照保持を確認する。静止素材でも時刻依存演出や音楽同期がある場合は合成結果を静的キャッシュに固定しない。

保存形式は実装時の現行バージョンから更新する。現行＋直前3世代の境界で、旧slot順を配列順へ、slot基準の高さ等を既存layer IDへ変換する。旧3段の空段も保持し、マスクの意味を維持する。未来のバージョン番号は本検討時点で固定しない。

## 複合クリップを追加する場合

単一素材クリップに子配列を付け足すより、素材クリップと複合クリップを区別する。内部タイムライン、親開始基準の子時刻、親トリム時の子の保持、親速度、合成後の変形・演出、不透明度、マスクの階層境界、複製・素材使用判定をまとめて定義する。まず1階層に制限する案が妥当。

一括移動だけが必要なら、複数選択とグループ移動の方が小さな拡張で済む。合成後の共通加工や組合せ再利用まで必要になった時点が複合クリップ導入の目安となる。

## 実装時の受入条件

- 3段を超える画像・動画・Spine混在の重なり、前後変更、空段、マスクをプレビューとMP4で照合する。
- 行追加・削除・並べ替え後も選択・行高・キー・開閉状態が別レイヤーへ移らず、Undo/Redoと保存復元が一致する。
- 旧形式からの読込で外観とマスク対象を保持する。
- 10/20/50段の静止画、および演出・動画を含む構成でGPU時間、デコード、メモリを計測して製品上限を決める。数値は試験条件案であり対応保証ではない。
