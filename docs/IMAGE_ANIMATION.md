# 画像クリップのアニメーション設計

2026-11-09実装。対象は「画像・演出」の画像クリップ。トランジェント・拍に同期する動きを「自動アニメ」にまとめ、位置・拡大縮小・回転の手動キーフレームをクリップ内に持たせる。

## 画面と操作

右上のインスペクターに「変形」と「自動アニメ」を設ける。変形はX、Y、拡大縮小、回転の4欄とし、各欄に「◇ キーを打つ」を置く。「位置」のXとYは別々に動かせる。タイムラインでレイヤーを展開すると、クリップのヘッダーの下にキーを持つ項目のグラフを縦に並べる。範囲はインスペクターでダブルクリック入力または左右ドラッグで調整する。入力はReturn、ドラッグはmouseUpで確定する。グラフ左の最小・最大ラベルから該当欄へフォーカスできる。

```text
変形                     自動アニメ
位置 X    [  0 px] [◇]    [オフ ▾]
位置 Y    [  0 px] [◇]    トランジェント / 拍
拡大縮小  [100  %] [◇]    強さ [8 %]
回転      [  0  °] [◇]

タイムライン        2.0秒                3.0秒                4.0秒
画像2   v           ┌── 人物.png────────────────────────────────┐
                    │ 拡大縮小  最大 [150 %]                     │
                    │                         ◇                  │
                    │                      ╱                     │
                    │ 最小 [ 50 %]  ◇───╱                        │
                    └────────────────────────────────────────────┘
```

- 変形の数値欄は、キーがない項目では固定値、キーがある項目では基準値を表示する。ダブルクリックで入力してReturn、または左右にドラッグして離すと確定する。基準値変更では最小・最大・全キーの値に同じ差分を加える。区間外に隠れたキーも移動し、キーの時刻は維持する。
- 最初の「キーを打つ」は再生位置に入力済みの値でキーを作り、その値を基準値として保持してレーンを開く。既存レーンではグラフの補間値でキーを追加し、同時刻に点があれば選択する。クリップ外ではキーを作らない。
- グラフの空白をクリックすると、横位置を時刻、縦位置を値として制御点を追加し、再生位置を維持する。既存の点をクリックすると選択する。グラフの空白クリックがスナップで既存点と同時刻になった場合は、その点を選択する。
- 点の中心から11pt以内で最も近い点を掴める。ポインタが掴める範囲に入ると、その点を少し大きい黄色のマーカーで表示し、ドラッグ中も強調する。点を左右にドラッグすると時刻、上下にドラッグすると値を変更する。隣の点の時刻を越えたり、同時刻に重なったりする候補では確定しない。選択点はDeleteで削除できる。最後の点を削除するとその値を固定値にしてグラフを閉じる。
- ヘッダーでクリップの移動、左右端のハンドルでトリム、グラフ領域でキー編集を行う。キーのあるレイヤーでは、レイヤー名の右にある薄い `>` でレーンを表示し、`v` で収納する。開閉状態はレイヤーごとに保持し、空白や別のクリップを選んでも変えない。開いているレイヤーでは同じ項目のグラフを横に並べ、別クリップのグラフからそのクリップを選択できる。表示時は画像行を縦に広げ、3段を縦スクロールできる。グラフの左右端は親クリップの区間と共通の時間軸に合わせる。グラフが表示範囲の端で見切れても、見えている部分の時刻や値の倍率は変えない。目盛りは固定する。グラフが見切れる場合もインスペクターの項目選択から範囲を編集できる。

### 値とグラフの範囲

| 項目 | 値の意味 | 固定値の初期値 | 縦軸の初期範囲 |
| --- | --- | --- | --- |
| 位置 X | 画面中心からのオフセット。右が正 | 0 px | −960〜960 px |
| 位置 Y | 画面中心からのオフセット。上が正 | 0 px | −540〜540 px |
| 拡大縮小 | 画像全体が画面に収まる倍率を100%とする等比スケール | 100% | 10〜200% |
| 回転 | 画像中心を軸に時計回りを正とする角度。360°を超える値も指定可 | 0° | −180〜180° |

位置は1920×1080基準のピクセルで保存し、描画サイズに応じて換算する。角度は度で保存する。スケールのキー・固定値・範囲端は正値とし、すべての数値は有限でなければならない。

「最小」「最大」は項目ごとに保存する縦軸の表示範囲で、上端を最大、下端を最小とする。最小 < 最大を必須とする。クリックと上下ドラッグで指定できる値はその範囲内。範囲外の既存値は端のマーカーで示し、数値欄から編集・削除できる。範囲変更の前後でキーの値と映像は同じ。たとえば最大を200%から120%に変えても、150%のキーは150%のまま再生する。

固定値・基準値、最小、最大はホイールクリックで各初期値に戻す。リセットした上下限が反対側と交差する場合は両端を初期値に戻す。拡大率の基準値を100%へリセットする差分で下限が0%以下になる場合は下限を10%へ戻し、上限がその下限以下になる場合は上限を200%へ戻す。移動後に0%以下になるキーは0.1%にする。

### キーの時刻、補間、クリップ編集

- キー配置時の「拍スナップ」は初期ONとし、既存の16分音符グリッドを使う。スナップ先の候補にはクリップの開始・終了も含める。OFFでクリック・ボタン・ドラッグから任意の時刻に打てる。BPMや拍開始の変更は以後のスナップと自動アニメ「拍」に反映し、既存キーは元の時刻を保つ。
- キーの編集区間は開始・終了を含む。終了のキーは最後の補間先として使い、画像の表示区間は従来どおり終了を含まない。時刻の一致判定は浮動小数点誤差を吸収するため同一項目内で共通化する（1マイクロ秒以内）。横位置はタイムラインの表示倍率にかかわらず同じ時間座標から計算する。
- キー間は初期版では線形補間。最初の点より前は最初の値、最後の点より後は最後の値を保持する。1点だけなら全区間でその値になる。例えば静止状態から途中で拡大するには、動き始めに100%、動き終わりに150%の2点を打つ。回転は入力値をそのまま補間するため、0°→360°は1回転になる。
- 本体の左右移動ではキーをクリップと一緒に移動し、段移動では時刻を維持する。右トリムではキーの時刻を保つ。左トリムでは開始時刻の差をキーの相対秒から引き、曲上のキー時刻を保つ。トリムで区間外になったキーは隠して保存し、両端を伸ばせば再表示する。補間には区間外の前後のキーも使い、トリム前と同じ時刻で同じ値を得る。
- ドラッグ中は一時停止し、開始時の座標とモデルで仮編集する。点のドラッグでは、仮の点の時刻で変形をプレビューする。mouseUpで1操作として検証・保存し、Esc・タブ切替では仮編集を破棄する。選択・シーク・展開状態はUndo履歴の対象外。キー追加・更新・削除、固定値、縦軸範囲、自動アニメ設定は共通EditHistoryでUndo/Redoし、自動保存する。

## 自動アニメと手動変形の合成

自動アニメはクリップごとに「オフ／トランジェント／拍」から選ぶ。初期版の効果は拡大で、強さは現行と同じ0〜25%。トランジェントは解析で検出した直近の打音、拍はBPMと拍開始から求めた直近の四分音符をトリガーにする。拍開始を第1拍とし、それ以前は発火しない。トリガー時を最大とし、現行の三次減衰で0.3秒後に通常の倍率へ戻る。間隔が0.3秒未満なら最新のイベントで再発火する。キーは打たず、曲の時刻から毎回評価する。

手動の位置・拡大率・角度を求めたあと、拡大率だけに自動倍率を掛ける。たとえばキー値120%で自動拡大が最大+8%の瞬間は、描画上129.6%になる。手動グラフは120%を表示する。自動アニメをオフにすると手動変形だけを再生する。拡大と回転は画像の中心を軸とし、その中心を手動で指定した位置へ移す。キャンバス外はクリップし、画像・スペクトラム・歌詞の合成順は現行どおりとする。

## モデルと実装の接続

| 所有先 | 保存する内容 |
| --- | --- |
| `ImageClip` | 固定値・基準値、自動アニメの種類と強さ、項目別の手動グラフ |
| 手動グラフ | 項目、縦軸の最小/最大、時刻順のキー |
| キー | UUID、クリップ開始からの相対秒、値。トリム後の相対秒は負値やクリップ長超過を許可 |

画像素材参照と分離し、同じ素材でもクリップごとに別のアニメーションを持てる。画像の差し替えでクリップのアニメーションを維持し、配置削除でそのクリップのアニメーションも削除する。選択中の点・展開状態・入力の仮値は保存しない。

1. `ImageTrack` の値モデルに変形とアニメーションを組み込む。数値欄・タイムラインで同じ更新・トリム処理を使う。保存前・復元時は項目とIDの一意性、キーの並びと時刻の重複、数値、縦軸範囲を検証する。
2. `ProjectFile` の保存形式をversion 4とし、自動アニメを種類＋強さで保存する。旧版は別名バックアップと新規作成の導線を使う。新規クリップの初期設定は「トランジェント・8%」。
3. `SceneRenderer` が時刻から変形を計算する。プレビュー、シーク、MP4書き出しは共通の評価処理を使う。書き出し開始時に確定したモデルを固定し、編集中の仮値は含めない。
4. `ImageEditor` に変形欄と自動アニメ欄、`PlacementEditor` と `TimelineView` にグラフ展開とキー操作をつなぐ。横座標は `TimelineGeometry`、拍スナップは `TimelineSnapGrid`、確定編集の履歴は `EditHistory` を共用する。

## 受け入れ確認

- 数値欄から最初のキーを打つと、レイヤーのレーンが開く。選択変更で収納されず、レイヤー名右の記号で開閉できる。基準値とキー・上下限の連動、ホイールリセット、クリック追加、ドラッグ、Delete、Esc、Undo/Redoを確認する。
- 最小50%・最大150%のグラフ中央をクリックすると100%になる。範囲を変更しても映像の値は同じで、不正な範囲は確定しない。
- クリップ移動では全キーが追従し、トリム後も残る区間の評価値は一致する。伸ばすと隠れた点が復元する。別段への移動や素材差し替えでキーは維持される。
- トランジェント・拍・オフを切り替え、120%の手動値と+8%の自動拡大からピーク時129.6%になることを確認する。BPM変更で拍の発火だけが変わり、手動キーの時刻は維持される。
- 保存・再読込でキー、縦軸、固定値、自動アニメが一致する。同じ時刻のシーク、通常再生、MP4のフレームで位置・拡大率・角度・描画順を比較する。
