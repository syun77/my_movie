# 画像クリップのアニメーション設計

画像・動画クリップ内の手動キーと項目別の音楽同期を扱う。音楽同期の現仕様は [AUDIO_AUTOMATION.md](AUDIO_AUTOMATION.md) を参照。

## 画面と操作

右上のインスペクターに「変形」と「音楽同期」を設ける。基本パラメーターはX、Y、拡大縮小、回転、不透明度の5欄とし、各欄のノブまたは数値の右クリックで「オートメーションを作成／削除」を表示し、作成済みのノブ右上に小さな青い丸を描く。「位置」のXとYは別々に動かせる。タイムラインでレイヤーを展開すると、クリップのヘッダーの下にキーまたは音楽同期を持つ項目のグラフを縦に並べる。範囲はインスペクターでダブルクリック入力または上下左右ドラッグで調整する。入力はReturn、ドラッグはmouseUpで確定する。グラフ左の最小・最大ラベルから該当欄へフォーカスできる。

```text
変形                     音楽同期（項目別）
位置 X    [  0 px]    項目 [拡大縮小 ▾]
位置 Y    [  0 px]    入力 [トランジェント ▾]
拡大縮小  [100  %]    帯域 [全帯域 ▾]
回転      [  0  °]    相対変化 [+8 %] 戻り [0.30秒]
不透明度  [100  %]

タイムライン        2.0秒                3.0秒                4.0秒
画像2   v           ┌── 人物.png────────────────────────────────┐
                    │ 拡大縮小  最大 [150 %]                     │
                    │                         ◇                  │
                    │                      ╱                     │
                    │ 最小 [ 50 %]  ◇───╱                        │
                    └────────────────────────────────────────────┘
```

- 変形の数値欄は、キーがない項目では固定値、キーがある項目では基準値を表示する。ダブルクリックで入力してReturn、または左右にドラッグして離すと確定する。基準値変更では最小・最大・全キーの値に同じ差分を加える。区間外に隠れたキーも移動し、キーの時刻は維持する。
- 「オートメーションを作成」は再生位置に入力済みの値でキーを作り、その値を基準値として保持してレーンを開く。追加キーはグラフから作成する。ノブの「オートメーションを削除」は手動キーを削除し（音楽同期があれば表示範囲を保持）、、基準値を固定値として保持する。クリップ外ではキーを作らない。
- グラフの空白をクリックすると、横位置を時刻、縦位置を値として制御点を追加し、再生位置を維持する。既存の点をクリックすると選択する。グラフの空白クリックがスナップで既存点と同時刻になった場合は、その点を選択する。
- 制御点を右クリックすると「削除」「シングル曲線」「スムーズ」「ホールド」「パルス」「ウェーブ」を選べる。補間種別は対象キーの`interpolation`へ保存し、直前のキーから対象キーまでに適用する。未指定はシングル曲線。最初の点には流入区間がないため、その設定は直前に点を追加したときに使う。右クリック選択・メニュー実行ではシークしない。
- シングル曲線は中央○で調整する2次曲線。スムーズは区間の進行率を`u=t²(3−2t)`へ置き換え、両端で傾きが0になるeaseInOutとする。中央○の調整量は保持し、同じ式のtをuへ置き換えて評価する。ホールドは対象キー時刻の直前まで前の値を保ち、その時刻で対象値へ切り替える。ホールド中は中央○を非表示にし、曲がり量は他の補間へ戻したときに使う。グラフも水平線と垂直接続を描く。
- パルスは前の値と対象点の値を、同じ長さずつ交互に繰り返す矩形波（デューティ比50%固定）。区間に1〜20個の整数周期を配置し、既定は4周期。最初は前の値、最後は対象点の値となり、両端も途中と同じ幅になる。中央○を上へ動かすと周期数が減って幅と周期が長くなり、下へ動かすと周期数が増えて短くなる。対象キーの`pulseCycles`へ保存し、グラフは全切替位置を垂直に描く。
- ウェーブは`(1−cos(2πt/period))/2`で2点の値の間を往復するサイン波。中央○の上下で周期を対数スケールで変更する。上で長く、下で短くなる。周期は区間長の0.05〜2倍、既定1倍（区間内1周期）。対象キーの`wavePeriod`へ比率を保存し、トリムや移動後も区間に対する周期を保つ。表示サンプルは1周期あたり32分割以上を確保する。
- パルス/ウェーブの中央○は時間方向の中間に固定し、縦位置で幅/周期の設定値を示す。波形そのものの値とは独立する。ホバー/ドラッグ中はパルスの幅秒と周期秒、ウェーブの周期秒を表示する。いずれも制御点時刻では指定値を優先し、波形の区間終端と異なる場合は垂直接続する。補間種別の切替で幅・周期の設定は失わない。
- 中央の○は上下だけを調整し、時刻スナップやシークは行わない。ホバーとドラッグ中は黄色で強調する。マウスを離した時に1操作として確定し、Escで仮変更を取り消す。変形と演出の全レーンで共通。
- 点の中心から11pt以内で最も近い点を掴める。ポインタが掴める範囲に入ると、その点を少し大きい黄色のマーカーで表示し、ドラッグ中も強調する。点を左右にドラッグすると時刻、上下にドラッグすると値を変更する。隣の点の時刻を越えたり、同時刻に重なったりする候補では確定しない。選択点はDeleteで削除できる。最後の点を削除するとその値を固定値にする。音楽同期が残っていればグラフを維持する。
- 画像クリップを選択し、レーン左側の項目名を右クリックして「レーンを削除（キーと音楽同期）」を選ぶと、選択クリップの該当項目のキー・音楽同期・縦軸範囲をまとめて削除する。基準値が固定値になり、削除は自動保存され、Undo/Redoできる。
- ヘッダーでクリップの移動、左右端のハンドルでトリム、グラフ領域でキー編集を行う。キーのあるレイヤーでは、レイヤー名の右にある薄い `>` でレーンを表示し、`v` で収納する。開閉状態はレイヤーごとに保持し、空白や別のクリップを選んでも変えない。開いているレイヤーでは同じ項目のグラフを横に並べ、別クリップのグラフからそのクリップを選択できる。表示時は画像行を縦に広げ、3段を縦スクロールできる。グラフの左右端は親クリップの区間と共通の時間軸に合わせる。グラフが表示範囲の端で見切れても、見えている部分の時刻や値の倍率は変えない。目盛りは固定する。グラフが見切れる場合もインスペクターの項目選択から範囲を編集できる。

### 値とグラフの範囲

| 項目 | 値の意味 | 固定値の初期値 | 縦軸の初期範囲 |
| --- | --- | --- | --- |
| 位置 X | 画面中心からのオフセット。右が正 | 0 px | −960〜960 px |
| 位置 Y | 画面中心からのオフセット。上が正 | 0 px | −540〜540 px |
| 拡大縮小 | 画像全体が画面に収まる倍率を100%とする等比スケール | 100% | 10〜200% |
| 回転 | 画像中心を軸に時計回りを正とする角度。360°を超える値も指定可 | 0° | −180〜180° |

位置は1920×1080基準のピクセルで保存し、描画サイズに応じて換算する。角度は度で保存する。スケールのキー・固定値・範囲端は正値とし、すべての数値は有限でなければならない。

「最小」「最大」は項目ごとに保存する縦軸の表示範囲で、上端を最大、下端を最小とする。最小 < 最大を必須とする。クリックと上下ドラッグで指定できる値はその範囲内。範囲外の既存値は端のマーカーで示し、数値欄から編集・削除できる。範囲変更の前後でキーの値と映像は同じ。たとえば最大を200%から120%に変えても、150%のキーは150%のまま再生する。

固定値・基準値、最小、最大はホイールクリックで各初期値に戻す。リセットした上下限が反対側と交差する場合は両端を初期値に戻す。拡大率の基準値を100%へリセットする差分で下限が0%以下になる場合は下限を10%へ戻し、上限がその下限以下になる場合は上限を200%へ戻す。移動後に0%以下になるキーは0.1%にする。

### キーの時刻、補間、クリップ編集

- キー配置時の「制御点スナップ」は初期ONとし、タイムライン上部の「スナップ」で選んだ音符のグリッドを使う。スナップ先の候補にはクリップの開始・終了も含める。OFFでクリック・ボタン・ドラッグから任意の時刻に打てる。音符単位・BPM・拍開始の変更は以後のスナップに反映し、既存キーは元の時刻を保つ。自動アニメ「拍」にはBPMと拍開始を使う。
- キーの編集区間は開始・終了を含む。終了のキーは最後の補間先として使い、画像の表示区間は従来どおり終了を含まない。時刻の一致判定は浮動小数点誤差を吸収するため同一項目内で共通化する（1マイクロ秒以内）。横位置はタイムラインの表示倍率にかかわらず同じ時間座標から計算する。
- キー間は中央ハンドル未調整なら線形補間。隣接点の中間時刻に○を表示し、上下ドラッグでその区間を上向き・下向きに曲げる。端のキー時刻と値は維持する。曲がり量は始点キーの`midpointOffset`へ保存し、線形値に`4t(1-t) × midpointOffset`を加える2次曲線として共通評価する。演出の有効範囲と拡大率の正数制約を超えた部分は制限する。最初の点より前は最初の値、最後の点より後は最後の値を保持する。1点だけなら全区間でその値になる。例えば静止状態から途中で拡大するには、動き始めに100%、動き終わりに150%の2点を打つ。回転は入力値をそのまま補間するため、0°→360°は1回転になる。
- 本体の左右移動ではキーをクリップと一緒に移動し、段移動では時刻を維持する。右トリムではキーの時刻を保つ。左トリムでは開始時刻の差をキーの相対秒から引き、曲上のキー時刻を保つ。トリムで区間外になったキーは隠して保存し、両端を伸ばせば再表示する。補間には区間外の前後のキーも使い、トリム前と同じ時刻で同じ値を得る。
- ドラッグ中は一時停止し、開始時の座標とモデルで仮編集する。点のドラッグでは、仮の点の時刻で変形をプレビューする。mouseUpで1操作として検証・保存し、Esc・タブ切替では仮編集を破棄する。選択・シーク・展開状態はUndo履歴の対象外。キー追加・更新・削除、固定値、縦軸範囲、自動アニメ設定は共通EditHistoryでUndo/Redoし、自動保存する。

## 音楽同期と手動変形の合成

各数値項目へ拍・帯域指定トランジェントの音楽同期を追加し、手動値へ加算または相対変化を重ねる。拡大縮小120%に相対8%が最大で掛かる場合は129.6%。戻り時間は0.03〜2秒、既定0.3秒。拍の音符分母は1〜16の全整数。グラフは手動線とピンクの合成線・発火位置を表示する。詳しくは [音楽同期仕様](AUDIO_AUTOMATION.md) を参照。


## モデルと実装の接続

| 所有先 | 保存する内容 |
| --- | --- |
| `VisualClip` | 固定値・基準値、項目別音楽同期、項目別の手動グラフ |
| 手動グラフ | 項目、縦軸の最小/最大、時刻順のキー、各キーから次のキーへの曲がり量、各キーへの流入区間の補間種別 |
| キー | UUID、クリップ開始からの相対秒、値。トリム後の相対秒は負値やクリップ長超過を許可 |

画像素材参照と分離し、同じ素材でもクリップごとに別のアニメーションを持てる。画像の差し替えでクリップのアニメーションを維持し、配置削除でそのクリップのアニメーションも削除する。選択中の点・展開状態・入力の仮値は保存しない。

1. `VisualTrack` の値モデルに変形とアニメーションを組み込む。数値欄・タイムラインで同じ更新・トリム処理を使う。保存前・復元時は項目とIDの一意性、キーの並びと時刻の重複、数値、縦軸範囲を検証する。
2. `ProjectFile` へ項目ごとの音楽同期設定を保存する。保存形式はversion 9で、旧version 4/5/6/7/8は対応外。新規画像の初期設定は「トランジェント・8%」、新規動画は「オフ」。
3. `SceneRenderer` が時刻から変形を計算する。プレビュー、シーク、MP4書き出しは共通の評価処理を使う。書き出し開始時に確定したモデルを固定し、編集中の仮値は含めない。
4. `VisualEditor` に変形欄と音楽同期欄、`PlacementEditor` と `TimelineView` にグラフ展開とキー操作をつなぐ。横座標は `TimelineGeometry`、拍スナップは `TimelineSnapGrid`、確定編集の履歴は `EditHistory` を共用する。

## 受け入れ確認

- 数値欄から最初のキーを打つと、レイヤーのレーンが開く。選択変更で収納されず、レイヤー名右の記号で開閉できる。基準値とキー・上下限の連動、ホイールリセット、クリック追加、ドラッグ、Delete、Esc、Undo/Redoを確認する。
- 最小50%・最大150%のグラフ中央をクリックすると100%になる。範囲を変更しても映像の値は同じで、不正な範囲は確定しない。
- クリップ移動では全キーが追従し、トリム後も残る区間の評価値は一致する。伸ばすと隠れた点が復元する。別段への移動や素材差し替えでキーは維持される。
- トランジェント・拍・無効を切り替え、120%の手動値と+8%の自動拡大からピーク時129.6%になることを確認する。BPM変更で拍の発火だけが変わり、手動キーの時刻は維持される。
- 保存・再読込でキー、縦軸、固定値、自動アニメが一致する。同じ時刻のシーク、通常再生、MP4のフレームで位置・拡大率・角度・描画順を比較する。

画像レイヤー行やオートメーションレーンの下端を上下にドラッグすると、その行の高さを調整できる。最小高さは画像行21pt、オートメーションレーン27pt。上下限を表示する高さが足りない場合は、右のインスペクターで上下限を編集する。レーンの高さはレイヤーとパラメーターの組み合わせごとにプロジェクトに保存する。表示領域を超えた行は縦スクロールで表示する。

### 基本の不透明度

不透明度は0〜100%、既定100%。0%は透明、50%は半透明、100%は元の表示。画像・動画の合成とブルーム/粒子の光量へ適用し、他のクリップや歌詞・スペクトラムには影響しない。共通DragValueFieldの直接入力、上下左右ドラッグ、中ボタン初期化とオートメーションに対応する。保存・Undo/Redo・プレビュー・出力で同じ値を使用する。カーブの値と基準値移動は0〜100%に制限する。

## 音楽同期への拡張案

項目ごとに拍・帯域指定トランジェントを手動カーブへ重ねる仕様は [AUDIO_AUTOMATION.md](AUDIO_AUTOMATION.md) を参照。拡大率専用の自動アニメは項目別の音楽同期へ統合している。
