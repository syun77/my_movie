# プレビューのXYハンドル

2026-11-19。承認された仕様を実装。位置X/Yの数値欄クリックからプレビュー上のハンドルで基準位置を編集する。

## 対象

位置を表すX/Yの組を明示登録する。画像・動画・Spineの配置位置、演出の中心/光源/発生源、図形とマスクの中心、歌詞位置、スペクトラム位置を対象とする。シェイクのX/Y強さ、幅/高さなどは座標ではないため含めない。複数発生源は発生源ごとに別の組とする。

ハンドルの基点は各欄の座標が指す点。配置は素材の基準中央、光源は光源位置、歌詞は中央揃えの軸とテキスト枠上端、スペクトラムは表示枠左上とする。

## 表示と解除

- 有効なXまたはYの数値欄（ノブを含む）を左クリックすると、その組のハンドルを表示する。ラベルクリックでも表示できるようにする。
- 数値欄のドラッグ開始・ダブルクリック入力でも表示する。既存の数値操作はそのまま動作する。Tabで欄へ移動した場合も対象にする。
- 同時に表示する操作対象は1組。他の位置欄をクリックすると切り替える。対応するX/Y両欄を同じ色で強調し、ハンドルに「画像の位置」「放射光線の中心」「光の粒子 発生源2」等の名前を添える。
- フィールドからプレビューへフォーカスが移っても表示を保つ。フォーカス喪失だけでは解除しない。
- 他の設定欄への操作、プレビューの空白クリック、クリップ選択変更、タブ切替、対象演出の無効化/削除、素材/プロジェクト切替で解除する。タイムラインでのシークや再描画だけでは解除しない。
- Escはドラッグ中なら今回の変更だけを取り消し、ハンドルは残す。通常時はハンドルを解除する。数値入力中のEscは既存の入力終了を優先し、次のEscで解除する。
- 対象クリップの区間外では隠し、同じ対象のまま区間内へ戻ったら再表示する。区間外のクリップを表示するための自動シークはしない。歌詞は表示中の歌詞があるとき、スペクトラムは表示有効時に表示する。
- 再生中は一時的に隠し、停止時に再表示する。表示操作そのものでは再生を止めない。UIだけの状態とし、保存・Undo対象にしない。

## 見た目とドラッグ

- 水色の十字と中央の丸で表示し、ホバー/ドラッグ中は黄色。表示サイズは画面上で一定とし、中心から約12ptの範囲を掴めるようにする。
- 中央をドラッグするとXYを同時変更。Shiftは移動方向が決まった時点で水平/垂直へ制限する。数値欄のShift低感度とは操作面が異なるため区別する。
- 掴んだ瞬間に座標をポインターへ合わせず、開始位置からの差分を適用して飛びを防ぐ。軸ごとの単位・刻み・有効範囲を既存数値欄と共有する。
- ドラッグ中は数値欄と映像を仮更新し、mouseUpでXYをまとめて1回確定・保存・Undo登録する。移動がなければ履歴を作らない。
- Esc、ウィンドウ非アクティブ化、対象の喪失、終了準備では開始時点へ戻す。途中で再生開始や選択変更を要求された場合も、仮編集を取り消してから処理する。
- ドラッグ開始時のモデル・再生時刻・座標変換を固定する。リサイズで変換が変わった場合は取り消す。
- 映像外の座標も元のパラメーター範囲内で許可する。画面外のハンドルは映像枠の端に方向付き代理ハンドルと「画面外」を表示し、元座標への差分ドラッグで戻せるようにする。枠端へ値を丸めない。
- ハンドル以外のプレビュー操作で画像や別の演出を自動選択しない。中ボタンの初期化は既存数値欄に任せる。

## オートメーションと音楽同期

初期仕様は数値欄と同じ固定値/基準値編集とする。ハンドル操作だけでキーを追加しない。

- 手動カーブなし: 固定値/基準値を変更する。
- 手動カーブあり: 各軸の基準値・全キー・上下限を同じ差分で移動する。範囲制限を既存の編集経路と共有する。
- 音楽同期あり: 同期設定を維持したまま基準値を変更する。
- ハンドルは編集する基準座標に表示する。アニメーション等の評価後の座標と異なる場合、評価後の位置を小さい非操作マーカーで示して点線でつなぎ、「基準位置を移動」と表示する。シェイクや光源固有の移動も評価後表示に含める。

これにより、音楽同期の相対倍率や上限への制限から元の値を逆算する必要をなくす。「現在時刻へキーを打つ」操作は別仕様として検討する。

## 座標と構成

1080p基準のモデル座標とプレビューの実際の映像矩形を変換する。余白は映像座標に含めない。画像位置は映像中央基準かつ描画変換のY方向を使い、演出には左上原点の座標もあるため、全項目へ同じ原点/Y方向を適用しない。描画と同じ変換を共有し、画面右へのドラッグは見た目で右、下へのドラッグは見た目で下へ動かす。UI表示が10px単位の項目もモデルのpx値で変換する。

- 座標ペア定義: 対象ID、X/Y項目、名前、基準点、座標変換、利用可能条件を集約する。項目名の末尾だけでペアを推測しない。
- 編集管理: 対象選択とドラッグセッションをモデルから分離し、既存の仮編集・確定・履歴経路へ接続する。
- DragValueField: 表示対象を通知する共通フックを設ける。既存の数値ドラッグ/リセット/右クリックを維持する。入力中のfield editor経由のクリックも扱う。
- PreviewView: MTKViewの上へAppKitの操作レイヤーを配置する。ハンドル外のイベントは通し、出力レンダラーへUIを混ぜない。
- マスクの既存ガイドは併用し、ガイド自体を別の移動対象にはしない。

PreviewPositionPairに13組のペア定義と基準値移動・評価後座標を集約。PreviewHandleCoordinatesが座標変換、PreviewHandleViewが表示とドラッグセッションを担当する。各編集器は既存の仮編集/確定通知を使う。

レンズフレアの自動移動ON時は既存仕様でX/Y数値欄が無効になるため、ハンドルも無効とする。

## 受入確認

表示/切替/解除とフォーカス移動、ダブルクリック/ノブ/中ボタン/右クリックの維持、全座標系での往復変換、XY同時更新とUndo1回、Esc取消、シークと区間外、再生時の非表示、非同期描画中の対象切替、画面外復帰、手動カーブと音楽同期の維持、ハンドルが動画へ出力されないことを検証する。コード実装後にbuild-app.shでappを再生成する。
