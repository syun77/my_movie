# 2値化演出

2026-11-19実装。追加演出「2値化」の現行仕様。

## 目的と適用対象

クリップの明暗をしきい値で2色に分け、白黒の切り絵、2色ポスター、音に合わせた明暗の変化を作る。「クリップ」の追加演出に「2値化」を追加する。画像・動画・Spine・図形・単色背景の共通素材加工面を対象とする。同じクリップの前段にある粒子・光も対象にする。後段の演出、別クリップ、歌詞、スペクトラムは対象外。

## 設定

| 項目 | 範囲 | 初期値 | 挙動 |
| --- | --- | --- | --- |
| 有効 | ON/OFF | 追加時ON | OFFでは処理を通さない |
| しきい値 | 0〜100% | 50% | 高くするほど暗部色が増える |
| 暗部の色 | RGB | 黒 | しきい値未満の色 |
| 明部の色 | RGB | 白 | しきい値以上の色 |
| 適用率 | 0〜100% | 100% | 0で加工前、100で完全な2色 |

「色を入れ替え」ボタンで暗部色と明部色を交換し、1回のUndoにする。色に独立した透明度は設けない。クリップ共通の不透明度を使う。しきい値と適用率の欄は整数表示、評価は小数を保持する。

初期版は境界ぼかし、ディザ、局所しきい値、自動しきい値を持たない。これらは2値の境界や時間的安定性を変えるため、必要になった段階で別途設計する。

## 色と透明度

入力RGBを `max(alpha, min(1, max(R,G,B)))` で割って判定色を求める。基準係数0は透明のままにする。これによりalpha0でRGBだけを持つ加算光も処理できる。線形sRGBの入力RGBを判定用に0〜1へ制限し、sRGBへ変換後の明るさを `Y = 0.2126 R + 0.7152 G + 0.0722 B` で求める。ここでのYは操作上の明るさであり、線形光の輝度とは区別する。中間グレーがしきい値50%付近で切り替わる操作感を優先する。

通常は `Y >= しきい値/100` を明部とする。端点は明示的に、0%では全有色画素を明部色、100%では全有色画素を暗部色とする。白画素を含めた完全な単色への遷移を保証する。

選択色を線形sRGBへ変換し、加工前のRGBと適用率で線形補間し、同じ基準係数を掛け直す。アルファ自体は変更しない。半透明PNG・Spineの縁を不透明にせず、透明領域に黒を生成しない。適用率100%でも半透明の縁や他レイヤーとの合成後には中間色が現れる。

## 処理順

2値化はチェーン内の指定位置で直前までの結果全体に作用する。

色調補正の明度で2値化する領域を調整でき、2値化後の白い部分をブルームで発光させられる。後段のぼかし・減光・光・拡大ループ等により最終結果が2色を超えることは許容する。処理順は [演出チェーン](EFFECT_CHAIN.md) で並べ替える。

## 編集・自動化・保存

- しきい値・適用率は共通DragValueFieldを使い、直接入力、ドラッグ、Shift微調整、中ボタン初期化、Esc取消に対応する。
- 両数値は手動オートメーションと項目別音楽同期に対応し、既存のParameterEvaluatorと物理範囲0〜100を共有する。色・有効状態は固定設定とする。
- ドラッグ中は仮プレビュー、終了時に1回確定して自動保存・Undo/Redoへ登録する。再生位置は動かさない。
- `ImageEffects.binarization` に有効状態・しきい値・2色・適用率を保持し、未設定は演出なし。削除時は専用カーブ・音楽同期・表示範囲も削除する。
- ProjectFile version 20に保存する。未設定の既存プロジェクトは演出なしで読み込む。

## 描画と検証

BinarizationRendererのCore Imageカーネルで1画素単位のGPU処理を行う。評価後の設定を画像加工キャッシュのキーへ含め、プレビュー・出力で同じ処理を使う。OFFまたは適用率0では処理を省略する。素材全体のCPU読出しやヒストグラム解析は不要。

検証対象は、黒/中間グレー/白/原色、しきい値の等号と0/100%、色交換、適用率0/50/100%、透明/半透明素材、後段演出との順序、前段粒子と対象外の歌詞、動画/Spine、保存復元、削除、Undo/Redo、シーク順に依存しないキー/音楽同期、プレビューとMP4の一致。動画の細部がしきい値付近でちらつくのは硬い2値化の性質であり、時間平滑化は初期版に含めない。
