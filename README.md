# my_movie

画像とオーディオファイルからMV（Music Video）を制作するmacOS向け動画編集ツール。

## 基本方針

- Swift＋AppKitで実装する。
- 画像とオーディオファイルを読み込み、画像にアニメーションを付けて音声とともに動画として書き出す。
- 既存の動画ファイル（mov、mp4）そのものの編集を主目的としない。

## 中核機能

### 音楽に同期した画像アニメーション

音楽データのトランジェント（音の立ち上がり）または拍をタイミングの基準として定め、画像のアニメーションを自動化する。
実装設計では、手動BPM・拍の開始位置指定と、トランジェントの自動検出・手動補正を段階的に実装する方針を提案している。

### 帯域ごとのオーディオビジュアライザー

イコライザーの表示のように、音声の周波数帯域ごとの強さに連動するアニメーションを簡単に表示できるようにする。
実装設計では、棒状スペクトラムのプリセットを最初に実装し、色・配置・感度・滑らかさなどを調整できる形を提案している。
