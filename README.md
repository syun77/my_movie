# MV Studio

最大50段の画像・動画レイヤーと音声1本から、音楽に連動するMVを作るSwift＋AppKitのmacOSアプリです。

## 起動

macOS 14以降、Xcode/Swift 6以降が必要です。外部ライブラリは不要です。

```bash
./scripts/build-app.sh
open "dist/MV Studio.app"
```

生成されるアプリはローカル利用用の署名です。Xcodeで開く場合は `Package.swift` を開き、MVStudioを実行してください。

## 使い方

左上で映像をプレビューし、右上の「歌詞」「クリップ」タブでクリップを追加・編集します。下段は全幅のタイムラインで、再生、全曲シーク、表示範囲の操作もここにあります。再生ボタンと全曲シークバーの上にある境界線を上へドラッグすると、映像プレビューが小さくなり、タイムラインが広がります。下へドラッグすると、映像プレビューが広がります。右側の設定欄は縦スクロールで操作できます。「クリップ」では選択中の素材名と種類を上部に固定表示します。「選択項目の自動化」の対象を一つ選ぶと、キー／LFO・音楽同期・グラフ表示範囲を同じ項目に対して編集できます。基本変形・演出の数値やタイムラインのレーンからも対象を選べます。対象を選ぶだけではキーや音楽同期を追加しません。歌詞・画像のクリップ行やオートメーションレーンの下端も、上下にドラッグして個別に高さを調整できます。表示しきれない行はタイムライン上で縦スクロールしてください。タイムライン全体と各行の高さは、プロジェクトに自動保存されます。タイムラインやオートメーションレーン上で **Shift＋ホイール** を使うと、再生位置を変えずに左右へスクロールできます。**⌘＋ホイール** で横方向に拡大・縮小できます。ズームでは約0.2秒かけて滑らかに表示範囲が変わります。**Option（Alt）＋ホイール** で再生位置を前後に動かせます。拡大中は細かく、縮小中は大きく移動します。歌詞・画像クリップの左右端にポインタを置くと、長さを調整できる部分が黄色に変わります。

「クリップ」上部の **「変更のみ」チェックボックス** をONにすると変更項目だけ、OFFにするとすべての項目を表示します。「変更のみ」は初期値と異なる項目と、キー・LFO・音楽同期を設定した項目を表示します。隠れた項目は「項目を選んで編集…」から呼び出せます。初期値に戻しても編集中は欄を保持し、表示モードは次回起動にも引き継ぎます。


位置のX/Y数値欄・ノブ・ラベルをクリックすると、プレビューにその組の移動ハンドルが表示されます。ハンドルをドラッグしてXYを同時変更でき、Shiftで水平・垂直に制限できます。離すと確定し、ドラッグ中のEscで取消、通常時のEscやプレビューの空白クリックで非表示にします。再生中は一時的に隠れます。画像・動画・Spineの位置、演出の中心や発生源、歌詞・スペクトラムの位置に対応します。オートメーションがある項目では基準値とカーブ全体を移動し、キーは追加しません。詳細は[XYハンドルの仕様](docs/PREVIEW_HANDLES.md)を参照してください。


1. 「プロジェクト設定」タブの「音声を選択…」で音声を読み込み、音声解析が完了するまで待ちます。
2. 同じタブでタイムラインのスナップ用にBPMと拍の開始位置（秒）を調整します。 新規音声のファイル名に `bpm128`・`128bpm` の指定があれば、そのBPMを自動設定します（大小文字・小数対応、20〜300、複数指定は先頭の有効値）。保存済みプロジェクトがある場合は保存値を優先します。
3. 「クリップ」タブで画像行を選び「素材と配置」見出し横の三メニュー →「＋素材を配置…」から画像・動画を選択するか、PNG/JPEG/TIFF/MP4/MOVをタイムラインの空白へ1ファイルずつドロップします。
4. ブロックの移動・端のドラッグ、開始/終了秒、所属レイヤー、画像ごとの自動アニメ・手動キーフレームを調整します。「追加演出」からブラー・ブルーム・光の粒子・舞い上がる火の粉・雪・光の粒子2を重ねられます。「プロジェクト設定 → 素材管理…」で素材を追加・削除・置き換えできます。
5. 「歌詞」タブでテロップを編集します。
6. 「スペクトラム」タブで表示のオン・オフ、バー／折れ線、色、分解度（4・8・16・32・64帯域）を選びます。幅で表示間隔、高さで振幅、X・Yで表示位置を調整し、「再生」で確認します。
7. 「MP4を書き出す」で音声全体を1920×1080（1080p）・30fpsのH.264/AAC動画として保存します。画像ゼロでも出力できます。

音声はmacOSがデコードできるWAV/AIFF/M4A/MP3などに対応します。解析・書き出し中は設定を固定し、「キャンセル」で停止できます。出力先の既存ファイルは保存ダイアログで置換を確認した後、出力完成時に置き換えます。

スペクトラムのサイズと位置は1920×1080基準のpxで、X・Yは映像左上から表示枠の左上までの距離です。バーの上辺は担当する周波数範囲の両端の強さを直線で結びます。バーの余白は、隣り合うバーの中心間隔に対する割合（0〜90%）で指定でき、0%では上辺がつながります。スペクトラムは映像に直接重ねます。

数値欄は左右にドラッグして調整でき、離すと確定します。ダブルクリックで直接入力し、ホイールクリックで初期値へ戻せます。歌詞・画像の時刻欄では拍スナップと区間の検証が適用されます。


演出の追加メニューは「色・質感」「ぼかし・発光」「粒子・天候」「効果線」「動き・抽象映像」「背景・図形・マスク」の6カテゴリです。チェーンの「この後に追加」でも同じカテゴリから選べます。追加済みの演出は表示を残して重複追加を防ぎ、追加済み一覧は適用順を保ちます。詳細は [演出カテゴリ](docs/EFFECT_CATEGORIES.md) を参照してください。

## 動画素材の同期再生

「クリップ」の **素材と配置 → 三メニュー → ＋素材を配置…** またはタイムラインへのファイルドロップから、MP4／MOV／M4Vの映像を画像と同じ可変レイヤーへ配置できます。主音声の時刻に合わせて等速再生し、動画内の音声は再生しません。H.264／HEVCのSDR素材を検証対象とし、HDR・透過動画・ネットワーク素材は対象外です。

動画は素材の長さ、次の配置、曲末までの範囲に配置されます。選択すると **素材開始（秒）** で動画内の開始位置を指定できます。左端トリムは素材開始位置も移動し、本体移動は素材開始位置を保ちます。変形・演出、Undo/Redo、コピー／貼り付け、素材管理の置換も共通です。再生前・シーク中は映像を準備し、デコードが大きく遅れた場合は再生を一時停止します。

**画像・動画を配置したプロジェクトをMP4へ出力できます。** 素材開始位置・トリム・変形・演出・歌詞・スペクトラムを反映し、1920×1080／30fpsのH.264映像と主音声のみの48kHz AAC音声を書き込みます。動画内の音声は含みません。使用中の素材が欠損・読込不能の場合は出力を停止し、未配置素材の欠損は出力を妨げません。保存形式はversion 21で、v18〜20は元ファイルをバックアップしてv21へ変換します。対応範囲外・変換不能な形式は元ファイルを保持して読み込みを停止します。詳細は [動画タイムライン仕様](docs/VIDEO_TIMELINE.md) を参照してください。

## シンプル版の範囲

- 位置・等比拡大縮小・回転・不透明度のキーフレーム、項目別の拍・帯域指定トランジェント同期
- クリップごとのガウスブラー、放射ブラー、ブルーム、光の粒子、舞い上がる火の粉、雪、光の粒子2
- 周波数帯域の強さを表示するスペクトラム。初期設定は水色の32本のバーで、設定はプレビューとMP4の両方に反映されます。
- 音声付きプレビュー、シーク、動画書き出し
- 解析と描画を分離し、プレビューと出力で共通の時刻評価・描画を使用

「音楽同期」は変形・不透明度・追加演出の数値ごとに設定できます。数値欄を右クリックして追加・編集・削除し、手動カーブへ加算または相対変化を重ねます。拍は4分音符=1拍を基準に音符分母1〜16を整数指定（初期4）。トランジェントは全帯域・低域・中域・高域・カスタムHzから選択します。戻り時間は0.03〜2秒（初期0.3秒）。新規画像・動画は音楽同期・オートメーション・追加演出なしで配置します。タイムラインには手動線とピンクの合成線・発火目盛りを表示します。詳細は [音楽同期仕様](docs/AUDIO_AUTOMATION.md) を参照してください。

基本パラメーターの「不透明度」は0〜100%（初期100%）で画像・演出を薄くでき、オートメーションによるフェードにも使えます。

手動アニメは、クリップ内に再生位置を合わせ、変形ノブまたは数値を右クリックして「オートメーションを作成」を選びます。作成済みのノブ右上には小さな青い丸が表示され、右クリックで「オートメーションを削除」を選べます。削除後は基準値を固定値として使います。レイヤー名右の **> / v** でレーンを開閉し、グラフのクリックでキーを追加します。黄色になった点はドラッグで時刻と値を調整でき、Deleteで削除できます。隣接する点の中間にある **○** を上下にドラッグすると、端の点を保ったまま区間のカーブを上向き・下向きに曲げられます。変形・演出の両方に対応し、Escで取り消せます。 制御点の右クリックから「削除」「シングル曲線（既定）」「スムーズ」「ホールド」「パルス」「ウェーブ」を選べます。カーブの種類は、直前の点から右クリックした点までに適用されます。スムーズは両端でなだらかになり、ホールドはその点の時刻まで前の値を保ちます。 パルスは矩形波、ウェーブはサイン波です。中央○を上下に動かすと、パルスは高低の幅を同じに保って周期が変わり、ウェーブでは周期を調整できます。パルスは上へ動かすと広く・周期が長く、下へ動かすと狭く・周期が短くなります。高低は50%ずつで、区間の両端も同じ幅になるよう周期数を整数に揃えます。ホバー中は幅と周期を秒で表示します。

レーンがある項目の変形欄は基準値です。基準値を変更すると、上下限とキー値が同じ差分だけ移動します。基準値、最小、最大はダブルクリックで入力、上下左右ドラッグで調整、ホイールクリックで初期値に戻せます。最小・最大だけを変更するとグラフの表示範囲が変わります。詳しくは [画像クリップのアニメーション](docs/IMAGE_ANIMATION.md) を参照してください。

## プリセット

「歌詞」「スペクトラム」の各タブで **プリセット → 現在の設定を保存…** を選び、名前を入力します。保存先は `~/Library/Application Support/MV Studio/Presets` です。別のプロジェクトを開き、同じタブの **プリセット** から保存した名前を選ぶと適用されます。適用は自動保存され、Undo/Redoで取り消し・やり直しができます。

保存または適用したプリセットにはチェックが付きます。設定を調整したあと、同じメニューの **「プリセット名」を上書き** で共有プリセットを更新できます。プロジェクトを開くと選択をリセットします。

- 歌詞はフォント・サイズ・描画位置・縁取りを保存します。適用先の本文、区間、連結はそのままです。
- スペクトラムは表示のオン・オフ、形式、色、帯域数、位置、サイズ、バーの余白を保存します。

## 自動保存と次回起動時の復元

音声の読み込み完了時に、同じフォルダへ `音声ファイル名.mvproject` を自動保存します（例: `song.wav.mvproject`）。画像の変更、BPM・拍開始位置の入力確定、拡大の強さ・スペクトラム設定の変更、終了時にも保存します。次回起動時は最後に保存できたプロジェクトを自動で開きます。同じ音声を選び直した場合も、既存のプロジェクトを復元します。

保存対象は音声・画像・動画素材の参照、画像の各配置/レイヤー/変形/アニメーション/追加演出、歌詞とフォント・描画位置・縁取りの設定です。配置していない画像も素材管理に残り、次回復元されます。再生は先頭から停止状態で再開し、音声解析は再実行します。素材はコピーしません。同じフォルダの素材は相対パス、別フォルダの画像は絶対パスで参照するため、別フォルダの画像を移動した場合は再選択してください。保存失敗は画面に表示され、次回起動用の参照先は成功時のみ更新されます。

プレビューと書き出しはMetalとCore Imageの共通レンダラーを使います。再生にはAVAudioPlayerを使用し、1080pのH.264映像とAAC音声を同じMP4へ書き出します。プレビューは960×540で内部描画します。

## 検証

```bash
CLANG_MODULE_CACHE_PATH=/tmp/my_movie-clang-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/tmp/my_movie-swift-cache \
swift test --disable-sandbox --cache-path /tmp/my_movie-spm-cache
```

無音、逆相ステレオの1kHz帯域検出、トランジェント検出、拡大の減衰、補間、音声付きMP4生成・読み戻しをテストします。Metal描画と動画書き出しのテストには、GPUとmacOSのメディアエンコーダへのアクセスが必要です。

構成は `Sources/MVStudio`（UI、解析、共通描画、書出し）と `Tests/MVStudioTests` に分離しています。継続的な進捗は `PROGRESS.md` を参照してください。

## タイムラインの設計

可変映像レイヤー（初期3段・最大50段）、「歌詞」「クリップ」タブ、歌詞ゴースト、画像ドロップ、素材管理を実装済みです。詳細は [画像タイムライン設計](docs/IMAGE_TIMELINE.md) を参照してください。

歌詞テロップの一覧編集・区間指定・文字表示を実装しています。詳細な設計は [タイムライン設計書](docs/TIMELINE.md) を参照してください。

文字入力中でなければSpaceキーで再生・一時停止できます。Command＋Spaceなら文字入力中でも再生・一時停止できます。入力フォーカスと変換中の文字は維持します。歌詞や数値の入力中はSpaceを通常の入力として扱い、Escキーで入力を確定してフォーカスを外します。

### 歌詞の見た目

1. 音声を読み込み、シークで歌詞の開始位置に移動します。
2. 「＋歌詞」で追加します。再生位置がテロップ内なら、その連結列の末尾に自動連結します。どのテロップにも重ならない位置なら、その再生位置から独立して追加します。追加したテロップの開始位置へシークします。
3. 本文と開始・終了秒を編集すると、自動でプレビューに反映・保存されます。適用ボタンは不要です。改行や本文の全文削除も反映します。日本語変換中は確定を待ち、時刻が空欄・不正な区間の間は最後の有効な内容を保持します。
4. 「フォント」でMacにインストール済みの書体を選びます。「サイズ」「X」「Y」は1080p基準のpxです。Xは映像左端から中央揃えの基準まで、Yは映像上端からテキスト枠の上端までの距離です。初期値はヒラギノ角ゴ W6、54px、X960、Y540です。
5. 「縁取り色」で色を選び、「太さ」で0〜12px（720p基準）を調整します。0で無効になります。設定は全歌詞共通で、変更時に自動保存されます。

白文字に縁取りを重ね、プレビューとMP4で同じ見た目にします。同時表示は1フレーズで、歌詞区間の重なりは設定できません。

### テロップの連結

「直前のテロップ末尾に連結」がONの歌詞は、直前の終了位置に追従します。先頭の開始位置を変えると表示時間を保って全体を移動し、終了位置を変えると後続の連結テロップが長さを保って移動します。独立したテロップは動きません。

連結チェックを外すと現在の位置のまま独立します。連結中の開始時刻を直接変更した場合も独立へ切り替えます。チェックを付けると直前のテロップ末尾へ接続します。曲末超過や独立テロップとの重なりが起きる変更は保存されません。直前を削除した場合は、その直後のテロップを現在位置で独立させます。連結設定はプロジェクトへ保存されます。

保存するプロジェクトはversion 21です。v18〜20は段階変換して読み込み、検証後に元データをバックアップしてv21へ保存します。v17以前・未来の形式・変換不能な形式は読み込みを停止します。詳細は [保存形式の世代管理](docs/PROJECT_MIGRATION.md) を参照してください。

### 拡大タイムライン

- 選択した歌詞・画像クリップは **⌘X** で切り取り、**⌘C** でコピーできます。**⌘V** は再生位置に貼り付けます。画像は選択中の画像行に貼り付けます。
- **⌘D** は選択したクリップの終端に同じ長さで複製します。貼り付け・複製先が同じ行のクリップと重なる場合や曲末を超える場合は配置できません。歌詞のコピーは独立したクリップになります。文字入力欄では通常のテキスト編集が使えます。
- クリップの右クリックメニューから切り取り・コピー・貼り付け・複製・削除を選べます。タイムラインでクリップを選択し、**Delete** でも削除できます。オートメーションの制御点を選択中は、Delete でその点を削除します。

全曲用のシークバーとは別に、再生位置付近の歌詞を拡大表示します。「表示範囲」で2〜300秒に調整でき、初期値は12秒です。変更した表示範囲はアプリ共通設定として自動保存され、再起動後や別の曲でも復元されます。通常は再生位置に表示が追従します。横スクロールした後は、再生を開始するか全曲シークバーを操作すると追従に戻ります。ピンクの線が現在位置、各ブロックの左右端が開始・終了です。時刻はミリ秒まで表示します。

- 本体をドラッグ：長さを保って移動します。連結した後続も追従します。
- 左端をドラッグ：終了を固定して開始を調整します。
- 右端をドラッグ：終了を調整し、連結した後続も追従します。
- 空白・時間目盛りをクリック/ドラッグ：その位置へシークします。
- ブロックをクリック：歌詞を選択して本文・時刻欄へ表示します。
- Esc：ドラッグを取り消して元へ戻します。

操作開始時に再生を一時停止し、ドラッグ中は表示範囲を固定します。ドラッグ中は映像へ仮反映し、マウスを離すと一括反映・自動保存します。新規作成・時刻入力・ドラッグは、タイムライン上部の「スナップ」で選んだ全音符・2分・4分・8分・16分音符の間隔で、拍開始を基準にスナップします。初期値は16分音符で、選択はアプリに保存します。クリップタブの「制御点スナップ」がオンなら、制御点の追加・横移動も同じグリッドまたはクリップの端に揃います。ドラッグは移動先の開始（右端トリムは終了）を揃え、独立した隣のテロップや曲の両端、最小表示時間を越えないように制限します。本体の移動や左端の変更では、そのテロップの直前との連結は解除します。連結した後続は維持します。

### 画像・演出と素材管理

- **追加演出 → 2値化** で、しきい値（初期50%）を境に暗部・明部の2色へ分けられます。初期は白黒で、色交換・適用率の調整が可能。しきい値と適用率はキー・音楽同期に対応し、素材の透明度を保持します。詳細は [2値化の仕様](docs/BINARIZATION.md) を参照してください。
- **追加演出 → 色調補正** で、色相（±180°）・明度（±100%）・彩度（0〜200%）を調整できます。3項目ともオートメーションに対応します。

- クリップを選択して **追加演出 → ＋ 演出を追加** を開きます。ガウスブラーは画像をぼかし、ブルームは画像の明部に光をにじませます。光の粒子は曲線を描く発光点の後を追い、星形に明滅しながら色が移り変わります。「曲線の強さ」で振れ幅を0〜200%に調整でき、色欄で色相の起点を選べます。上段の画像が手前に重なると粒子は隠れます。
- 「光の粒子」の発生源欄では＋で最大4つまで追加できます。番号を選び、映像左上を原点とするX・Yで軌道の中心を指定します。
- 「舞い上がる火の粉」は、画面下から立ち上る橙色の火の粉を重ねます。個数、大きさ、上昇速度、横風、揺れの速さ、明るさを調整できます。
- 「雪」は、輪郭が柔らかい白い粒を映像全体に降らせます。個数、大きさ、落下速度、横風、不透明度を調整できます。
- 「光の粒子2」は、色とりどりの丸い光が、画面中央から軌道を広げたり縮めたりしながら粒ごとに異なる方向へ回転します。光は加算合成され、粒の外側では元の画像がそのまま見えます。発生数、彩度、速度、不透明度を調整できます。
- 各演出は種類のメニューで選択して設定します。「有効」のチェックを外すと設定値を保ったまま一時停止でき、「削除」で選択中の演出を取り除けます。数値は1080p基準です。 [追加演出の仕様](docs/IMAGE_EFFECTS.md)

- クリップ本体を別の画像行へ上下ドラッグすると、開始/終了と演出を保ってレイヤーを移動できます。重なる行やタイムライン外で離すと元に戻り、Escでも取り消せます。同じ段での左右ドラッグは時刻移動です。
- 画像1が最背面、画像3が最前面です。各段には複数の画像を時間順に配置でき、同じ段の前後2クリップを重ねると、その重なり時間でクロスフェードします。包含・同時3重は配置できません。別段は通常合成します。
- ファイルドロップは落とした行と時刻に配置します。1回1枚、長さは2秒を目安とし、選択中の音符単位にスナップします。既存画像に重なる場所へのドロップは置き換えになりません。
- 背面に表示する薄い歌詞ゴーストはタイミング確認用で、クリックや出力の対象になりません。映像では通常の歌詞を表示します。
- 「配置を削除」はそのブロックだけ削除します。素材一覧や元ファイルは残ります。
- 「プロジェクト設定 → 素材管理…」で読込済み画像と使用箇所を確認できます。「画像を読み込む…」は未配置素材として登録します。
- 管理画面の「置き換え…」は、その素材を使用する全配置へ反映します。欠損画像も別ファイルへ置き換えて復旧できます。編集欄の「画像を変更…」は選択中の配置だけを変更します。
- 使用中素材の削除は、その素材を使う配置も削除する確認を表示します。元の画像ファイルは削除しません。
- 欠損画像が配置されている場合は書き出しを停止し、素材管理からの修復を案内します。未配置素材の欠損は出力を妨げません。

タブと表示範囲はアプリ共通設定として保存します。プロジェクトの素材はコピーしないため、参照元を移動した場合は素材管理から置き換えてください。

## Undo / Redo

「編集」メニューまたは **⌘Z**（取り消す）／**⇧⌘Z**（やり直す）で、歌詞・画像・共通設定の編集を戻せます。追加/削除、本文/時刻/連結/フォント/描画位置/縁取り、画像の配置/段移動/トリム/変形/自動アニメ/キーフレーム/グラフ範囲/追加演出、素材の登録/削除/置換、BPM/拍開始/スペクトラムが対象です。削除した素材と配置もまとめて復元します。

本文・時刻の入力セッション、スライダーの1回の操作、タイムラインの1回のドラッグをそれぞれまとめます。Undo/Redo後も自動保存します。IME変換中や解析・画像読込・動画出力中は実行できません。Escはドラッグ中の取消です。

履歴はメモリ内で保持し、音声/プロジェクトの読込成功時にリセットします。音声の切替・再起動をまたいだ復元、元の画像ファイルそのものの変更、書き出した動画、選択・シーク・タブ・表示範囲は履歴の対象外です。

表示範囲は固定2〜300秒または「曲全体」を選択可能。「曲全体」は5分を超える曲にも対応し、曲切替時も曲長に追従する。固定範囲と切替状態をUserDefaultsへ保存し、表示幅に合わせて目盛り間隔を調整する。

数値欄は丸ノブと数値を併設しています。右・上へのドラッグで増加、左・下で減少し、最初に動かした主方向で操作します。Shiftを押すと感度が1/10になります。ノブの点は初期値、針は現在値を示します。範囲のある項目は範囲内の割合、その他は初期値を中心とした相対位置を示します。

動画クリップを選ぶと「再生速度（倍）」で0.1〜16倍に変更できます。素材の使用区間を保って配置の長さが変わります（2倍なら長さは半分）。隣の配置や曲末を超える変更、1フレーム未満になる変更は適用されません。数値をダブルクリックして直接入力、ノブをドラッグして調整、中ボタンで1倍へ戻せます。プレビューとMP4出力に同じ速度を使用します。

## Spine素材を配置する

「クリップ」→「素材と配置」見出し横の三メニュー →「＋素材を配置…」でSpine 4.3のJSONを選択します。同名atlasがなければatlasを選択してください。提供サンプルでは `testdata-blink-v2-neck-merged.json` の後に `spine.atlas` を選びます。PNGはatlasから読み込みます。JSONのタイムラインへのドロップも利用できます。

アニメーション選択、ループ／終端保持、素材開始、移動・回転、凸形／凹形マスク、ウェイト付きメッシュを使用できます。可変レイヤーの画像・動画と混在し、主音声に同期してプレビュー・MP4出力します。配置と参照は自動保存・Undo/Redo・コピー／貼り付けに対応します。外部更新後は素材管理の「再読込」を使います。

初期対応はdefault skin・速度1倍・物理OFF・normal blendです。特殊blend、tint black、deformキー、制約を使うモデル、複数skin、.skelは対象外です。対応外の機能は黙って省略せずエラーを表示します。Spine Runtimesのライセンスと固定ソース情報はアプリのResources/Licensesへ同梱します。

実装範囲と検証内容は [初期実装仕様](docs/SPINE_PHASE1.md)、後段の構想は [Spine配置・再生設計](docs/SPINE_TIMELINE.md) を参照してください。

Spine選択後「オートメーションを作成」で名前付きの切替レーンを表示します。名前へ縦スナップし、キー時刻でホールド切替します。左欄の右クリック→「2つのアニメーションでブレンド」でA（下端0%）とB（上端100%）を選び、混合率カーブを編集できます。既定はシングル曲線です。アニメーションはクリップ共通時計で進み、切替やブレンドで先頭に戻りません。

ブレンドのレーンを削除すると通常のアニメーション選択へ戻ります。削除時の混合率が50%未満ならA、50%以上ならBを選択し、A/Bと混合率の欄を閉じます。詳細は [Spineオートメーション仕様](docs/SPINE_AUTOMATION.md) を参照してください。

### 図形とマスク

「クリップ」の追加演出から「図形」「このクリップのマスク」を追加できます。長方形・三角形・楕円・星の幅/高さ・中心・回転を指定し、図形には色と不透明度を設定できます。マスクはその位置までのクリップ全体を切り抜き、出力欄の「直下段のマスク」と同時に使用できます。両方とも反転・境界ぼかし・強さを調整できます。直下が空でもさらに下の段へは適用しません。空クリップで図形やマスクだけを使う場合は「単色背景が有効」をOFFにします。数値の右クリックからオートメーション・音楽同期を設定できます。詳細は [図形とマスク](docs/SHAPES_AND_MASKS.md) を参照してください。

集中線は「クリップ」→「追加演出」から追加できます。中心と空白のサイズ、線の本数・太さ・長さ・ばらつき・色・不透明度、更新頻度を調整できます。更新頻度0で静止し、ほかの9数値はキー・音楽同期に対応します。空クリップで線だけを重ねる場合は単色背景を無効にします。詳細は [集中線](docs/FOCUS_LINES.md) を参照してください。

- 追加演出「八芒星」: 青白く光る反復空間。速度・拡大率・明るさ・不透明度を調整でき、オートメーションと音楽同期に対応します。

「集中線２」は放射状ノイズによる青〜水色の光の集中線です。追加演出から選択し、速度・拡大率・明るさ・不透明度を調整できます。4項目ともキー・音楽同期に対応します。

### 拡大ループ

追加演出「拡大ループ」は現在の配置素材に拡大・回転・2段階のクロスフェードを適用する。速度100%で約3.33秒周期、拡大率100%、明るさ100%、不透明度100%、中心X960/Y540が初期値。中心は1080p基準・左上原点のpx座標。6数値は共通ノブ・キー・音楽同期に対応する。不透明度0%または無効で元画像を描画する。直前までの結果全体を読み取り、前段の粒子・光・図形も拡大します。描画面の外は透明です。歌詞・スペクトラムは対象外です。自画像マスクと下段マスク、クリップ不透明度を共有する。左トリムは位相を保持し、設定をversion21へ保存する。

- 追加演出「ワープ航行」: 星間空間を前進する全画面演出。速度・拡大率・明るさ・不透明度、オートメーションと音楽同期に対応します。

- 追加演出「Vignette（周辺減光）」は光学風の滑らかな減衰で、強さ・範囲・ぼかしを調整できます。各項目はオートメーションと音楽同期に対応します。

- 色収差: 提供シェーダーの `(1+sin(6t))/2 × (1+sin(16t)/2) × (1+sin(19t)/2) × (1+sin(27t)/2)` を3乗して、赤/青のサンプル座標を逆方向にずらす。ずれ量0〜100pxは1080p基準の乗算係数で、初期96pxは画面幅の5%に相当（実際のずれは時間式により係数を超える）。角度−180〜180°、初期0°。正方向から赤、負方向から青を取得し、リニアRGBを `max(0, 1−ずれpx/1920×0.5)` 倍する。クリップ相対時刻と保存する位相を使い、左トリムで連続性を維持。チェーン内の指定位置で前段全体へ適用し、歌詞・スペクトラムは対象外。透明領域外のサンプルは透明、合成alphaは3サンプルの最大値。0px/無効で元描画。共通数値操作・キー・音楽同期・保存・Undo/Redo・プレビュー/MP4出力に対応。

クロスグレア: 「追加演出」から追加し、素材の明るい部分へ十字の光を付けられます。しきい値・強さ・長さ・太さ・角度はキーと音楽同期に対応します。[仕様と性能上の制約](docs/CROSS_GLARE.md)。

- 追加演出「レンズフレア」: 光源X/Y・大きさ・強さを調整でき、キーと音楽同期に対応します。


### 放射ブラー

追加演出の「放射ブラー」は、中心に向かう軌跡を連続的にぼかします。強さ・中心X/Y・最大サンプル回数を調整できます。最大回数は2〜256（新規256）で、軌跡の長さに応じて自動的にサンプルを配分します。既存クリップの回数は上限として保持するため、品質を高めたい場合は256へ上げてください。回数を増やしてもブラーの区間長は変わりません。固定ジッターで規則的な残像を軽減し、プレビューとMP4で同じMetal処理を使います。高い上限ほどGPU負荷が増えます。詳細は [品質評価](docs/RADIAL_BLUR_QUALITY.md) を参照してください。

集中線３（一定幅の線・短い尖端・不透明度のばらつき）の仕様は [docs/SHARP_FOCUS_LINES.md](docs/SHARP_FOCUS_LINES.md) を参照。追加演出から利用でき、更新頻度以外の11数値はキー・音楽同期に対応する。

- 直線効果線: 角度・表示本数・長さ・太さ・速度、ばらつき・フェード・発光・色を調整できる平行線演出。キー・音楽同期に対応。詳細は [仕様](docs/STRAIGHT_LINES.md)。

### 放射光線

「クリップ → 追加演出 → 放射光線」で、中心から広がる加算光線と白い中心光を重ねられます。「中心からの長さ」で長半径、「潰れ具合」で正円からの変形を調整します。光線は0%で正円、＋で横長、−で縦長。中心光と光輪は常に正円です。「画面比率に合わせる」で長さを保って16:9へ揃えられます。本数・太さ・明滅・光量・にじみを調整でき、14数値はオートメーションと音楽同期に対応します。「形状のばらつき」を上げると光線の向きがランダムに回転し、「更新頻度」で切替の速さを調整できます。更新頻度0で静止。「配置を変更」で再抽選します。空クリップで光だけを重ねる場合は単色背景を無効にしてください。詳細は [放射光線](docs/RADIAL_RAYS.md)。

### 演出チェーン

「追加演出」の一覧は上から下へ適用します。ハンドルを上下ドラッグするか、行のメニューで並べ替えられます。5pt以上動かすと元の行が薄くなり、半透明の行がポインターに追従します。黄色の挿入線で移動先を示し、Escや領域外ドロップで取り消せます。「雪→ブラー」は雪もぼかし、「ブラー→雪」は雪を鮮明に保ちます。各演出の無効化、全体バイパス、途中への追加、Undo/Redoに対応します。「このクリップのマスク」はその位置までの結果を切り抜き、「直下段のマスク」はクリップタブ最下部の独立カテゴリから設定します。設定・キー・音楽同期はノードと一緒に保持します。詳細は [演出チェーン](docs/EFFECT_CHAIN.md)。

保存形式はv21、読込はv18〜21です。旧形式は原本をバックアップして段階変換し、既存ノードの順序・設定を保持します。

光の粒子・火の粉・雪・光の粒子2は「粒子の見た目」で画像を選択できます。大きさ・角度・回転ばらつき・回転速度はキーと音楽同期に対応し、元画像/演出色と通常/加算を選べます。画像未指定・解除後は既存形状で演出します。詳細は [パーティクル画像](docs/PARTICLE_IMAGES.md)。


### 可変レイヤー

「クリップ」のタイムライン左上の **＋レイヤー** で段を追加できます。初期3段・最大50段、最低1段を残します。左欄の≡を上下へドラッグして前後を変更し、名前のダブルクリックで改名します。●/○はプレビューと出力の表示切替、錠は編集のロックです。⋯または右クリックで追加位置・前後移動・削除を選べます。内容がある段の削除は確認し、Undoで戻せます。

上ほど前面です。直下段マスクは空段・非表示段を飛び越さず、詳細欄に対象名を表示します。50段は編集・保存の上限であり、全段のリアルタイム再生保証ではありません。重い演出や多数の動画・Spineには既存のメモリ制限も適用されます。詳細は [可変レイヤー仕様](docs/VARIABLE_VISUAL_LAYERS.md) を参照してください。

Sobel＋色収差は「追加演出 → 色・質感」から追加できます。自動切替／輪郭／色収差／合成を選び、輪郭の幅・強さ・色、色ずれ量、速度、適用率を調整できます。5つの数値はキーと音楽同期に対応します。詳細は [Sobel＋色収差](docs/SOBEL_CHROMATIC.md) を参照してください。

炎アウトラインは「追加演出 → ぼかし・発光」から追加できます。四辺から内側へ揺らぐ紫系の炎を透明背景に重ねます。中心位置・幅/高さ・広がり・細かさ・速度・明るさ・不透明度・色相の10項目はキーと音楽同期に対応し、中心はプレビューのハンドルでも移動できます。素材なしの空クリップでも使用できます。詳細は [炎アウトライン](docs/FIRE_OUTLINE.md) を参照してください。

### 電撃ビーム

「追加演出 → 効果線 → 電撃ビーム」で、画像・動画・Spine・空クリップに電撃を重ねられます。位置、角度、長さ、本数、太さ、折れ曲がり、発光、速度、色を設定でき、全数値はキー・音楽同期に対応します。電撃だけを別レイヤーへ重ねる場合は単色背景をOFFにします。詳細は [電撃ビーム](docs/ELECTRIC_BEAM.md) を参照してください。

グラデーション背景は「追加演出 → 背景・図形・マスク」から追加できます。2色・直線/円形・A→B/A→B→Aを選び、中心・位置・変化幅・角度・偏り・不透明度を調整します。数値のキー/音楽同期にも対応します。空クリップの単色背景が前段にある場合はOFFにしてください。[仕様](docs/GRADIENT_BACKGROUND.md)。

### LFOオートメーション

クリップインスペクターの「選択項目の自動化」で対象項目を選び、「LFO」へ切り替えてAmountを増やします。Hz指定または音符周期（通常/付点/3連）、Tilt、Curve、Bipolar、位相と曲/クリップ基準を設定できます。キーへ戻すと保持したキーを復元します。数値はダブルクリック入力・ドラッグ・中ボタン初期化に対応し、プレビュー・MP4・Undo/Redo・自動保存へ反映します。レーンの右クリックからもモードを切り替えられます。詳細は [LFO仕様](docs/LFO_AUTOMATION.md) を参照してください。

追加演出「粒子・天候 → 渦巻き粒子」は外周から中心へ旋回して集まる粒子を描きます。中心・半径・個数・収束時間・回転数・速度・サイズ・不透明度、回転方向・色・粒子画像を調整できます。数値はキー/LFO/音楽同期、中心はプレビューハンドルに対応します。

渦巻き粒子の標準表示では「ぼかしの幅」「ぼかしの強さ」で粒の周囲の光を調整できます。幅または強さ0で芯だけを描きます。画像方式では無効です。

- 歌詞の光彩幅はアウトラインと独立した0〜50px（1080p基準）。指定色のぼかしを文字の背後へ描き、0で無効。共通ノブで編集し、プロジェクト・歌詞プリセット・Undo/Redo・プレビュー・動画出力で共有する。未保存時は0px・白。光彩カテゴリの「色」でアウトラインとは独立した色を指定できる。

- 歌詞タイムラインの空白をダブルクリック、または右クリックの「歌詞クリップを追加」で、その位置にスナップして歌詞を追加する。クリップの右クリックでコピー/貼り付け/複製を選べる。⌘Cで選択クリップをコピー、⌘Vで再生位置へ貼り付け、⌘Dで選択クリップの直後へ複製する。重なりや曲末超過は反映しない。文字入力中は通常の文字コピー/貼り付けを使う。

同じレイヤーのクリップを重ねると、重なり全体でなだらかにクロスフェードします。交差する2本の曲線が切替区間を示し、移動・端トリムで時間を調整できます。画像・動画・Spine・空クリップに共通です。詳細は [クロスフェード仕様](docs/CLIP_CROSSFADE.md)。

プロジェクト全体の音声選択、BPM・拍開始、素材管理、出力形式の確認、MP4書き出しは「プロジェクト設定」タブにまとめています。設定タブでは直前の歌詞／クリップのタイムラインを維持します。再生・シーク、表示範囲・スナップ、処理の進捗・キャンセルは共通領域で操作できます。
