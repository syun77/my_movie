# MV Studio

最大3段の画像レイヤーと音声1本から、音楽に連動するMVを作るSwift＋AppKitのmacOSアプリです。

## 起動

macOS 14以降、Xcode/Swift 6以降が必要です。外部ライブラリは不要です。

```bash
./scripts/build-app.sh
open "dist/MV Studio.app"
```

生成されるアプリはローカル利用用の署名です。Xcodeで開く場合は `Package.swift` を開き、MVStudioを実行してください。

## 使い方

左上で映像をプレビューし、右上の「歌詞」「画像・演出」タブでクリップを追加・編集します。下段は全幅のタイムラインで、再生、全曲シーク、表示範囲の操作もここにあります。タイムラインやオートメーションレーン上で **⌘＋ホイール** を使うと、再生位置付近を横方向に拡大・縮小できます。ホイール操作では約0.2秒かけて滑らかに表示範囲が変わります。歌詞・画像クリップの左右端にポインタを置くと、長さを調整できる部分が黄色に変わります。

1. 「音声を選択…」で音声を読み込み、32帯域の解析が完了するまで待ちます。
2. タイムラインのスナップ用にBPMと拍の開始位置（秒）を調整します。
3. 「画像・演出」タブで画像行を選び「＋画像を配置…」から画像を選択するか、PNG/JPEG/TIFFをタイムラインの空白へ1枚ずつドロップします。
4. ブロックの移動・端のドラッグ、開始/終了秒、所属レイヤー、画像ごとの自動アニメ・手動キーフレームを調整します。「画像管理…」で素材を追加・削除・置き換えできます。
5. 「歌詞」タブでテロップを編集し、「再生」で映像と音声を確認します。スペクトラム表示も切り替えられます。
6. 「MP4を書き出す」で音声全体を1920×1080（1080p）・30fpsのH.264/AAC動画として保存します。画像ゼロでも出力できます。

音声はmacOSがデコードできるWAV/AIFF/M4A/MP3などに対応します。解析・書き出し中は設定を固定し、「キャンセル」で停止できます。出力先の既存ファイルは保存ダイアログで置換を確認した後、出力完成時に置き換えます。

## シンプル版の範囲

- 位置・等比拡大縮小・回転のキーフレーム、トランジェント・拍に同期した拡大
- 周波数帯域の強さを表示する32本の棒状スペクトラム
- 音声付きプレビュー、シーク、動画書き出し
- 解析と描画を分離し、プレビューと出力で共通の時刻評価・描画を使用

「自動アニメ」は画像クリップごとに「オフ」「トランジェント」「拍」を選べます。打音または四分音符の位置で拡大し、0.3秒で元の倍率に戻ります。強さは0〜25%です。

手動アニメは、画像クリップ内に再生位置を合わせ、変形欄の **◇** で最初のキーを打ちます。レイヤー名右の **> / v** でレーンを開閉できます。グラフのクリックでキーを追加します。ポインタを近づけて黄色になった点はドラッグで時刻と値を調整でき、Deleteで削除できます。追加の **◇** はその時刻のグラフの値でキーを打ちます。

レーンがある項目の変形欄は基準値です。基準値を変更すると、上下限とキー値が同じ差分だけ移動します。基準値、最小、最大はダブルクリックで入力、左右ドラッグで調整、ホイールクリックで初期値に戻せます。最小・最大だけを変更するとグラフの表示範囲が変わります。詳しくは [画像クリップのアニメーション](docs/IMAGE_ANIMATION.md) を参照してください。

## 自動保存と次回起動時の復元

音声の読み込み完了時に、同じフォルダへ `音声ファイル名.mvproject` を自動保存します（例: `song.wav.mvproject`）。画像の変更、BPM・拍開始位置の入力確定、拡大の強さ・スペクトラム表示の変更、終了時にも保存します。次回起動時は最後に保存できたプロジェクトを自動で開きます。同じ音声を選び直した場合も、既存のプロジェクトを復元します。

保存対象は音声・画像素材の参照、画像の各配置/レイヤー/変形/アニメーション、歌詞と縁取り設定です。配置していない画像も画像管理に残り、次回復元されます。再生は先頭から停止状態で再開し、音声解析は再実行します。素材はコピーしません。同じフォルダの素材は相対パス、別フォルダの画像は絶対パスで参照するため、別フォルダの画像を移動した場合は再選択してください。保存失敗は画面に表示され、次回起動用の参照先は成功時のみ更新されます。

シンプル版はCore Graphicsで描画し、AVAudioPlayerで再生します。出力は一時映像を作成してから元音声と結合します。大規模なレイヤー編集向けのMetal構成は [設計書](docs/ARCHITECTURE.md) に記載しています。

## 検証

```bash
CLANG_MODULE_CACHE_PATH=/tmp/my_movie-clang-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/tmp/my_movie-swift-cache \
swift test --disable-sandbox --cache-path /tmp/my_movie-spm-cache
```

無音、逆相ステレオの1kHz帯域検出、トランジェント検出、拡大の減衰、補間、音声付きMP4生成・読み戻しをテストします。書き出しテストにはmacOSのメディアエンコーダへのアクセスが必要です。

構成は `Sources/MVStudio`（UI、解析、共通描画、書出し）と `Tests/MVStudioTests` に分離しています。継続的な進捗は `PROGRESS.md` を参照してください。

## タイムラインの設計

画像3レイヤー、「歌詞」「画像・演出」タブ、歌詞ゴースト、画像ドロップ、画像管理を実装済みです。詳細は [画像タイムライン設計](docs/IMAGE_TIMELINE.md) を参照してください。

歌詞テロップの一覧編集・区間指定・文字表示を実装しています。詳細な設計は [タイムライン設計書](docs/TIMELINE.md) を参照してください。

文字入力中でなければSpaceキーで再生・一時停止できます。Command＋Spaceなら文字入力中でも再生・一時停止できます。入力フォーカスと変換中の文字は維持します。歌詞や数値の入力中はSpaceを通常の入力として扱い、Escキーで入力を確定してフォーカスを外します。

### 歌詞と縁取り

1. 音声を読み込み、シークで歌詞の開始位置に移動します。
2. 「＋歌詞」で追加します。再生位置がテロップ内なら、その連結列の末尾に自動連結します。どのテロップにも重ならない位置なら、その再生位置から独立して追加します。追加したテロップの開始位置へシークします。
3. 本文と開始・終了秒を編集すると、自動でプレビューに反映・保存されます。適用ボタンは不要です。改行や本文の全文削除も反映します。日本語変換中は確定を待ち、時刻が空欄・不正な区間の間は最後の有効な内容を保持します。
4. 「縁取り色」で色を選び、「太さ」で0〜12px（720p基準）を調整します。0で無効になります。設定は全歌詞共通で、変更時に自動保存されます。

白文字に縁取りを重ね、プレビューとMP4で同じ見た目にします。同時表示は1フレーズで、歌詞区間の重なりは設定できません。

### テロップの連結

「直前のテロップ末尾に連結」がONの歌詞は、直前の終了位置に追従します。先頭の開始位置を変えると表示時間を保って全体を移動し、終了位置を変えると後続の連結テロップが長さを保って移動します。独立したテロップは動きません。

連結チェックを外すと現在の位置のまま独立します。連結中の開始時刻を直接変更した場合も独立へ切り替えます。チェックを付けると直前のテロップ末尾へ接続します。曲末超過や独立テロップとの重なりが起きる変更は保存されません。直前を削除した場合は、その直後のテロップを現在位置で独立させます。連結設定はプロジェクトへ保存されます。

プロジェクト形式はversion 4です。旧形式を読み込んだ場合はそのまま上書きせず、「バックアップして新規作成」を選ぶと旧ファイルを別名で残して作り直せます。旧設定の自動移行は行いません。

### 拡大タイムライン

全曲用のシークバーとは別に、再生位置付近の歌詞を拡大表示します。「表示範囲」で2〜300秒に調整でき、初期値は12秒です。変更した表示範囲はアプリ共通設定として自動保存され、再起動後や別の曲でも復元されます。再生・シークに合わせて表示範囲が追従し、ピンクの線が現在位置、各ブロックの左右端が開始・終了です。時刻はミリ秒まで表示します。

- 本体をドラッグ：長さを保って移動します。連結した後続も追従します。
- 左端をドラッグ：終了を固定して開始を調整します。
- 右端をドラッグ：終了を調整し、連結した後続も追従します。
- 空白・時間目盛りをクリック/ドラッグ：その位置へシークします。
- ブロックをクリック：歌詞を選択して本文・時刻欄へ表示します。
- Esc：ドラッグを取り消して元へ戻します。

操作開始時に再生を一時停止し、ドラッグ中は表示範囲を固定します。ドラッグ中は映像へ仮反映し、マウスを離すと一括反映・自動保存します。新規作成・時刻入力・ドラッグは、BPMの16分音符（60 ÷ BPM ÷ 4秒）単位で、拍開始を基準にスナップします。ドラッグは移動先の開始（右端トリムは終了）を揃え、独立した隣のテロップや曲の両端、最小表示時間を越えないように制限します。本体の移動や左端の変更では、そのテロップの直前との連結は解除します。連結した後続は維持します。

### 画像・演出と画像管理

- クリップ本体を別の画像行へ上下ドラッグすると、開始/終了と演出を保ってレイヤーを移動できます。重なる行やタイムライン外で離すと元に戻り、Escでも取り消せます。同じ段での左右ドラッグは時刻移動です。
- 画像1が最背面、画像3が最前面です。各段には複数の画像を時間順に配置でき、同じ段の重なりは禁止、別段の重なりは許可します。
- ファイルドロップは落とした行と時刻に配置します。1回1枚、初期長2秒、16分音符単位にスナップします。既存画像に重なる場所へのドロップは置き換えになりません。
- 背面に表示する薄い歌詞ゴーストはタイミング確認用で、クリックや出力の対象になりません。映像では通常の歌詞を表示します。
- 「配置を削除」はそのブロックだけ削除します。素材一覧や元ファイルは残ります。
- 「画像管理…」で読込済み画像と使用箇所を確認できます。「画像を読み込む…」は未配置素材として登録します。
- 管理画面の「置き換え…」は、その素材を使用する全配置へ反映します。欠損画像も別ファイルへ置き換えて復旧できます。編集欄の「画像を変更…」は選択中の配置だけを変更します。
- 使用中素材の削除は、その素材を使う配置も削除する確認を表示します。元の画像ファイルは削除しません。
- 欠損画像が配置されている場合は書き出しを停止し、画像管理からの修復を案内します。未配置素材の欠損は出力を妨げません。

タブと表示範囲はアプリ共通設定として保存します。プロジェクトの素材はコピーしないため、参照元を移動した場合は画像管理から置き換えてください。

## Undo / Redo

「編集」メニューまたは **⌘Z**（取り消す）／**⇧⌘Z**（やり直す）で、歌詞・画像・共通設定の編集を戻せます。追加/削除、本文/時刻/連結/縁取り、画像の配置/段移動/トリム/変形/自動アニメ/キーフレーム/グラフ範囲、素材の登録/削除/置換、BPM/拍開始/スペクトラムが対象です。削除した素材と配置もまとめて復元します。

本文・時刻の入力セッション、スライダーの1回の操作、タイムラインの1回のドラッグをそれぞれまとめます。Undo/Redo後も自動保存します。IME変換中や解析・画像読込・動画出力中は実行できません。Escはドラッグ中の取消です。

履歴はメモリ内で保持し、音声/プロジェクトの読込成功時にリセットします。音声の切替・再起動をまたいだ復元、元の画像ファイルそのものの変更、書き出した動画、選択・シーク・タブ・表示範囲は履歴の対象外です。

表示範囲は固定2〜300秒または「曲全体」を選択可能。「曲全体」は5分を超える曲にも対応し、曲切替時も曲長に追従する。固定範囲と切替状態をUserDefaultsへ保存し、表示幅に合わせて目盛り間隔を調整する。
