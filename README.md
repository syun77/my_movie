# MV Studio

画像1枚と音声1本から、音楽に連動するMVを作るSwift＋AppKitのmacOSアプリです。

## 起動

macOS 14以降、Xcode/Swift 6以降が必要です。外部ライブラリは不要です。

```bash
./scripts/build-app.sh
open "dist/MV Studio.app"
```

生成されるアプリはローカル利用用の署名です。Xcodeで開く場合は `Package.swift` を開き、MVStudioを実行してください。

## 使い方

1. 「画像を選択…」でPNG/JPEG/TIFFを読み込みます。
2. 「音声を選択…」で音声を読み込みます。32帯域の解析が完了するまで待ちます。
3. BPM、拍の開始位置（秒）、拡大の強さを調整します。開始位置より前は拡大しません。
4. 「再生」で音声と映像を確認します。スライダーで任意の時刻へ移動できます。
5. 「スペクトラムを表示」で帯域表示を切り替えます。
6. 「MP4を書き出す」で音声全体を1280×720・30fpsのH.264/AAC動画として保存します。

音声はmacOSがデコードできるWAV/AIFF/M4A/MP3などに対応します。解析・書き出し中は設定を固定し、「キャンセル」で停止できます。出力先の既存ファイルは保存ダイアログで置換を確認した後、出力完成時に置き換えます。

## シンプル版の範囲

- 画像のアスペクト比を保持した中央配置、拍に同期した拡大パルス
- 周波数帯域の強さを表示する32本の棒状スペクトラム
- 音声付きプレビュー、シーク、動画書き出し
- 解析と描画を分離し、プレビューと出力で共通の時刻評価・描画を使用

BPMは手動指定です。トランジェント検出、BPM自動推定、複数画像・レイヤー、Undoは今後の実装対象です。

## 自動保存と次回起動時の復元

音声の読み込み完了時に、同じフォルダへ `音声ファイル名.mvproject` を自動保存します（例: `song.wav.mvproject`）。画像の変更、BPM・拍開始位置の入力確定、拡大の強さ・スペクトラム表示の変更、終了時にも保存します。次回起動時は最後に保存できたプロジェクトを自動で開きます。同じ音声を選び直した場合も、既存のプロジェクトを復元します。

保存対象は音声・画像の参照、アニメーション設定、歌詞と縁取り設定です。再生は先頭から停止状態で再開し、音声解析は再実行します。素材はコピーしません。同じフォルダの素材は相対パス、別フォルダの画像は絶対パスで参照するため、別フォルダの画像を移動した場合は再選択してください。保存失敗は画面に表示され、次回起動用の参照先は成功時のみ更新されます。

シンプル版はCore Graphicsで描画し、AVAudioPlayerで再生します。出力は一時映像を作成してから元音声と結合します。大規模なレイヤー編集向けのMetal構成は [設計書](docs/ARCHITECTURE.md) に記載しています。

## 検証

```bash
CLANG_MODULE_CACHE_PATH=/tmp/my_movie-clang-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/tmp/my_movie-swift-cache \
swift test --disable-sandbox --cache-path /tmp/my_movie-spm-cache
```

無音、逆相ステレオの1kHz帯域検出、拍と開始位置、補間、音声付きMP4生成・読み戻しをテストします。書き出しテストにはmacOSのメディアエンコーダへのアクセスが必要です。

構成は `Sources/MVStudio`（UI、解析、共通描画、書出し）と `Tests/MVStudioTests` に分離しています。継続的な進捗は `PROGRESS.md` を参照してください。

## タイムラインの設計

歌詞テロップの一覧編集・区間指定・文字表示を実装しています。Undoなどの目標設計は [タイムライン設計書](docs/TIMELINE.md) を参照してください。

### 歌詞と縁取り

1. 音声を読み込み、シークで歌詞の開始位置に移動します。
2. 「＋歌詞」で追加します。再生位置がテロップ内なら、その連結列の末尾に自動連結します。どのテロップにも重ならない位置なら、その再生位置から独立して追加します。追加したテロップの開始位置へシークします。
3. 本文と開始・終了秒を編集すると、自動でプレビューに反映・保存されます。適用ボタンは不要です。改行や本文の全文削除も反映します。日本語変換中は確定を待ち、時刻が空欄・不正な区間の間は最後の有効な内容を保持します。
   再生またはシークで位置を合わせて「現在位置を開始に」「現在位置を終了に」を押すと、その場で一時停止し、選択中の歌詞に時刻を適用・自動保存します。この操作では編集欄の本文ともう一方の時刻も一緒に適用します。不正な区間ではエラーを表示し、保存しません。
4. 「縁取り色」で色を選び、「太さ」で0〜12px（720p基準）を調整します。0で無効になります。設定は全歌詞共通で、変更時に自動保存されます。

白文字に縁取りを重ね、プレビューとMP4で同じ見た目にします。同時表示は1フレーズで、歌詞区間の重なりは設定できません。

### テロップの連結

「直前のテロップ末尾に連結」がONの歌詞は、直前の終了位置に追従します。先頭の開始位置を変えると表示時間を保って全体を移動し、終了位置を変えると後続の連結テロップが長さを保って移動します。独立したテロップは動きません。

連結チェックを外すと現在の位置のまま独立します。連結中の開始時刻を直接変更した場合も独立へ切り替えます。チェックを付けると直前のテロップ末尾へ接続します。曲末超過や独立テロップとの重なりが起きる変更は保存されません。直前を削除した場合は、その直後のテロップを現在位置で独立させます。連結設定はプロジェクトへ保存されます。

プロジェクト形式はversion 2です。旧形式を読み込んだ場合はそのまま上書きせず、「バックアップして新規作成」を選ぶと旧ファイルを別名で残して作り直せます。旧設定の自動移行は行いません。

### 拡大タイムライン

全曲用のシークバーとは別に、再生位置付近の歌詞を拡大表示します。「表示範囲」で2〜30秒に調整でき、初期値は12秒です。再生・シークに合わせて表示範囲が追従し、ピンクの線が現在位置、各ブロックの左右端が開始・終了です。時刻はミリ秒まで表示します。

- 本体をドラッグ：長さを保って移動します。連結した後続も追従します。
- 左端をドラッグ：終了を固定して開始を調整します。
- 右端をドラッグ：終了を調整し、連結した後続も追従します。
- 空白・時間目盛りをクリック/ドラッグ：その位置へシークします。
- ブロックをクリック：歌詞を選択して本文・時刻欄へ表示します。
- Esc：ドラッグを取り消して元へ戻します。

操作開始時に再生を一時停止し、ドラッグ中は表示範囲を固定します。ドラッグ中は映像へ仮反映し、マウスを離すと一括反映・自動保存します。位置は1/30秒単位で調整し、独立した隣のテロップや曲の両端、最小表示時間を越えないように制限します。本体の移動や左端の変更では、そのテロップの直前との連結は解除します。連結した後続は維持します。
